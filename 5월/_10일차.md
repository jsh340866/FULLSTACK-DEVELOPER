## 1. 추상 클래스 기반 Unit 구조(Ch20/unit/Unit.java)

### 설명

`Unit` 클래스는 모든 유닛의 공통 속성과 동작을 정의하는 추상 클래스입니다.
Marine, Medic 같은 실제 유닛 클래스들이 이를 상속받아 구현됩니다.

공통 데이터:

* hp
* armor
* type
* isDead

공통 메서드:

* move()
* underAttack()

추상 메서드를 사용하여 각 유닛마다 서로 다른 이동 및 피격 로직을 구현할 수 있도록 구성했습니다.

### 실제 코드

```java
package Ch20.unit;

public abstract class Unit {
	int hp;
	int amor;
	String type;
	public boolean isDead;
	
	abstract public void move();
	abstract public void underAttack(int damage);
}
```

### 예상 출력

```text
(추상 클래스이므로 직접 실행 불가)
```

### 핵심 정리

* 추상 클래스는 공통 기능 정의용
* 객체 생성 불가능
* 상속받은 클래스에서 추상 메서드 구현 필요

## 2. Marine 공격 시스템 구현(Ch20/unit/Marine.java)

### 설명

Marine 클래스는 Unit을 상속받아 실제 공격 기능을 구현합니다.

특징:

* 기본 공격 가능
* 총기 사용 공격 가능
* 공격 방식 선택 가능
* Gun 객체를 주입받아 공격 수행

공격 방식:

* 총기사용
* 기본공격

객체지향적으로 무기 기능을 분리하여 확장 가능하게 설계했습니다.

### 실제 코드

```java
public class Marine extends Unit {

	int base_damage;
	Gun myGun;
	
	int attackMethod;
	
	public final static int 총기사용=1;
	public final static int 기본공격=2;
	
	public void attack(Unit unit) {
		if(!unit.isDead) {
			if(this.attackMethod==this.총기사용)
				myGun.fire(unit);
			else
				unit.underAttack(this.base_damage);
		}
	}
}
```

### 예상 출력

```text
marine1 이 공격합니다
총기 공격 실행
```

### 핵심 정리

* 객체 내부에 다른 객체를 포함하는 구조 사용
* 공격 방식을 상수로 관리
* 다형성을 활용한 무기 교체 가능

## 4. Thread를 이용한 동시 실행(Ch20/Main_01.java)

### 설명

Thread를 이용하여 여러 동작을 동시에 실행했습니다.

동시 실행 구조:

* Medic가 지속적으로 회복
* Marine끼리 공격 수행
* 각각 독립 Thread에서 동작

실제 게임 구조처럼 병렬 처리 흐름을 구현했습니다.

### 실제 코드

```java
new Thread() {
	@Override
	public void run() {
		while(true) {
			medic1.setHealingPoint(marine1);
			try {
				Thread.sleep(1500);
			} catch (InterruptedException e) {
				e.printStackTrace();
			}
		}
	}
}.start();
```

### 예상 출력

```text
marine1 회복 중...
marine2 공격 중...
```

### 핵심 정리

* Thread는 동시에 작업 수행 가능
* sleep()으로 실행 간격 제어
* 게임/서버/채팅 프로그램에서 자주 사용
