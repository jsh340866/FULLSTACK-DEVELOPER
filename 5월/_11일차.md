## 1. JSP 선언문 사용(Ch01/C01선언문.jsp)

### 설명
JSP 선언문(`<%! %>`)을 사용해 멤버변수와 메서드를 선언했다.  
표현식(`<%= %>`)으로 값을 화면에 출력했다.

### 실제 코드
```jsp
<%!
	String name = "HONG GIL DONE";

	public String testFunc() {
		return "name : " + name;
	}
%>

NAME : <%=name %>
testFunc : <%=testFunc() %>
```

### 예상 출력
```text
NAME : HONG GIL DONE
testFunc : name : HONG GIL DONE
```

### 핵심 정리
- 선언문은 멤버변수/메서드 생성
- 표현식은 화면 출력용

---

## 2. JSP 선언문 변수 동작(Ch01/C02선언문.jsp)

### 설명
선언문에서 만든 변수는 객체 상태를 유지할 수 있다.

### 실제 코드
```jsp
<%!
	int n = 0;

	public int countUp() {
		n++;
		return n;
	}
%>

N : <%= countUp() %>
```

### 예상 출력
```text
N : 1
새로고침
N : 2
```

### 핵심 정리
- 선언문 변수는 멤버변수처럼 동작
- 새로고침 시 값 유지 가능

---

## 3. 스크립틀릿 사용(Ch01/C03스크립틀릿.jsp)

### 설명
스크립틀릿(`<% %>`) 안에서 자바 코드를 실행했다.

### 실제 코드
```jsp
<%
	String str1 = "HELLO1";
	String str2 = "HELLO2";
	String str3 = str1 + str2;

	int a = 0;

	for(int i=0;i<10;i++){
		a++;
	}
%>
```

### 예상 출력
```text
str1 : HELLO1
str2 : HELLO2
str3 : HELLO1HELLO2
a : 10
```

### 핵심 정리
- 스크립틀릿은 Service 영역 코드
- 반복문/조건문 사용 가능

---

## 8. JavaBean DTO 연동(Ch02/C04Request_Process.jsp)

### 설명
폼 데이터를 JavaBean DTO 객체와 자동 매핑했다.

### 실제 코드
```jsp
<jsp:useBean id="dto" class="Ch02.C04TestDto" scope="request"/>
<jsp:setProperty property="*" name="dto"/>
```

### 예상 출력
```text
DTO : C04TestDto [username=test, password=1234]
```

### 핵심 정리
- useBean : 객체 생성
- setProperty : request 값 자동 저장
