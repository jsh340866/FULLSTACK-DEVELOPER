## 1. Forward와 Redirect 차이 (`Ch03`)

### 설명

JSP에서 페이지를 이동시키는 방식에는:

- Forward
- Redirect

두 가지가 있습니다.

---

### 실제 코드

#### Forward

```jsp
request.setAttribute("C02", "02_Value");
request.getRequestDispatcher("./03.jsp").forward(request,response);
```

#### Redirect

```jsp
response.sendRedirect("./03.jsp");
```

---

### 코드 해석

#### Forward

```jsp
request.getRequestDispatcher("./03.jsp").forward(request,response);
```

- 서버 내부 이동
- request 데이터 유지
- 주소 변경 없음

즉:

```jsp
request.setAttribute("C02","값");
```

으로 저장한 데이터를 다음 페이지에서도 사용 가능합니다.

---

#### Redirect

```jsp
response.sendRedirect("./03.jsp");
```

- 브라우저가 새 요청 수행
- request 데이터 초기화
- 주소 변경 발생

---

### 핵심 정리

- Forward = request 유지
- Redirect = 새 요청 발생

---

## 2. EL(Expression Language) (`Ch03`)

### 설명

EL은 JSP에서 데이터를 쉽게 출력하기 위한 문법입니다.

---

### 실제 코드

```jsp
${name}
${param.username}
${C02}
```

---

### 코드 해석

```jsp
${name}
```

는 기존 자바 코드:

```jsp
<%= request.getAttribute("name") %>
```

를 간단하게 표현한 방식입니다.

---

### 핵심 정리

- `${}` 형태 사용
- request/session/param 접근 가능
- JSP 코드 단순화

# Ch04 - 회원가입 / 로그인 처리

---

## 3. DTO(Data Transfer Object) (`Ch04`)

### 설명

DTO는 데이터를 저장하는 객체입니다.

회원가입 정보들을 하나로 묶어서 전달합니다.

---

### 실제 코드

```java
private String userid;
private String password;
private String username;
```

---

### 코드 해석

회원 정보를:

- 아이디
- 비밀번호
- 이름

형태로 저장하는 객체입니다.

즉:

```java
UserDTO dto
```

하나가 회원 데이터 전체를 관리합니다.

---

### 핵심 정리

- DTO = 데이터 저장 객체
- 회원정보 묶음 역할

---

## 4. DAO(Data Access Object) (`Ch04`)

### 설명

DAO는 DB 작업을 담당하는 객체입니다.

---

### 실제 코드

```java
dao.insert(dto);
```

---

### 코드 해석

```java
dao.insert(dto);
```

의 의미:

- DTO 안 데이터를
- DB에 INSERT 수행

즉 흐름은:

```text
JSP → DTO → DAO → DB
```

입니다.

---

### 핵심 정리

- DAO = DB 처리 객체
- INSERT / SELECT 담당

---

## 5. JDBC 연결 (`Ch04`)

### 설명

JDBC는 자바에서 DB와 연결하기 위한 기술입니다.

---

### 실제 코드

```java
Class.forName(driver);

Connection conn =
DriverManager.getConnection(url,user,password);
```

---

### 코드 해석

```java
Class.forName(driver);
```

- JDBC 드라이버 로딩

```java
DriverManager.getConnection(...)
```

- MySQL DB 연결 수행

---

### 핵심 정리

- JDBC = 자바 DB 연결 기술
- SQL 실행 가능

---

## 6. 회원가입 처리 흐름 (`Ch04/auth`)

### 설명

회원가입 처리 과정:

1. 사용자 입력
2. DTO 저장
3. DAO INSERT
4. DB 저장
5. 로그인 페이지 이동

---

### 실제 코드

```jsp
<jsp:useBean id="dto" class="Ch04.UserDTO"/>
<jsp:setProperty name="dto" property="*"/>
```

```java
dao.insert(dto);
```

---

### 코드 해석

```jsp
<jsp:setProperty name="dto" property="*"/>
```

- form 데이터를 DTO에 자동 저장

```java
dao.insert(dto);
```

- DB INSERT 수행

---

### 핵심 정리

- 입력값 → DTO 저장
- DAO → DB INSERT

---

## 7. 로그인 처리 흐름 (`Ch04/auth`)

### 설명

로그인은 DB 정보와 비교하여 인증하는 과정입니다.

---

### 실제 코드

```java
UserDTO userDTO = dao.select(userid);
```

```java
if(password.equals(userDTO.getPassword()))
```

---

### 코드 해석

```java
dao.select(userid);
```

- DB 사용자 조회

```java
password.equals(userDTO.getPassword())
```

- 비밀번호 비교

성공 시:

```jsp
session.setAttribute("isAuth", true);
```

- 로그인 상태 유지

---

### 핵심 정리

- DB 사용자 검증
- Session 로그인 유지

## 8. Session 개념 (`Ch05`)

### 설명

Session은 사용자별 데이터를 저장하는 공간입니다.

로그인 상태 유지에 사용됩니다.

---

### 실제 코드

```jsp
session.setAttribute("userid", userid);
```

---

### 코드 해석

```jsp
session.setAttribute("userid", userid);
```

- 로그인 성공 후 사용자 정보 저장
- 다른 페이지에서도 로그인 상태 유지 가능

---

### 핵심 정리

- 사용자 상태 저장
- 로그인 유지 핵심 기능
