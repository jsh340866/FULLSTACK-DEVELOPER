## 1. 회원가입 페이지 구성 (`Ch04/join_form.jsp`)

### 설명

* 사용자 정보를 입력받는 회원가입 폼 구현
* form 태그와 input 태그 사용 방식 확인
* action 속성을 통해 데이터 전달

### 실제 코드

```jsp
<form action="auth/Join.jsp" method="post">
    <input type="text" name="userid">
    <input type="password" name="password">
    <button>회원가입</button>
</form>
```

### 예상 출력

```text
아이디와 비밀번호 입력 후 회원가입 요청
```

### 핵심 정리

* form의 action은 데이터를 전달할 JSP 의미
* method="post"는 body 영역으로 데이터 전달
* name 속성값으로 request.getParameter() 사용 가능

## 2. 회원가입 처리 (`Ch04/auth/Join.jsp`)

### 설명

* request.getParameter()로 사용자 입력값 받기
* 전달받은 데이터를 변수에 저장
* 회원가입 처리 흐름 확인

### 실제 코드

```jsp
String userid = request.getParameter("userid");
String password = request.getParameter("password");
```

### 예상 출력

```text
회원가입 처리 완료
```

### 핵심 정리

* request 객체는 요청 데이터를 저장
* getParameter()로 form 데이터 추출 가능

## 10. Forward와 Redirect 복습 (`Ch03중요/Forward`, `Ch03중요/Redirect`)

### 설명

* Forward와 Redirect의 차이 실습
* request 유지 여부와 URL 변경 차이 확인

### 실제 코드

```jsp
RequestDispatcher dispatcher = request.getRequestDispatcher("03.jsp");
dispatcher.forward(request, response);
```

```jsp
response.sendRedirect("03.jsp");
```

### 예상 출력

```text
Forward : URL 유지
Redirect : URL 변경
```

### 핵심 정리

* Forward는 서버 내부 이동
* Redirect는 클라이언트 재요청
* Forward는 request 유지 가능
* Redirect는 새로운 request 생성
