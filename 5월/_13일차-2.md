## 1. Cookie 생성 (`Ch06/01/setCookie.jsp`)

### 설명

* Cookie 객체를 생성하여 사용자 브라우저에 저장
* response.addCookie()를 통해 클라이언트로 전달
* 로그인 유지 기능 등에 활용 가능

### 실제 코드

```jsp
Cookie cookie = new Cookie("userid", "admin");
response.addCookie(cookie);
```

### 예상 출력

```text
쿠키 저장 완료
```

### 핵심 정리

* Cookie는 브라우저에 저장되는 데이터
* response.addCookie()로 전달 가능
* Session과 달리 클라이언트에 저장됨

---

## 2. Cookie 조회 (`Ch06/01/getCookie.jsp`)

### 설명

* request.getCookies()를 이용해 저장된 쿠키 조회
* 반복문으로 쿠키 이름과 값 확인

### 실제 코드

```jsp
Cookie[] cookies = request.getCookies();
```

### 예상 출력

```text
userid = admin
```

### 핵심 정리

* request.getCookies()는 배열 형태 반환
* 브라우저에 저장된 쿠키 확인 가능

---

## 3. Cookie 삭제 (`Ch06/01/deleteCookie.jsp`)

### 설명

* Cookie의 유효 시간을 0으로 설정하여 삭제
* 로그아웃 및 자동 로그인 해제에 사용 가능

### 실제 코드

```jsp
cookie.setMaxAge(0);
response.addCookie(cookie);
```

### 예상 출력

```text
쿠키 삭제 완료
```

### 핵심 정리

* setMaxAge(0)은 즉시 삭제 의미
* 삭제 후 다시 addCookie() 필요

---

## 4. Cookie 활용 예제 (`Ch06/02/setCookie.jsp`)

### 설명

* Cookie의 유지 시간과 경로(path) 설정
* 브라우저 종료 후에도 유지되는 Cookie 실습

### 실제 코드

```jsp
cookie.setMaxAge(60*60);
cookie.setPath("/");
```

### 예상 출력

```text
1시간 유지되는 쿠키 생성
```

### 핵심 정리

* setPath()로 쿠키 사용 범위 지정 가능
* setMaxAge()로 유지 시간 설정 가능

---

## 5. PageContext 객체 (`Ch07/C01PageContext.jsp`)

### 설명

* JSP 내장 객체인 pageContext 사용
* 현재 페이지 범위에서 데이터 저장 및 조회 가능

### 실제 코드

```jsp
pageContext.setAttribute("msg", "hello");
```

### 예상 출력

```text
hello
```

### 핵심 정리

* pageContext는 현재 JSP 페이지에서만 유효
* 가장 작은 범위(scope)를 가짐

---

## 6. Request 객체 복습 (`Ch07/C02Request.jsp`)

### 설명

* request 객체를 이용한 데이터 처리 복습
* 요청 정보와 파라미터 확인 실습

### 실제 코드

```jsp
String name = request.getParameter("name");
```

### 예상 출력

```text
사용자 입력값 출력
```

### 핵심 정리

* request는 클라이언트 요청 데이터를 담고 있음
* 요청 1회 동안만 유지됨

---

## 7. Response 객체 (`Ch07/C03Response.jsp`)

### 설명

* response 객체를 이용한 응답 처리
* 브라우저로 데이터 전송 및 페이지 이동 가능

### 실제 코드

```jsp
response.sendRedirect("main.jsp");
```

### 예상 출력

```text
다른 페이지로 이동
```

### 핵심 정리

* response는 서버의 응답 담당 객체
* Redirect 처리 가능

---

## 8. 파일 다운로드 처리 (`Ch07/C04Download_SingleFile.jsp`, `Ch07/C05Download_zip.jsp`)

### 설명

* 서버 파일을 사용자에게 다운로드 제공
* 단일 파일 다운로드 및 zip 다운로드 실습
* response 헤더 설정을 통해 다운로드 처리

### 실제 코드

```jsp
response.setHeader("Content-Disposition",
    "attachment; filename=file1.svg");
```

### 예상 출력

```text
브라우저에서 파일 다운로드 시작
```

### 핵심 정리

* Content-Disposition 헤더로 다운로드 처리 가능
* attachment 옵션 사용 시 저장 창 표시
