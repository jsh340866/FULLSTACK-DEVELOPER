## 1. Spring Framework 와 Spring Boot (`Spring-Intro`)

### 설명

Spring Framework 는 **IoC / DI / AOP / MVC** 를 제공하는 핵심 프레임워크.

Spring Boot 는 Spring 기반 프로젝트를 **빠르게 구성하는 도구**입니다.

### 핵심 정리

- Spring Boot ≠ Spring 대체
- Boot 내부 동작 원리 = Spring Framework

---

## 2. IoC / DI 핵심 (`Spring-Core`)

### 설명

객체 생성과 연결을 개발자가 직접 하지 않고 **Spring 컨테이너가 관리**합니다.

실무에서는 **생성자 주입**을 사용합니다.

### 실제 코드

```java
@Service
@RequiredArgsConstructor
public class OrderService {

    private final UserService userService;
}
```

### 핵심 정리

- IoC → 객체 관리 주도권을 Spring 이 담당
- DI → 필요한 객체를 외부 주입
- 실무 표준:

```java
final + @RequiredArgsConstructor
```

## 3. Bean / Spring MVC (`Spring-Container-WebMVC`)

### 설명

Bean = Spring 이 관리하는 객체.

Spring MVC 요청 흐름:

```text
Browser
 ↓
DispatcherServlet
 ↓
Controller
 ↓
View / JSON
```

### 실제 코드

```java
@Controller
public class HomeController {

    @GetMapping("/")
    public String home() {
        return "index";
    }
}
```

### 핵심 정리

- Bean 기본 스코프 = singleton
- `new` 객체는 Spring Bean 아님
- `@Controller` → View 반환
- `@RestController` → JSON 반환

## 5. Lombok 핵심 (`02_LOMBOK_DI`)

### 설명

Lombok 은 반복 코드를 자동 생성하는 라이브러리.

### 실제 코드

```java
@Getter
@Builder
@RequiredArgsConstructor
@Slf4j
```

### 핵심 정리

- `@Getter` → getter 자동 생성
- `@Builder` → Builder 패턴 생성
- `@Slf4j` → Logger 자동 생성
- `@RequiredArgsConstructor` → 생성자 DI 표준

---

## 6. Lombok REST API 실습 (`02_LOMBOK_DI`)

### 실제 코드

```java
@RestController
@RequestMapping("/students")
@Slf4j
public class StudentController {

    @GetMapping
    public List<StudentDto> getAll() {

        log.info("GET /students");

        return List.of(
            StudentDto.builder()
                .id(1L)
                .name("홍길동")
                .build()
        );
    }
}
```

### 예상 출력

```json
[
  {
    "id":1,
    "name":"홍길동"
  }
]
```

### 핵심 정리

- `@RestController` → JSON 응답
- `@Builder` → 객체 생성 단순화
- `@Slf4j` → 로그 출력 가능

## 오늘 핵심 정리

- Spring 핵심 = **IoC / DI**

- Lombok 으로 반복 코드 감소
- 실무 표준 = **final + @RequiredArgsConstructor**
