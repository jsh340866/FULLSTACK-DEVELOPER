## 1. Spring Boot 프로젝트 초기 구성 (`01_INIT`)

### 설명

Spring Boot 프로젝트의 가장 기본적인 실행 구조를 학습했다.

흐름은 다음과 같다.

**사용자 요청 → Controller → View 반환 → JSP 출력**

`@Controller`가 요청을 받고, 문자열 View 이름을 반환하면 JSP 페이지가 렌더링된다.

Spring Boot에서는 실행 시작점으로 `DemoApplication` 이 사용된다.

### 실제 코드

#### HomeController

```java
@Controller
@Slf4j
public class HomeController {

    @GetMapping("/")
    public String home() {
        log.info("GET /");
        return "index";
    }
}
```

#### View 반환

```java
return "index";
```

→ `WEB-INF/views/index.jsp` 로 연결

### 예상 출력

```txt
GET /
```

브라우저 접속 시 index.jsp 화면 출력

### 핵심 정리

- `@Controller` : 요청 처리 담당
- `@GetMapping` : GET 요청 매핑
- 문자열 반환값 = View 이름
- Controller → JSP 연결 구조 이해

## 2. Lombok + DI 구성 (`02_LOMBOK_DI`)

### 설명

반복적으로 작성하던 DTO 메서드를 Lombok으로 자동 생성하고, Spring Bean 등록 방법을 학습했다.

Bean 등록 방식은 크게 두 가지가 등장했다.

1. `@Component`
2. `@Configuration + @Bean`

Spring Container 내부에 객체를 등록하고 필요할 때 주입하는 개념(DI)을 이해하는 단계였다.

### 실제 코드

#### Lombok DTO

`02_LOMBOK_DI/src/main/java/com/example/demo/Dtos/PersonDTO.java`

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
@Builder
@Component
public class PersonDTO {
    private String name;
    private int age;
    private String addr;
}
```

#### Bean 등록

`02_LOMBOK_DI/src/main/java/com/example/demo/Config/PersonConfig.java`

```java
@Bean
public PersonDTO personBean01(){
    return PersonDTO.builder()
            .name("김범수")
            .age(50)
            .addr("인천")
            .build();
}
```

#### Component 등록

```java
@Component
public class PersonComponent {
```

### 예상 출력

Container 내부 Bean 생성

```txt
PersonDTO Bean 등록 완료
PersonComponent Bean 등록 완료
```

(실행 흐름 기준)

### 핵심 정리

- `@Data` → Getter/Setter/ToString 자동 생성
- `@Builder` → 객체 생성 간소화
- `@Component` → 클래스 자체 Bean 등록
- `@Bean` → 메서드 반환 객체 Bean 등록
- Spring DI = Container가 객체 생성/관리

## 3. 요청 파라미터 처리 (`03_PARAM`)

### 설명

사용자가 전달한 데이터를 Controller에서 받는 방법을 학습했다.

Spring MVC에서 가장 자주 사용하는 기능 중 하나인 **Parameter Binding** 중심 내용이다.

다양한 방식으로 데이터를 전달하고 처리한다.

- QueryString
- RequestParam
- DTO Binding
- Redirect
- Forward
- Model 전달

### 실제 코드

#### RequestParam 사용

`03_PARAM/src/main/java/com/example/demo/Controller/ParamController.java`

```java
@GetMapping("/p01")
public String paramHandler_1(
    @RequestParam(required = false) String name
){
    log.info("GET /param/p01.." + name);
    return "param/page01";
}
```

#### Controller 공통 URL 설정

```java
@RequestMapping("/param")
```

#### 실습 문제 Controller

`03_PARAM/src/main/java/com/example/demo/Controller/ExController.java`

```java
@RequestMapping("/ex")
```

### 예상 출력

요청

```txt
GET /param/p01?name=abc
```

콘솔

```txt
GET /param/p01..abc
```

### 핵심 정리

- `@RequestParam` → 요청 데이터 받기
- `required=false` → 필수 여부 설정
- Query Parameter → 메서드 파라미터 자동 매핑
- `@RequestMapping` → 공통 URL 설정
- Spring MVC는 파라미터 바인딩 기능 제공

## 오늘 핵심 정리

Spring Boot MVC 흐름은 기본적으로 다음 순서로 동작한다.

```txt
사용자 요청
   ↓
Controller
   ↓
파라미터 처리
   ↓
Model/View 반환
   ↓
JSP 렌더링
```

또한 Spring Container가 Bean 객체를 생성/관리하며, Lombok을 활용해 DTO 작성량을 크게 줄일 수 있다.
