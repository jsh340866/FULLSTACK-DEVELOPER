## 1. Validation(입력값 검증) (`04_DATA_VALIDATION/Controller/ExController.java`)

### 설명

Spring Boot는 DTO 필드에 **제약 조건 애너테이션**을 작성하고 Controller에서 `@Valid` 를 사용해 검증을 수행한다.

전체 흐름:

```text
요청 파라미터
↓
DTO 바인딩
↓
@Valid Validation 수행
↓
BindingResult 저장
↓
오류 검사
↓
로그 출력 / View 처리
```

---

### 실제 코드

`04_DATA_VALIDATION/Dtos/ExUserDto.java`

```java
@NotBlank(message="이름은 필수입니다.")
private String username;

@Min(
    value = 10,
    message = "10세 이상만 가입 가능합니다"
)
@Max(
    value=120,
    message="나이가 올바르지 않습니다."
)
@NotNull(message="나이를 입력해주세요.")
private int age;

@NotBlank(message="이메일은 필수입니다.")
@Email(message="이메일 형식이 올바르지 않습니다.")
private String email;

@Size(
    min=8,
    max=20,
    message="비밀번호는 8~20자여야 합니다."
)
@NotBlank(message="비밀번호를 입력해주세요.")
private String password;
```

`04_DATA_VALIDATION/Controller/ExController.java`

```java
@GetMapping("/ex01")
public void ex01(
        @Valid ExUserDto dto,
        BindingResult bindingResult
){
    log.info(
        "EX01 오류 발생여부 : "
        + bindingResult.hasErrors()
    );
}
```

---

### 예상 출력

```text
EX01 오류 발생여부 : false
```

(정상 데이터 입력 시)

```text
EX01 오류 발생여부 : true
```

(검증 실패 시)

---

### 핵심 정리

* 검증 규칙은 DTO 내부 작성
* Controller는 `@Valid` 로 검증 실행
* 결과는 `BindingResult` 저장
* `BindingResult` 는 검증 대상 객체 바로 뒤에 위치

## 2. BindingResult 오류 처리 (`04_DATA_VALIDATION/Controller/ExController.java`)

### 설명

Validation 실패 시 Spring은 오류 정보를 `BindingResult` 객체에 저장한다.

Controller는 이를 이용해 **오류 메시지 조회 / 사용자 피드백 / 화면 분기** 를 직접 처리할 수 있다.

---

### 실제 코드

```java
@GetMapping("/ex02")
public void ex02(
        @Valid ExUserDto dto,
        BindingResult bindingResult
){

    if(bindingResult.hasErrors()) {

        for(FieldError e :
                bindingResult.getFieldErrors())
        {
            log.info(
                "EX02 field : "
                + e.getField()
                + ", message : "
                + e.getDefaultMessage()
            );
        }
    }
}
```

---

### 예상 출력

```text
EX02 field : username, message : 이름은 필수입니다.
EX02 field : email, message : 이메일 형식이 올바르지 않습니다.
EX02 field : password, message : 비밀번호는 8~20자여야 합니다.
```

---

### 핵심 정리

* `hasErrors()` → 오류 존재 여부 확인
* `getFieldErrors()` → 필드별 오류 조회
* `FieldError` 로 필드명/메시지 접근 가능
* 서버 예외 없이 Controller 단에서 처리 가능

---

## 3. Exception Handling(예외 처리) (`05_EXCEPTION/Controller/ExceptionTestController.java`)

### 설명

Spring MVC 요청 처리 도중 예외가 발생하면 `ExceptionHandler` 를 통해 예외 처리 로직으로 전달된다.

프로젝트에서는:

* 파일 예외
* 산술 예외

상황을 직접 발생시키는 예제가 구성되어 있다.

---

### 실제 코드

`05_EXCEPTION/Controller/ExceptionTestController.java`

```java
@GetMapping("/ex1")
public void ex1()
        throws FileNotFoundException
{
    log.info("GET /except/ex1...");

    throw new FileNotFoundException(
        "파일을 찾을 수 없습니다."
    );
}
```

```java
@GetMapping("/ex2/{num}/{div}")
public String ex2(
        @PathVariable int num,
        @PathVariable int div,
        Model model
) throws ArithmeticException
{

    log.info(
        "GET /except/ex2..."
        + (num/div)
    );

    model.addAttribute(
        "result",
        (num/div)
    );

    return "except/ex2";
}
```

---

### 예상 흐름

```text
요청
↓
Controller 실행
↓
예외 발생
↓
ExceptionHandler 탐색
↓
Model 저장
↓
에러 View 반환
```

---

### 핵심 정리

* `throw` 로 예외 강제 발생 가능
* `ArithmeticException` 같은 런타임 예외 처리 가능
* Spring MVC 예외 처리 흐름 학습용 예제

---

## 4. 전역 예외 처리 (`05_EXCEPTION/Controller/GlobalException/GlobalExceptionHandler.java`)

### 설명

`@ControllerAdvice` 는 여러 Controller 에서 발생하는 예외를 **공통 처리**하기 위한 기능이다.

중복된 예외 처리 로직을 하나의 클래스에서 관리할 수 있다.

---

### 실제 코드

```java
@ControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    @ExceptionHandler(
        FileNotFoundException.class
    )
    public String exceptionHandler_1(
            Exception e,
            Model model)
    {

        log.error(
            "[Global] ExceptionTestController ex1 : "
            + e
        );

        model.addAttribute(
            "e",
            e
        );

        return "global/error1";
    }
```

```java
@ExceptionHandler(
    ArithmeticException.class
)
public String exceptionHandler_2(
        Exception e,
        Model model)
{

    log.error(
        "[Global] ExceptionTestController ex2 : "
        + e
    );

    model.addAttribute("e",e);

    return "global/error2";
}
```

```java
@ExceptionHandler(Exception.class)
public String exceptionHandler_All(
        Exception e,
        Model model)
{

    log.error(
        "[Global] etc exceptions : "
        + e
    );

    model.addAttribute("e",e);

    return "global/error3";
}
```

---

### 핵심 정리

* `@ControllerAdvice` → 전역 적용
* `@ExceptionHandler` → 특정 예외 매핑
* 로그 기록 + Model 전달 + View 반환 가능
* 예외 처리 코드 중복 감소

## 6. Thymeleaf 기본 데이터 출력 (`06_THYMELEAF/Controller/ThymeleafTestController.java`)

### 설명

Controller 는 Model 에 데이터를 저장하고,

Thymeleaf 는 `${}` 문법을 사용해 View 에 데이터를 출력한다.

프로젝트에서는:

* 기본 문자열
* DTO 객체
* List<DTO>
* 조건 데이터

를 모두 Model 에 저장하고 있다.

---

### 실제 코드

`06_THYMELEAF/Controller/ThymeleafTestController.java`

```java
@GetMapping("/index")
public String index(
        @RequestParam Boolean isAuth,
        Model model)
{

    model.addAttribute(
        "name",
        "HongGilDong"
    );

    model.addAttribute(
        "dto",
        new PersonDTO(
            "남길동",
            55,
            "대구"
        )
    );

    List<PersonDTO> list =
        new ArrayList<>();

    for(int i=0;i<10;i++){
        list.add(
            new PersonDTO(
                "TEST"+i,
                i,
                ""
            )
        );
    }

    model.addAttribute(
        "list",
        list
    );

    model.addAttribute(
        "isAuth",
        isAuth
    );

    return "th/index";
}
```

---

### 핵심 정리

* Controller → Model 저장
* View → `${}` 로 데이터 접근
* DTO / List / Boolean 전달 가능

## 7. Thymeleaf 반복문 / 조건문 / 링크 (`06_THYMELEAF/templates/th/index.html`)

### 설명

Thymeleaf 는 JSP 없이 HTML 기반 템플릿 엔진으로 동작하며,

반복문·조건문·링크 생성 기능을 지원한다.

---

### 실제 코드

#### 기본 데이터 출력

```html
이름 :
<span th:text="${name}">
</span>

DTO.NAME :
<span th:text="${dto.name}">
</span>

DTO.AGE :
<span th:text="${dto.age}">
</span>
```

#### 반복문

```html
<th:block
    th:each="dto:${list}">
    <div
      th:text="${dto}">
    </div>
</th:block>
```

#### 조건문

```html
<th:block th:if="${isAuth}">
    <div>인증 완료!</div>
</th:block>

<th:block th:unless="${isAuth}">
    <div>인증 실패!</div>
</th:block>
```

#### 링크 생성

```html
<a
th:href=
"@{/param/p01(name=${name})}">
th:/param/p01 이동
</a>

<a
th:href=
"@{/param/p06(
name=${dto.name},
age=${dto.age},
addr=${dto.addr}
)}">
th:/param/p06
</a>
```

#### JS 데이터 사용

```html
<script th:inline="javascript">

console.log([[ ${name} ]]);
console.log([[ ${dto} ]]);
console.log([[ ${list} ]]);

</script>
```

---

### 핵심 정리

* `th:text` → 데이터 출력
* `th:each` → 반복문
* `th:if` / `th:unless` → 조건문
* `th:href` → 동적 URL 생성
* `th:inline="javascript"` → JS 변수 연동
