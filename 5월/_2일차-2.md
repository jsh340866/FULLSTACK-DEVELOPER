## 6. ActionListener (`JAVA03/Ch05/C06SwingEventMain중요`)

### 문제

여러 버튼 클릭을 하나의 클래스에서 처리하려면 어떻게 할까?

### 코드

```java
class C06GUI extends JFrame implements ActionListener {

    btn1.addActionListener(this);

    @Override
    public void actionPerformed(ActionEvent e) {
        if(e.getSource() == btn1) {
            System.out.println("파일로 저장 버튼 클릭");
        }
    }
}
```

### 핵심 정리

-   클래스가 ActionListener 구현
-   this로 이벤트 연결
-   e.getSource()로 버튼 구분

----------
