## 1. List 기본 (JAVA03/Ch04/C01ListMain중요)

### 설명
- 순서 유지 + index 접근 가능
- 중복 허용

👉 **핵심 이유**
- “몇 번째 데이터” 접근 필요

### 실제 코드
```java
List<String> list = new ArrayList<>();

// 추가
list.add("HTML");
list.add("CSS");
list.add("JS");
list.add("JAVA");

// 조회
System.out.println("전체 개수 : " + list.size());
System.out.println("2번째 데이터 : " + list.get(1));

// 값으로 위치 찾기
System.out.println("JAVA 위치 : " + list.indexOf("JAVA"));

// 반복 출력
for(String str : list) {
    System.out.println(str);
}

// 삭제
list.remove(0);

// 전체 삭제
list.clear();

예상 출력
전체 개수 : 4
2번째 데이터 : CSS
JAVA 위치 : 3
HTML
CSS
JS
JAVA
핵심 정리
순서 + index 접근 필요 → List

4. 로또 예제 (JAVA03/Ch04/C04Ex)
설명
Set → 중복 제거
Stream → 정렬
실제 코드
Set<Integer> set = new HashSet<>();
Random random = new Random();

// 중복 없이 6개 생성
while(set.size() < 6) {
    int num = random.nextInt(45) + 1;
    set.add(num);
}

System.out.println("Set 결과 : " + set);

// 정렬
List<Integer> list = set.stream()
                        .sorted()
                        .collect(Collectors.toList());

System.out.println("정렬 결과 : " + list);
예상 출력
Set 결과 : [34, 3, 15, 22, 11, 41]
정렬 결과 : [3, 11, 15, 22, 34, 41]
핵심 정리
Set + Stream + List 조합 사용

6. Map 기본 (JAVA03/Ch04/C06MapMain중요)
설명
key-value 구조
실제 코드
Map<String, Integer> map = new HashMap<>();

// 추가
map.put("aaa", 1111);
map.put("bbb", 2222);
map.put("ccc", 3333);

// 중복 key → 덮어쓰기
map.put("aaa", 9999);

// 조회
System.out.println("aaa 값 : " + map.get("aaa"));

// 전체 출력
for(String key : map.keySet()) {
    System.out.println(key + " : " + map.get(key));
}

// 삭제
map.remove("bbb");

System.out.println("SIZE : " + map.size());
예상 출력
aaa 값 : 9999

bbb : 2222
ccc : 3333

핵심 정리
key 기반 조회 → Map
7. Map 활용 (JAVA03/Ch04/C07Ex중요)
설명
다양한 타입 저장
실제 코드
Map<String, Object> map = new HashMap<>();

map.put("이름", "홍길동");
map.put("나이", 20);
map.put("자격증", new String[]{"정보처리기사", "SQLD"});
map.put("취미", Arrays.asList("게임", "등산"));

// 출력
for(String key : map.keySet()) {
    Object value = map.get(key);

    if(value instanceof String[]) {
        String[] arr = (String[]) value;
        for(String s : arr) {
            System.out.println("배열 : " + s);
        }
    }
    else if(value instanceof List) {
        List list = (List)value;
        for(Object o : list) {
            System.out.println("리스트 : " + o);
        }
    }
    else {
        System.out.println(key + " : " + value);
    }
}
핵심 정리
Map + Object → 복합 데이터 처리
