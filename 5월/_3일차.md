## 1. 문자 출력 스트림 (`JAVA03/Ch06/C01WriterMain`)

### 설명

`FileWriter`를 이용해서 텍스트 파일에 문자열을 저장하는 예제입니다.

문자 기반 스트림이기 때문에 문자열을 직접 저장할 수 있습니다.

`true` 옵션을 사용하면 기존 파일 내용 뒤에 이어서 추가되고,
`false` 또는 생략 시 기존 내용을 덮어씁니다.

### 실제 코드

```java
Writer fout = new FileWriter("C:\\IOTEST\\test1.txt",true);

fout.write("HELLOWORLD\n");
fout.write("HELLOWORLD\n");
fout.write("HELLOWORLD\n");

fout.flush();
fout.close();
```

### 예상 출력

```txt
HELLOWORLD
HELLOWORLD
HELLOWORLD
```

(파일 내부에 저장됨)

### 핵심 정리

* `FileWriter` : 문자 파일 출력
* `true` : 이어쓰기(Append)
* `flush()` : 버퍼 내용 강제 저장
* `close()` : 스트림 종료

## 2. 문자 입력 스트림 (`JAVA03/Ch06/C02ReaderMain`)

### 설명

`FileReader`를 이용해서 파일 내용을 한 글자씩 읽는 예제입니다.

`read()`는 문자 하나를 읽어서 정수(int) 형태로 반환합니다.
파일 끝까지 읽으면 `-1`을 반환합니다.

### 실제 코드

```java
Reader fin = new FileReader("C:\\IOTEST\\test1.txt");

int data = 0;
while((data = fin.read())!=-1)
	System.out.print((char)data);

fin.close();
```

### 예상 출력

```txt
HELLOWORLD
HELLOWORLD
HELLOWORLD
```

### 핵심 정리

* `FileReader` : 문자 파일 입력
* `read()` : 한 문자 읽기
* `(char)data` 형변환 필요
* `-1` : 파일 끝 의미

## 3. 문자 기반 파일 복사 (`JAVA03/Ch06/C03FileCopyMain`)

### 설명

`FileReader`와 `FileWriter`를 이용해서 파일 내용을 복사하는 구조입니다.

원본 파일에서 한 글자씩 읽어서 대상 파일에 그대로 저장합니다.

명령행 인수(`args`)를 이용해 파일 이름을 전달받습니다.

### 실제 코드

```java
Reader fin = new FileReader(PATH + args[0]);
Writer fout = new FileWriter(PATH + args[1]);

int data = 0;
while((data = fin.read())!=-1)
{
	fout.write(data);
}

fout.flush();
fout.close();
fin.close();
```

### 예상 출력

```txt
원본 파일 내용이 복사 파일에 동일하게 저장됨
```

### 핵심 정리

* 입력 스트림 → 읽기
* 출력 스트림 → 저장
* `args[0]` : 원본 파일명
* `args[1]` : 복사 파일명
* 문자 단위 복사 가능

## 4. 버퍼(Buffer)를 이용한 파일 읽기 (`JAVA03/Ch06/C04BufferAddMain`)

### 설명

문자를 한 개씩 읽는 대신 `char[]` 배열 버퍼를 사용해서 여러 글자를 한 번에 읽는 방식입니다.

속도가 더 빨라지며 대용량 파일 처리에 효율적입니다.

`StringBuffer`를 사용해서 읽어온 문자열을 계속 누적합니다.

### 실제 코드

```java
StringBuffer strBuffer = new StringBuffer();
char [] buff = new char[4096];

while(true)
{
	int data = fin.read(buff);
	if(data == -1)
		break;

	strBuffer.append(buff);
}
```

### 예상 출력

```txt
파일 내용을 빠르게 읽어와 StringBuffer에 저장
```

### 핵심 정리

* 버퍼 사용 시 성능 향상
* `char[]` 배열에 여러 문자 저장
* `StringBuffer` : 문자열 누적
* 대용량 파일 처리에 적합

## 5. 바이트 입력 스트림 (`JAVA03/Ch06/C05FileInputStreamMain중요`)

### 설명

`FileInputStream`을 사용해서 파일을 바이트 단위로 읽는 예제입니다.

이미지, PDF, 영상 같은 바이너리 파일은 문자 스트림보다 바이트 스트림을 사용하는 것이 적절합니다.

### 실제 코드

```java
InputStream fin = new FileInputStream("C:\\IOTEST\\07장_입출력.pdf");

byte[] buffer = new byte[1024];

while(true)
{
	int data = fin.read(buffer);
	if(data == -1)
		break;
}

fin.close();
```

### 예상 출력

```txt
PDF 파일을 바이트 단위로 읽음
```

### 핵심 정리

* `InputStream` : 바이트 입력
* `byte[]` 버퍼 사용 가능
* 바이너리 파일 처리에 적합
* 문자 파일이 아닌 경우 바이트 스트림 사용

---

## 6. 바이트 출력 스트림 (`JAVA03/Ch06/C06FileOutputStreamMain중요`)

### 설명

`FileOutputStream`을 이용해서 파일에 바이트 데이터를 저장하는 예제입니다.

문자열을 저장할 때는 `getBytes()`를 이용해 바이트 배열로 변환합니다.

### 실제 코드

```java
OutputStream fout = new FileOutputStream("C:\\IOTEST\\test2.txt");

fout.write("먀댲댜쟏".getBytes(StandardCharsets.UTF_8));
fout.write('a');
fout.write('b');
fout.write('c');

fout.flush();
fout.close();
```

### 예상 출력

```txt
먀댲댜쟏abc
```

(파일 내부 저장)

### 핵심 정리

* `OutputStream` : 바이트 출력
* `getBytes()` : 문자열 → 바이트 배열 변환
* UTF-8 인코딩 사용 가능
* 문자와 바이트 모두 저장 가능

---

## 7. 바이트 기반 파일 복사 (`JAVA03/Ch06/C07FileCopyMain여기까지중요`)

### 설명

`FileInputStream`과 `FileOutputStream`을 사용한 파일 복사 예제입니다.

PDF, 이미지 같은 바이너리 파일 복사 시 사용됩니다.

### 실제 코드

```java
InputStream fin = new FileInputStream(PATH + args[0]);
OutputStream fout = new FileOutputStream(PATH + args[1]);

byte[] buffer = new byte[1024];

while(true)
{
	int data = fin.read(buffer);
	if(data == -1)
		break;

	fout.write(buffer,0,data);
}

fout.flush();
fout.close();
fin.close();
```

### 예상 출력

```txt
원본 바이너리 파일이 동일하게 복사됨
```

### 핵심 정리

* 바이트 단위 파일 복사
* `write(buffer,0,data)` 사용
* 이미지 / PDF 복사 가능
* 버퍼 사용 시 속도 향상

---

## 오늘 핵심 정리

* 문자 파일은 `Reader` / `Writer` 사용
* 바이너리 파일은 `InputStream` / `OutputStream` 사용
* `read()`의 반환값 `-1`은 파일 끝 의미
* 버퍼 배열을 사용하면 속도가 빨라짐
* `flush()` 후 `close()`로 마무리 필요
* 파일 복사는 입력 스트림 + 출력 스트림 조합으로 구현 가능
