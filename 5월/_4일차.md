## 1. 문자 변환 스트림 (`JAVA03/Ch07/C01CharConvertStreamMain`)

### 설명

바이트 스트림을 문자 스트림으로 변환하는 보조 스트림 예제입니다.

`InputStreamReader`와 `OutputStreamWriter`를 사용해서
문자 인코딩 처리를 수행합니다.

### 실제 코드

```java
OutputStream out = System.out;
OutputStreamWriter writer = new OutputStreamWriter(out);

writer.write("HELLO WORLD\n");
writer.flush();
```

### 예상 출력

```txt
HELLO WORLD
```

### 핵심 정리

* 바이트 → 문자 변환 가능
* `OutputStreamWriter` 사용
* 문자 인코딩 처리 가능
* 보조 스트림 개념 학습

## 2. BufferedReader 문자열 입력 (`JAVA03/Ch07/C02ReadLineMain`)

### 설명

`BufferedReader`를 이용해서 문자열 한 줄을 입력받는 예제입니다.

`readLine()` 메서드를 사용하면 Enter 기준으로 문자열을 읽을 수 있습니다.

### 실제 코드

```java
BufferedReader br = new BufferedReader(
	new InputStreamReader(System.in)
);

String str = br.readLine();
System.out.println(str);
```

### 예상 출력

```txt
안녕하세요
안녕하세요
```

### 핵심 정리

* `BufferedReader` : 버퍼 기반 입력
* `readLine()` : 한 줄 입력
* 콘솔 문자열 입력 처리 가능

## 3. 데이터 스트림 (`JAVA03/Ch07/C03DataInOutputStreamMain`)

### 설명

기본 자료형 데이터를 파일에 저장하고 읽는 예제입니다.

`DataOutputStream`과 `DataInputStream`을 사용합니다.

문자열, 정수, 실수 등을 자료형 그대로 저장할 수 있습니다.

### 실제 코드

```java
DataOutputStream dout = new DataOutputStream(
	new FileOutputStream("C:\\IOTEST\\data.dat")
);

dout.writeUTF("홍길동");
dout.writeInt(100);

DataInputStream din = new DataInputStream(
	new FileInputStream("C:\\IOTEST\\data.dat")
);

System.out.println(din.readUTF());
System.out.println(din.readInt());
```

### 예상 출력

```txt
홍길동
100
```

### 핵심 정리

* 기본 자료형 저장 가능
* `writeUTF()` / `readUTF()` 사용
* 자료형 유지 가능
* 입력 순서와 출력 순서 동일해야 함

## 4. 객체 스트림 (`JAVA03/Ch07/C04ObjectStreamMain`)

### 설명

객체 자체를 파일에 저장하고 읽는 예제입니다.

객체 스트림을 사용하려면 클래스가 `Serializable` 인터페이스를 구현해야 합니다.

### 실제 코드

```java
class Person implements Serializable {
	String name;
	int age;
}

ObjectOutputStream out = new ObjectOutputStream(
	new FileOutputStream("C:\\IOTEST\\obj.dat")
);

out.writeObject(new Person());
```

### 예상 출력

```txt
객체가 파일에 저장됨
```

### 핵심 정리

* 객체 단위 저장 가능
* `Serializable` 구현 필요
* 객체 직렬화 개념 학습
* 객체 상태 그대로 저장 가능
