## 1. JDBC 기본 연결(`JAVA03/Ch08/C01DBConn.java`)

### 핵심 정리

## 2. INSERT 처리(`JAVA03/Ch08/C02DBInsert.java`)

### 설명

* INSERT SQL 실행 구조 학습
* `PreparedStatement`로 값 바인딩 처리

### 실제 코드

```java
String sql = "insert into tbl_std values(?,?,?,?)";
pstmt = conn.prepareStatement(sql);
```

### 예상 출력

```text
INSERT 성공
```

### 핵심 정리

* INSERT / UPDATE / DELETE 는 `executeUpdate()` 사용
* `?` 로 SQL 값 전달 가능

## 5. SELECT 조회 처리(`JAVA03/Ch08/C05DBSelect.java`)

### 설명

* SELECT 결과를 `ResultSet`으로 조회
* 반복문으로 데이터 출력

### 실제 코드

```java
rs = pstmt.executeQuery();

while(rs.next()) {
    System.out.println(rs.getString("name"));
}
```

### 예상 출력

```text
홍길동
김철수
```

### 핵심 정리

* SELECT는 `executeQuery()` 사용
* `rs.next()`로 다음 행 접근

## 10. Transaction 처리(`JAVA03/Ch08/C08TxMainTRANSACTION.java`)

### 설명

* JDBC Transaction 처리 방식 학습
* 여러 SQL 작업을 하나의 작업 단위로 처리

### 실제 코드

```java
conn.setAutoCommit(false);
conn.commit();
conn.rollback();
```

### 예상 출력

```text
TRANSACTION SUCCESS
```

### 핵심 정리

* commit() : 작업 최종 반영
* rollback() : 작업 취소
* Transaction으로 데이터 무결성 유지 가능
