## 1. GUI 기반 1:1 채팅 서버/클라이언트 (`Ch12/ServerUI.java`, `Ch12/ClientUI.java`)

### 설명

Swing GUI와 Socket 통신을 연결하여 1:1 채팅 프로그램을 구현했습니다.

* `ServerSocket` 으로 서버 대기
* `Socket` 으로 클라이언트 연결
* `DataInputStream`, `DataOutputStream` 으로 문자열 송수신
* `JTextArea` 에 대화 출력
* `JTextField` 에 입력 후 Enter 키로 전송

GUI와 네트워크를 함께 사용하는 기본 구조를 연습한 코드입니다.

### 실제 코드

```java
// 서버 소켓 생성
ServerSocket server = new ServerSocket(9999);

// 연결 대기
Socket client = server.accept();

// 스트림 생성
InputStream in = client.getInputStream();
OutputStream out = client.getOutputStream();

// 보조 스트림
DataInputStream din = new DataInputStream(in);
DataOutputStream dout = new DataOutputStream(out);
```

```java
if (e.getKeyCode() == 10)

    dout.writeUTF(txt1.getText());

```

### 예상 출력

```text

[INFO] 접속자 IP : /192.168.x.x

[CLIENT] : 안녕하세요
[SERVER] : 반갑습니다
```

### 핵심 정리

* `ServerSocket` 은 연결 대기용
* `Socket` 은 실제 통신용
* `writeUTF()` / `readUTF()` 로 문자열 송수신 가능

## 2. 송수신 Thread 분리 (`Ch12/ClientRecvThread.java`, `Ch12/ServerRecvThread.java`)

### 설명

채팅 프로그램은 송신과 수신이 동시에 동작해야 하기 때문에 별도의 Thread를 사용했습니다.

`Runnable` 을 구현한 뒤 Thread 객체로 실행하여 계속해서 메시지를 수신합니다.

연결 종료 시 `EOFException` 으로 예외 처리도 수행했습니다.

### 실제 코드

```java
public class ClientRecvThread implements Runnable {

    @Override
    public void run() {
        String recv = null;

        while (true) {
            try {
                recv = din.readUTF();
            } catch (EOFException e) {
                System.out.println("[ERROR] 서버가 연결을 끊었습니다.");
                break;
            }

            System.out.println("[SERVER] : " + recv + "\n");
            cgui.area.append("[SERVER] : " + recv + "\n");
        }
    }
}
```

```java
ClientRecvThread recvThread = new ClientRecvThread(din,this);
Thread th1 = new Thread(recvThread);
th1.start();
```

### 예상 출력

```text
[SERVER] : 테스트 메시지
[SERVER] : 반갑습니다
```

### 핵심 정리

* 수신 대기를 위해 Thread 사용
* `Runnable` 구현 후 `Thread.start()` 실행
* 네트워크 프로그램은 대부분 멀티스레드 구조 사용
* `EOFException` 으로 연결 종료 감지 가능

## 3. 다중 채팅 서버 구현 (`Ch13/ServerBackground.java`)

### 설명

여러 명의 클라이언트를 동시에 처리하는 채팅 서버를 구현했습니다.

`Map<String, DataOutputStream>` 을 사용하여 닉네임별 출력 스트림을 저장하고,
모든 사용자에게 메시지를 전달하는 `broadCast()` 기능을 구현했습니다.

### 실제 코드

```java
Map<String,DataOutputStream> ClientList;

ClientList = new HashMap();
Collections.synchronizedMap(ClientList);
```

```java
public void broadCast(String msg) {

    for(String key : ClientList.keySet()) {
        try {
            ClientList.get(key).writeUTF(msg);
            ClientList.get(key).flush();
        }catch(Exception e) {}
    }
}
```

```java
public void addClient(String nick, DataOutputStream Dout) {
    broadCast(nick  + " 님이 접속하셨습니다");
    ClientList.put(nick, Dout);
}
```

### 예상 출력

```text
홍길동 님이 접속하셨습니다
[홍길동] : 안녕하세요
[김철수] : 반갑습니다
```

### 핵심 정리

* 여러 클라이언트 정보를 Map으로 관리 가능
* `broadcast()` 로 전체 사용자에게 메시지 전달
* 멀티 채팅은 사용자별 Thread가 필요함
* `Collections.synchronizedMap()` 으로 동기화 처리 가능

## 5. Reflection 기본 개념 (`Ch14/C00INFO.java`, `Ch14/C01Basic.java`)

### 설명

Reflection은 실행 중인 클래스 정보를 동적으로 확인하고 조작하는 기능입니다.

* 클래스 정보 확인
* 생성자 확인
* 메서드 확인
* 필드 확인

프레임워크 내부에서 자주 사용되는 중요한 기능입니다.

### 실제 코드

```java
Class<?> clazz = Class.forName("java.lang.String");
```

```java
Method [] methods = clazz.getDeclaredMethods();

for(Method m : methods) {
    System.out.println(m);
}
```

### 예상 출력

```text
public int java.lang.String.length()
public char java.lang.String.charAt(int)
```

### 핵심 정리

* `Class.forName()` 으로 클래스 로딩 가능
* Reflection으로 클래스 내부 정보 확인 가능
* Method / Field / Constructor 객체 사용

## 6. Reflection으로 객체 생성 및 메서드 호출 (`Ch14/C02Basic.java`)

### 설명

Reflection을 이용해 객체 생성, 메서드 호출, 필드 수정까지 수행했습니다.

실행 중 동적으로 객체를 만들고 기능을 호출할 수 있습니다.

### 실제 코드

```java
Class<?> clazz = Class.forName("Ch14.Simple");

Constructor con = cons[0];
Object ob2 = con.newInstance("홍길동", 30, "대구");
```

```java
Method setName = clazz.getDeclaredMethod("setName", String.class);
setName.invoke(ob1, "남길동");
```

```java
Field addr = clazz.getDeclaredField("addr");
addr.set(ob1, "창원");
```

```java
public static Object genObject(Class<?> clazz) throws Exception {

    Constructor con = clazz.getDeclaredConstructor(null);
    Object obj = con.newInstance(null);
    return obj;
}
```

### 예상 출력

```text
ob1 : Simple [name=null, age=0, addr=null]

ob2 : Simple [name=홍길동, age=30, addr=대구]

setName ob1 : Simple [name=남길동, age=0, addr=null]

ob1 : Simple [name=남길동, age=0, addr=창원]
```

### 핵심 정리

* Reflection으로 객체 생성 가능
* `invoke()` 로 메서드 실행 가능
* `Field.set()` 으로 필드값 변경 가능
* 실행 중 동적 객체 제어 가능
