## 1. 람다식 기본 사용(`Ch16/C01Lamda중요.java`)

### 설명

* `List<Person>` 객체를 생성한 뒤 람다식을 사용해 정렬 수행
* `forEach()` 와 `System.out::println` 조합 사용
* `sort()` 안에서 `(a,b)->a.getAge()-b.getAge()` 형태로 나이 오름차순 정렬
* 람다식은 인터페이스의 추상 메서드를 간단하게 구현하기 위한 문법

### 실제 코드

```java
list.sort((a,b)->{return a.getAge() - b.getAge();});
list.forEach(System.out::println);
```

### 예상 출력

```text
Person [name=서길동, age=35, addr=울산]
Person [name=남길동, age=45, addr=창원]
Person [name=홍길동, age=55, addr=대구]
```

### 핵심 정리

* `forEach()` : 반복 처리
* `sort()` : 정렬 처리
* `System.out::println` : 메서드 참조 표현식
* `a-b` : 오름차순 정렬

## 2. 함수형 인터페이스와 람다식(`Ch16/C02Lamda중요.java`)

### 설명

* 인터페이스에 추상 메서드가 하나만 존재하면 람다식 사용 가능
* 반환값이 있는 람다식 구현 예제
* `Printer` 인터페이스의 `print()` 메서드를 람다식으로 구현

### 실제 코드

```java
Printer printer = (name)->{return "02 " + name;};
String str2 = printer.print("HELLO WORLD");
System.out.println(str2);
```

### 예상 출력

```text
02 HELLO WORLD
```

### 핵심 정리

* 함수형 인터페이스 : 추상 메서드 1개만 존재
* 람다식은 익명 객체를 간단하게 표현한 형태
* 반환값이 있으면 `return` 사용 가능

## 3. 계산기 람다식 구현(`Ch16/C03Ex.java`)

### 설명

* `Calculator` 함수형 인터페이스 생성
* 덧셈, 뺄셈, 곱셈, 나눗셈 기능을 각각 람다식으로 구현
* 하나의 인터페이스를 여러 기능으로 재사용 가능

### 실제 코드

```java
Calculator add = (n1,n2)->{return n1 + n2;};
Calculator sub = (n1,n2)->{return (n1>n2)?n1-n2:n2-n1;};
Calculator mul = (n1,n2)->{return n1 * n2;};
Calculator div = (n1,n2)->{return n1 / n2;};
```

### 예상 출력

```text
30
20
200
20
```

### 핵심 정리

* 같은 인터페이스로 여러 동작 구현 가능
* 람다식은 코드 재사용성과 가독성을 높여줌
* 삼항 연산자와 함께 사용 가능

## 5. 클로저 기본 개념(`Ch16/C05ClosureBasic.java`)

### 설명

* 람다식이 외부 변수를 기억하는 구조를 클로저라고 함
* 람다 내부에서 사용하는 외부 변수는 사실상 final 상태
* 메서드 종료 후에도 외부 변수 값을 유지 가능

### 실제 코드

```java
String str = "Hello?";
Greeter t1 = ()->{return str;};

int n = 100;
Greeter t2 = ()->{return "2. " + n;};
```

### 예상 출력

```text
1. Hello?
2. 100
Closure : hihi
Closure : hello hello
```

* `t1`, `t2`, `t3`, `t4` 호출 순서대로 출력됨

### 핵심 정리

* 클로저 : 외부 변수 값을 기억하는 함수
* 람다 내부에서 사용하는 지역 변수는 변경 불가(final)
* 함수가 끝나도 값 유지 가능

* 배열/객체 내부 값은 변경 가능

## 8. Stream API 활용(`Ch17/C01StreamMain.java`)

### 설명

* `filter()` 로 조건 필터링
* `map()` 으로 데이터 변환
* `sorted()` 로 정렬
* `collect()` 로 리스트 재생성
* `Person` 객체를 `Employee` 객체로 변환
* 메서드 참조 `Person::getAge` 사용

### 실제 코드

```java
List<Integer> li2 = li1.stream()
                       .filter((n)->{return n%2==0;})
                       .collect(Collectors.toList());

List<Integer> li3 = li1.stream()
                       .filter((n)->{return n%2==1;})
                       .map((n)->{return n*n;})
                       .collect(Collectors.toList());
```

```java
persons.stream()
       .sorted((a,b)->{return b.getAge()-a.getAge();})
       .forEach((e)->{System.out.println(e);});
```

```java
List<Employee> employees = persons.stream()
                                  .map((person)->{return new Employee(person);})
                                  .collect(Collectors.toList());
```

### 예상 출력

```text
li1 : [1, 2, 3, 4, 5]
li2 : [2, 4]
li3 : [1, 9, 25]

Person [name=남길동, age=55]
Person [name=유재석, age=53]
Person [name=홍길동, age=45]
...

[45, 55, 35, 53, 32, 27]
이름 길이 : [3, 3, 3, 3, 3, 3]

Employee 변환 :
Employee [department=인턴, role=-, name=홍길동, age=45]
Employee [department=인턴, role=-, name=남길동, age=55]
...
```

### 핵심 정리

* `filter()` : 조건에 맞는 데이터만 선택
* `map()` : 데이터 변환
* `sorted()` : 정렬 처리
* `collect()` : 결과를 컬렉션으로 반환
* 객체 -> 객체 변환도 가능
