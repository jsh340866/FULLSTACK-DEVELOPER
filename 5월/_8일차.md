## 3. 람다 + Stream 기반 계산기 구현 (`Ch18/C02Ex.java`)

### 설명

* 사칙연산을 함수형 인터페이스로 구현
* Stream reduce를 이용해 합/차/곱/나눗셈 처리
* sorted()를 이용한 내림차순 정렬 후 계산

### 실제 코드

```java
sub = arr->Arrays.stream(arr)
                 .boxed()
                 .sorted((a,b)->(b-a))
                 .reduce((sub,item)->sub-item)
                 .orElse(0);
```

### 예상 출력

```text
합	 : 210
차	 : 2
곱	 : 720000000
나눗셈	 : 0
```

### 핵심 정리

* boxed()는 기본형 int를 Integer 객체형으로 변환함
* reduce()는 누적 계산용 메서드
* orElse()는 값이 없을 때 기본값 반환

## 7. 애노테이션 기본 개념 (`Ch19/C00INFO.java`)

### 설명
- Annotation(애노테이션)은 코드에 추가 정보를 붙이는 메타데이터 기능
- 컴파일러나 프레임워크가 특정 동작을 수행할 수 있도록 정보를 제공함
- 클래스, 메서드, 필드 등에 부착 가능
- Reflection과 함께 사용하면 실행 중 애노테이션 정보를 읽을 수 있음

### 실제 코드
```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
public @interface TestAnnotation {

}
```

### 예상 출력
```text
실행 결과 없음
(애노테이션 개념 학습용 코드)
```

### 핵심 정리
- @Target : 애노테이션 사용 위치 지정
- @Retention : 애노테이션 유지 범위 지정
- RUNTIME 설정 시 Reflection으로 읽기 가능
- Spring 같은 프레임워크에서 많이 사용됨

## 8. 사용자 정의 애노테이션 생성 (`Ch19/C01CustomAnnotation.java`)

### 설명

* @interface로 커스텀 애노테이션 생성
* @Retention / @Target 사용
* 기본값 설정

### 실제 코드

```java
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE,ElementType.METHOD})
public @interface C02CustomAnnotation {
    String value() default "HELLO WORLD";
}
```

### 핵심 정리

* RetentionPolicy.RUNTIME 설정 시 실행 중 애노테이션 유지
* Target으로 적용 위치 제한 가능
