## 1. 추상 클래스 Unit 설계 (Ch20/unit/Unit.java)

### 설명

* 모든 유닛의 공통 속성(HP, 방어력, 타입)을 관리하기 위한 부모 클래스입니다.
* move(), underAttack() 메서드는 자식 클래스마다 동작이 다르므로 abstract 로 선언되었습니다.
* Marine, Medic 클래스가 Unit 을 상속받아 사용합니다.

### 실제 코드

```java
public abstract class Unit {
	int hp;
	int amor;
	String type;
	public boolean isDead;
	
	abstract public void move();
	abstract public void underAttack(int damage);
}
```

### 예상 출력

```text
(추상 클래스이므로 직접 실행 출력 없음)
```

### 핵심 정리

* 공통 속성은 부모 클래스에 작성
* 공통 기능 구조만 만들고 실제 동작은 자식 클래스에서 구현
* 클래스 다이어그램에서 부모 역할 담당

## 2. Marine 클래스와 공격 시스템 (Ch20/unit/Marine.java)

### 설명

* Marine 은 Unit 을 상속받는 해병 클래스입니다.
* 기본 공격 또는 총기 공격을 선택할 수 있습니다.
* Gun 객체를 포함하고 있어 Has-A 관계를 구성합니다.
* 공격 시 상대 유닛의 HP 와 방어력이 감소합니다.

### 실제 코드

```java
public void attack(Unit unit) {
	if(!unit.isDead) {
		
		if(this.attackMethod==this.총기사용)
			myGun.fire(unit);
		else
			unit.underAttack(this.base_damage);
		
	}
}
```

### 예상 출력

```text
[정보] 해병 에게 10 만큼 피해를 입혔습니다.
```

* Marine 은 Unit 을 상속받음
* Gun 객체를 내부에 포함하여 무기 사용 가능
* 객체 간 포함 관계를 클래스 다이어그램으로 표현 가능

## 3. Medic 클래스와 회복 기능 (Ch20/unit/Medic.java)

### 설명

* Medic 는 Unit 을 상속받는 의무병 클래스입니다.

* setHealingPoint() 메서드를 통해 대상 유닛을 치료합니다.

## 6. Main_01 실행 흐름과 Thread 사용 (Ch20/Main_01.java)

### 설명

* Marine 과 Medic 객체를 생성하고 서로 공격/회복을 수행합니다.
* Thread 를 사용해 여러 동작이 동시에 실행됩니다.
* marine1 ↔ marine2 는 서로 공격하고 medic1 은 marine1 을 지속 회복합니다.

### 실제 코드

```java
new Thread() {
	@Override
	public void run() {
		while(true) {
			marine1.attack(marine2);
			try {
				Thread.sleep(1000);
			} catch (InterruptedException e) {
				e.printStackTrace();
			}
		}
	}		
}.start();
```

### 예상 출력

```text
[정보] 재장전 완료
[정보] marine2 에게 10 만큼 피해를 입혔습니다.
대상 marine1 HP 를 회복시킵니다. 현재 HP : 120
```

### 핵심 정리

* Thread 를 사용해 동시 동작 구현
* 객체 간 상호작용 흐름 이해 가능
* 클래스 다이어그램과 실제 객체 동작 연결 학습
