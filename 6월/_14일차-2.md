## 1. OAuth2 로그인 시작 (`Config/SecurityConfig.java`)

### 설명

Spring Security에서 OAuth2 로그인을 사용하도록 설정합니다.

OAuth 로그인 성공 시 사용자 정보를 처리할 서비스를 등록합니다.

전체 흐름은 다음과 같습니다.

```text
카카오 로그인 버튼 클릭
 ↓
카카오 로그인
 ↓
인증 성공
 ↓
PrincipalDetailsOauth2Service 호출
```

---

### 실제 코드

```java
http.oauth2Login((oauth2)->{
    oauth2.loginPage("/login");

    oauth2.userInfoEndpoint((endpoint)->{
        endpoint.userService(
                principalDetailsOauth2Service
        );
    });
});
```

---

### 코드 설명

#### oauth2Login()

```java
http.oauth2Login(...)
```

Spring Security에게

```text
OAuth2 로그인 사용
```

을 설정합니다.

---

#### loginPage()

```java
oauth2.loginPage("/login");
```

OAuth 로그인 버튼이 존재하는 페이지를 지정합니다.

```text
/login
 └─ 카카오 로그인
```

---

#### userService()

```java
endpoint.userService(
        principalDetailsOauth2Service
);
```

OAuth 인증 성공 후

```java
PrincipalDetailsOauth2Service
```

를 실행하도록 등록합니다.

---

### 핵심 정리

- OAuth 로그인 시작점
- 인증 성공 후 사용자 정보 처리 서비스 연결

---

## 2. OAuth 사용자 정보 조회 (`PrincipalDetailsOauth2Service.java`)

### 설명

OAuth 인증 성공 후 가장 먼저 실행되는 클래스입니다.

카카오 서버에서 사용자 정보를 조회합니다.

---

### 실제 코드

```java
OAuth2User oauth2User =
        super.loadUser(userRequest);
```

---

### 코드 설명

이 한 줄이 실제로는

```text
카카오 서버 요청
 ↓
사용자 정보 조회
 ↓
응답 수신
```

과정을 수행합니다.

예시 응답

```json
{
  "id":"123456",
  "email":"test@kakao.com"
}
```

---

### 핵심 정리

- OAuth 사용자 정보 조회
- 카카오 API 호출 역할 수행

---

## 3. 응답 데이터 추출 (`PrincipalDetailsOauth2Service.java`)

### 설명

카카오가 전달한 사용자 정보를 꺼냅니다.

---

### 실제 코드

```java
Map<String,Object> attributes =
        oauth2User.getAttributes();
```

---

### 코드 설명

OAuth 응답 데이터를 Map 형태로 저장합니다.

예시

```json
{
  "id":"123456",
  "email":"test@kakao.com"
}
```

↓

```java
attributes.get("id");
attributes.get("email");
```

사용 가능

---

### 핵심 정리

- OAuth 응답 데이터 저장
- 사용자 정보 추출 가능

## 5. OAuth 사용자 아이디 생성 (`PrincipalDetailsOauth2Service.java`)

### 설명

OAuth 사용자는 직접 아이디를 입력하지 않습니다.

따라서 시스템에서 고유 아이디를 생성합니다.

---

### 실제 코드

```java
String username =
        oauth2UserInfo.getProvider()
        +"_"
        +oauth2UserInfo.getProviderId();
```

---

### 예상 결과

```text
kakao_123456
```

---

### 코드 설명

카카오 사용자 고유번호를 이용해

```text
provider_providerId
```

형태의 아이디를 생성합니다.

---

### 핵심 정리

- OAuth 사용자 식별용 아이디 생성
- 중복 방지 가능

---

## 6. 회원 존재 여부 확인 (`PrincipalDetailsOauth2Service.java`)

### 설명

이미 가입된 회원인지 조회합니다.

---

### 실제 코드

```java
User user =
        userRepository
                .findById(username)
                .orElse(null);
```

---

### 흐름

```text
username 조회
 ↓
회원 존재
 ↓
로그인
```

또는

```text
username 조회
 ↓
회원 없음
 ↓
회원가입
```

---

### 핵심 정리

- 기존 회원 확인
- 자동 회원가입 여부 결정

---

## 7. 자동 회원가입 (`PrincipalDetailsOauth2Service.java`)

### 설명

최초 로그인 시 자동으로 회원을 생성합니다.

---

### 실제 코드

```java
if(user == null){

    User newUser =
            User.builder()
                    .username(username)
                    .email(
                        oauth2UserInfo.getEmail()
                    )
                    .role("ROLE_USER")
                    .build();

    userRepository.save(newUser);
}
```

---

### 코드 설명

회원이 없으면

```text
OAuth 로그인
 ↓
회원 생성
 ↓
DB 저장
```

과정을 수행합니다.

---

### 핵심 정리

- 최초 로그인 = 회원가입
- 이후 로그인 = 기존 회원 사용

---

## 8. PrincipalDetails 생성 (`PrincipalDetailsOauth2Service.java`)

### 설명

OAuth 사용자 정보를 Spring Security 인증 객체로 변환합니다.

---

### 실제 코드

```java
return new PrincipalDetails(userDTO);
```

---

### 코드 설명

일반 로그인

```text
User
 ↓
PrincipalDetails
```

OAuth 로그인

```text
카카오 사용자 정보
 ↓
User 생성
 ↓
PrincipalDetails
```

최종 결과는 동일합니다.

---

### 핵심 정리

- Security가 이해할 수 있는 객체 생성
- 인증 완료를 위한 마지막 단계

---

## 한 줄 요약

> OAuth2 로그인은 카카오가 인증을 대신 수행하고, PrincipalDetailsOauth2Service가 사용자 정보를 받아 회원 조회 및 자동 회원가입을 수행한 뒤 PrincipalDetails로 변환하여 Spring Security 인증을 완료하는 구조이다.
