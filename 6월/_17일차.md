## 1. Node.js 개발 환경 이해 (`NodeJS`)

### 설명

Node.js는 브라우저 밖에서도 JavaScript를 실행할 수 있도록 만들어진 런타임 환경입니다.

기존 JavaScript는 브라우저에서만 동작했지만 Node.js를 사용하면 서버 개발, 빌드 도구 실행, 패키지 관리 등을 수행할 수 있습니다.

SCSS 역시 브라우저가 직접 해석하지 못하기 때문에 Node.js 환경에서 컴파일 작업을 수행하게 됩니다.

개발 흐름

```text
SCSS 작성
↓
Node.js 실행
↓
Sass 컴파일
↓
CSS 생성
↓
브라우저 적용
```

### 실제 코드

```bash
npm install -g sass
```

- sass 패키지 설치

```bash
sass 01.scss 01.css
```

- SCSS를 CSS로 변환

### 예상 출력

```text
01.scss
↓
컴파일
↓
01.css 생성
```

### 핵심 정리

- Node.js는 JavaScript 실행 환경이다.
- npm을 통해 다양한 개발 도구를 설치할 수 있다.
- SCSS는 Node.js 환경에서 CSS로 변환된다.

## 2. CSS와 SCSS의 차이점 (`SCSS`)

### 설명

CSS는 스타일을 작성하는 표준 언어입니다.

하지만 프로젝트 규모가 커질수록 코드 중복이 많아지고 관리가 어려워집니다.

SCSS는 CSS의 확장 문법으로 변수, 중첩, 함수, 반복문 등을 제공하여 유지보수성을 높여줍니다.

### 실제 코드

CSS

```css
.container ul li.name {
    color: green;
}

.container ul li.age {
    background-color: orange;
}
```

SCSS

```scss
.container {
    ul {
        li {
            &.name {
                color: green;
            }

            &.age {
                background-color: orange;
            }
        }
    }
}
```

### 예상 출력

```text
SCSS 작성
↓
컴파일
↓
기존 CSS 형태로 변환
```

### 핵심 정리

- CSS는 브라우저가 직접 해석한다.
- SCSS는 CSS를 더 편리하게 작성하기 위한 전처리기이다.
- 최종적으로는 CSS로 변환되어 동작한다.

## 3. SCSS 중첩(Nesting) 문법 (`01/01.scss`)

### 설명

SCSS의 대표적인 기능은 중첩(Nesting)입니다.

HTML 구조와 비슷하게 작성할 수 있어 가독성이 좋아집니다.

기존 CSS는 선택자를 반복 작성해야 하지만 SCSS는 부모-자식 관계를 그대로 표현할 수 있습니다.

### 실제 코드

```scss
.container {
    ul {
        li {
            color: red;
        }
    }
}
```

컴파일 결과

```css
.container ul li {
    color: red;
}
```

### 예상 출력

```text
li 태그 글자색 → red
```

### 핵심 정리

- HTML 구조를 그대로 표현할 수 있다.
- 선택자 중복을 줄일 수 있다.
- 유지보수가 쉬워진다.

---

## 4. 부모 선택자(&) 활용 (`01/01.scss`)

### 설명

`&`는 현재 선택자를 의미합니다.

클래스를 조합하거나 BEM 방식의 네이밍을 만들 때 자주 사용합니다.

### 실제 코드

```scss
.fs {
    &-small {
        font-size: 0.5rem;
    }

    &-medium {
        font-size: 1rem;
    }

    &-large {
        font-size: 2rem;
    }
}
```

컴파일 결과

```css
.fs-small {
    font-size: 0.5rem;
}

.fs-medium {
    font-size: 1rem;
}

.fs-large {
    font-size: 2rem;
}
```

### 예상 출력

```text
.fs-small
.fs-medium
.fs-large
클래스 생성
```

### 핵심 정리

- `&`는 현재 선택자를 의미한다.
- 클래스 조합에 매우 유용하다.
- BEM 스타일 작성에 자주 사용된다.

## 5. SCSS 변수(Variable) 사용 (`02/02.scss`)

### 설명

SCSS는 변수 기능을 제공합니다.

반복적으로 사용하는 값을 변수로 관리하여 수정 비용을 줄일 수 있습니다.

### 실제 코드

```scss
$size: 200px;

.container {
    width: $size;
    height: $size;
}
```

컴파일 결과

```css
.container {
    width: 200px;
    height: 200px;
}
```

### 예상 출력

```text
width : 200px
height : 200px
```

### 핵심 정리

- `$` 기호로 변수를 선언한다.
- 값을 한 곳에서 관리할 수 있다.
- 유지보수성이 향상된다.

---

## 6. 전역 변수와 지역 변수 (`02/02.scss`)

### 설명

SCSS 변수는 선언 위치에 따라 사용 범위가 달라집니다.

전역 변수는 모든 영역에서 사용할 수 있고, 지역 변수는 해당 블록 내부에서만 사용할 수 있습니다.

### 실제 코드

```scss
$size: 200px;

.container {
    $localSize: 100px;

    .item {
        width: $size;
        height: $localSize;
    }
}
```

### 예상 출력

```text
width : 200px
height : 100px
```

### 핵심 정리

- 전역 변수는 프로젝트 전체에서 사용 가능
- 지역 변수는 특정 블록 내부에서만 사용 가능
- 변수 범위를 이해해야 오류를 줄일 수 있다.
