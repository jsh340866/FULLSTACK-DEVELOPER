## 1. Node.js 개발 환경 이해 (`NodeJS`)

### 설명

Node.js는 브라우저 밖에서도 JavaScript를 실행할 수 있도록 만든 런타임 환경입니다.

기존 JavaScript는 브라우저에서만 동작했지만 Node.js를 사용하면 서버 개발, 빌드 도구 실행, 패키지 관리 등의 작업을 수행할 수 있습니다.

SCSS 역시 브라우저가 직접 해석할 수 없기 때문에 Node.js 환경에서 CSS로 컴파일하는 과정을 거쳐야 합니다.

전체 흐름

```text
SCSS 작성
↓
Node.js 실행
↓
Sass 컴파일
↓
CSS 생성
↓
브라우저 적용
```

### 실제 코드

```bash
node -v
npm -v
```

- Node.js 및 npm 설치 확인

### 예상 출력

```text
v22.x.x
10.x.x
```

### 핵심 정리

- Node.js는 JavaScript 실행 환경이다.
- npm을 통해 다양한 패키지를 설치할 수 있다.
- SCSS 컴파일을 위해 Node.js 환경이 필요하다.

## 2. npm 프로젝트 생성 및 패키지 설치 (`package.json`)

### 설명

Node.js 프로젝트를 시작하기 위해 npm 프로젝트를 생성하고 SCSS 개발에 필요한 패키지를 설치하였습니다.

npm은 Node Package Manager의 약자로 프로젝트에서 사용하는 라이브러리와 개발 도구를 관리합니다.

### 실제 코드

프로젝트 초기화

```bash
npm init -y
```

- package.json 자동 생성
- 프로젝트 정보 관리

Sass 설치

```bash
npm install sass --save-dev
```

- SCSS → CSS 컴파일러 설치
- 개발 환경 전용 패키지

Nodemon 설치

```bash
npm install -g nodemon
```

- 파일 변경 시 자동 재실행

Parcel Bundler 설치

```bash
npm install parcel-bundler -D
```

- HTML, CSS, JS 자동 빌드
- 프론트엔드 개발 환경 구성

### 예상 출력

```text
package.json 생성

node_modules 생성

sass 설치 완료
nodemon 설치 완료
parcel-bundler 설치 완료
```

### 핵심 정리

- npm init -y : 프로젝트 초기화
- sass : SCSS 컴파일러
- nodemon : 자동 재실행 도구
- parcel-bundler : 프론트엔드 번들링 도구
- package.json : 프로젝트 설정 파일

## 3. CSS와 SCSS의 차이점 (`SCSS`)

### 설명

CSS는 브라우저가 직접 해석하는 스타일 언어입니다.

하지만 프로젝트 규모가 커질수록 코드 중복이 많아지고 유지보수가 어려워집니다.

SCSS는 CSS의 확장 문법으로 변수, 중첩, 함수, 반복문 등의 기능을 제공하여 생산성과 유지보수성을 높여줍니다.

### 실제 코드

CSS

```css
.container ul li.name {
    color: green;
}

.container ul li.age {
    background-color: orange;
}
```

SCSS

```scss
.container {
    ul {
        li {
            &.name {
                color: green;
            }

            &.age {
                background-color: orange;
            }
        }
    }
}
```

### 예상 출력

```text
SCSS 작성
↓
컴파일
↓
CSS 생성
```

### 핵심 정리

- CSS는 브라우저가 직접 해석한다.
- SCSS는 CSS를 편리하게 작성하기 위한 전처리기이다.
- SCSS는 최종적으로 CSS로 변환된다.

## 4. SCSS 중첩(Nesting) 문법 (`01/01.scss`)

### 설명

중첩(Nesting)은 SCSS의 대표적인 기능입니다.

HTML 구조와 비슷한 형태로 스타일을 작성할 수 있어 가독성이 향상됩니다.

CSS에서 반복되던 선택자 작성이 줄어들어 유지보수가 쉬워집니다.

### 실제 코드

```scss
.container {
    ul {
        li {
            color: red;
        }
    }
}
```

컴파일 결과

```css
.container ul li {
    color: red;
}
```

### 예상 출력

```text
li 태그 글자색 → red
```

### 핵심 정리

- HTML 구조를 그대로 표현할 수 있다.
- 선택자 중복을 줄일 수 있다.
- 가독성과 유지보수성이 향상된다.

## 5. 부모 선택자(&) 활용 (`01/01.scss`)

### 설명

`&`는 현재 선택자를 의미합니다.

클래스 조합이나 BEM(Block Element Modifier) 방식의 네이밍을 만들 때 자주 사용됩니다.

### 실제 코드

```scss
.fs {
    &-small {
        font-size: 0.5rem;
    }

    &-medium {
        font-size: 1rem;
    }

    &-large {
        font-size: 2rem;
    }
}
```

컴파일 결과

```css
.fs-small {
    font-size: 0.5rem;
}

.fs-medium {
    font-size: 1rem;
}

.fs-large {
    font-size: 2rem;
}
```

### 예상 출력

```text
.fs-small
.fs-medium
.fs-large
클래스 생성
```

### 핵심 정리

- `&`는 현재 선택자를 의미한다.
- 클래스 조합을 쉽게 만들 수 있다.
- BEM 스타일 작성에 활용된다.

## 6. SCSS 변수(Variable) 사용 (`02/02.scss`)

### 설명

SCSS는 변수 기능을 제공합니다.

반복적으로 사용하는 값을 변수로 관리하여 수정 비용을 줄일 수 있습니다.

### 실제 코드

```scss
$size: 200px;

.container {
    width: $size;
    height: $size;
}
```

컴파일 결과

```css
.container {
    width: 200px;
    height: 200px;
}
```

### 예상 출력

```text
width : 200px
height : 200px
```

### 핵심 정리

- `$` 기호로 변수를 선언한다.
- 값을 재사용할 수 있다.
- 유지보수성이 향상된다.

---

## 7. 전역 변수와 지역 변수 (`02/02.scss`)

### 설명

SCSS 변수는 선언 위치에 따라 사용 범위가 달라집니다.

전역 변수는 프로젝트 전체에서 사용할 수 있으며, 지역 변수는 특정 블록 내부에서만 사용할 수 있습니다.

### 실제 코드

```scss
$size: 200px;

.container {
    $localSize: 100px;

    .item {
        width: $size;
        height: $localSize;
    }
}
```

### 예상 출력

```text
width : 200px
height : 100px
```

### 핵심 정리

- 전역 변수는 모든 영역에서 사용 가능
- 지역 변수는 선언된 블록 내부에서만 사용 가능
- 변수 범위를 이해해야 오류를 줄일 수 있다.
