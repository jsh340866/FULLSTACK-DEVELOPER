# 오늘 배운 것

React에서 화면을 구성하는 기본 단위인 컴포넌트 작성 방법과 JSX 문법을 학습하였다.

또한 Props를 이용한 데이터 전달, 이벤트 처리 방식, useState를 이용한 상태 관리, useEffect를 이용한 생명주기 처리 방법을 실습하였다.

React는 HTML을 단순히 출력하는 것이 아니라 상태(State)가 변경되면 화면을 자동으로 다시 그려주는(Rendering) 방식으로 동작한다는 점을 이해하였다.

---

## 1. JSX 문법 (`02/src/02JSX`)

### 설명

JSX(JavaScript XML)는 JavaScript 코드 안에서 HTML 형태의 UI를 작성하기 위한 문법이다.

React에서는 HTML 파일을 따로 작성하지 않고 JSX를 이용하여 화면을 구성한다.

JSX를 사용하는 이유는 UI를 JavaScript 코드와 함께 관리할 수 있기 때문이다.

---

### 실제 코드

```jsx
function App() {
    return (
        <div>
            <h1>Hello React</h1>
        </div>
    );
}
```

---

### 예상 출력

```text
Hello React
```

---

### 핵심 정리

- React 화면은 JSX로 작성
- HTML처럼 보이지만 JavaScript 문법
- return 내부에 화면 구성
- React Component는 JSX를 반환

---

## 2. 컴포넌트(Component) 생성 (`02/src/02JSX/CustomComponent.jsx`)

### 설명

React는 화면을 작은 부품(Component) 단위로 나누어 개발한다.

컴포넌트를 사용하는 이유는 재사용성과 유지보수성을 높이기 위해서이다.

한 번 만들어 놓으면 여러 화면에서 동일하게 사용할 수 있다.

---

### 실제 코드

```jsx
function MyComponent() {
    return <h1>안녕하세요</h1>;
}
```

사용

```jsx
<MyComponent />
```

---

### 예상 출력

```text
안녕하세요
```

---

### 핵심 정리

- 화면을 기능별로 분리
- 재사용 가능
- 함수 하나가 컴포넌트 역할 수행
- JSX 반환 필수

---

## 3. Props 사용 (`02/src/02JSX/CustomComponent.jsx`)

### 설명

Props는 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하기 위한 객체이다.

컴포넌트를 재사용하면서도 각각 다른 데이터를 표시하기 위해 사용한다.

---

### 실제 코드

```jsx
function User(props){
    return <h2>{props.name}</h2>;
}
```

사용

```jsx
<User name="홍길동"/>
<User name="김철수"/>
```

---

### 예상 출력

```text
홍길동
김철수
```

---

### 핵심 정리

- 부모 → 자식 데이터 전달
- 읽기 전용
- 컴포넌트 재사용 가능
- HTML 속성처럼 전달

---

## 4. 구조분해 할당 Props (`02/src/02JSX/01_Basic.jsx`)

### 설명

Props 객체에서 필요한 값만 꺼내 사용하기 위해 구조분해 할당을 사용한다.

props.name 대신 name만 사용할 수 있어 코드가 간결해진다.

---

### 실제 코드

```jsx
export function Element4({auth,name}) {

    if(auth === "ROLE_ADMIN"){
        return (
            <h2>
                관리자님 환영합니다.
                NAME = {name}
            </h2>
        );
    }
}
```

---

### 예상 출력

```text
관리자님 환영합니다.
NAME = 관리자
```

---

### 핵심 정리

- props 객체 분해
- 코드 가독성 향상
- 자주 사용되는 React 문법

---

## 6. 리스트 출력 map() (`02/src/02JSX`)

### 설명

React에서 배열 데이터를 화면에 반복 출력할 때 사용한다.

for문보다 map() 사용이 일반적이다.

---

### 실제 코드

```jsx
const names = ["김철수","이영희","홍길동"];

return (
    <>
        {names.map(name =>
            <h3>{name}</h3>
        )}
    </>
);
```

---

### 예상 출력

```text
김철수
이영희
홍길동
```

---

### 핵심 정리

- 배열 반복 출력
- React 표준 반복 방식
- 게시판 목록 구현 시 활용

## 7. 이벤트 처리 (`04/src/04Event`)

### 설명

사용자의 클릭, 입력, 마우스 이동 등을 처리하기 위해 사용한다.

HTML의 onclick과 비슷하지만 React에서는 camelCase 방식으로 작성한다.

---

### 실제 코드

```jsx
function handleClick(){
    console.log("클릭");
}

<button onClick={handleClick}>
    버튼
</button>
```

---

### 예상 출력

```text
클릭
```

---

### 핵심 정리

- 사용자 행동 감지
- camelCase 사용
- 함수 참조 형태로 전달

## 8. useState (`03/src/03Component/MyComponent.jsx`)

### 설명

React에서 값이 변경될 때 화면을 다시 렌더링하기 위해 사용한다.

일반 변수는 값이 변경되어도 화면이 바뀌지 않지만 State는 변경 시 자동 렌더링된다.

---

### 실제 코드

```jsx
const [count, setCount] = useState(1);
```

버튼 클릭

```jsx
setCount(count + 1);
```

---

### 예상 출력

```text
1
2
3
4
...
```

---

### 핵심 정리

- React 상태 저장소
- 값 변경 시 자동 렌더링
- 가장 많이 사용하는 Hook

---

## 9. useEffect 초기 실행 (`03/src/03Component/MyComponent.jsx`)

### 설명

컴포넌트가 처음 생성될 때 실행되는 코드를 작성하기 위해 사용한다.

주로 API 호출이나 초기 데이터 설정에 사용된다.

---

### 실제 코드

```jsx
useEffect(()=>{
    console.log("init setting");
},[]);
```

---

### 예상 출력

```text
init setting
```

(최초 1회만 실행)

---

### 핵심 정리

- 컴포넌트 생성 시 실행
- API 호출 시 자주 사용
- 빈 배열 사용

---

## 10. useEffect 상태 감지 (`03/src/03Component/MyComponent.jsx`)

### 설명

특정 State 값이 변경될 때만 실행되는 기능이다.

값 변화 감시 기능이라고 생각하면 된다.

---

### 실제 코드

```jsx
useEffect(()=>{
    console.log("count changed");
},[count]);
```

---

### 예상 출력

```text
count changed
```

(count 변경 시마다 실행)

---

### 핵심 정리

- 특정 State 감시
- 값 변경 시 자동 실행
- 사이드 이펙트 처리

# 오늘 핵심 정리

1. JSX는 React 화면을 작성하기 위한 문법이다.
2. Component는 화면을 재사용 가능한 단위로 분리하기 위해 사용한다.
3. Props는 부모에서 자식으로 데이터를 전달하기 위해 사용한다.
4. 구조분해 할당을 사용하면 Props를 편리하게 사용할 수 있다.
5. 조건부 렌더링으로 상황에 따라 다른 화면을 출력할 수 있다.
6. map()은 배열 데이터를 반복 출력하기 위해 사용한다.
7. Event는 사용자 행동을 처리하기 위해 사용한다.
8. useState는 상태를 저장하고 화면을 자동 갱신한다.
9. useEffect는 컴포넌트 생성 또는 상태 변경 시 실행된다.
10. React는 State 변경 → 재렌더링 → 화면 갱신 구조로 동작한다.

# 한 줄 요약

> React는 Component와 State를 중심으로 동작하며, useState와 useEffect를 통해 데이터 변화에 따라 화면을 자동으로 갱신하는 프론트엔드 라이브러리이다.
