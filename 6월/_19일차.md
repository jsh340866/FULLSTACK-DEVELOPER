## 1. Component (`03_Component/MyComponent.jsx`)

### 설명

React의 가장 기본 단위는 Component이다.

컴포넌트는 화면을 하나의 객체처럼 분리하여 관리하는 방식이다.

하나의 화면을 여러 개의 Component로 나누면

- 재사용 가능
- 유지보수 편리
- 코드 분리

라는 장점이 생긴다.

React에서는 대부분의 화면이 Component들의 조합으로 만들어진다.

---

### 실제 코드

```jsx
function MyComponent(){

    return(
        <>
            <h1>Hello React</h1>
        </>
    )

}

export default MyComponent;
```

#### 코드 설명

```jsx
function MyComponent(){

    // JSX 반환
    return(
        <>
            {/* 화면 출력 */}
            <h1>Hello React</h1>
        </>
    )

}

// 다른 파일에서도 사용할 수 있도록 export
export default MyComponent;
```

---

### 예상 출력

```
Hello React
```

---

### 핵심 정리

- Component는 화면을 구성하는 최소 단위
- export default로 다른 파일에서 import 가능
- Component를 조립하여 하나의 페이지를 만든다.

---

## 2. Event (`04_Event`)

### 설명

React의 이벤트는 HTML과 비슷하지만

JavaScript 함수와 연결하여 동작한다.

대표적으로

- 클릭
- 입력
- 키보드
- 마우스
- 스크롤

등을 처리할 수 있다.

---

### 실제 코드

```jsx
<button onClick={clickHandler}>
    클릭
</button>
```

```jsx
const clickHandler = ()=>{

    console.log("클릭");

}
```

#### 코드 설명

```jsx
// 클릭 이벤트 발생
<button onClick={clickHandler}>

// 실행될 함수
const clickHandler=()=>{

    // 콘솔 출력
    console.log("클릭");

}
```

---

### OnChange 예제

```jsx
<input
    onChange={(e)=>{

        console.log(e.target.value);

    }}
/>
```

#### 코드 설명

```jsx
// 입력값이 변경될 때마다 실행
onChange={(e)=>{

    // 현재 입력값 출력
    console.log(e.target.value);

}}
```

---

### 예상 출력

```
a
ab
abc
abcd
```

---

### 핵심 정리

- onClick → 클릭
- onChange → 입력값 변경
- onKeyDown → 키보드 입력
- onSubmit → 폼 제출
- React 이벤트는 CamelCase를 사용한다.

---

## 3. 조건부 렌더링 (`05_ConditionRendering`)

### 설명

React에서는

if문 대신

삼항연산자나 && 연산자를 가장 많이 사용한다.

조건에 따라

다른 Component를 출력하거나

화면 일부만 변경할 수 있다.

---

### 실제 코드

```jsx
{
    isLogin
    ?
    <h1>로그인 완료</h1>
    :
    <h1>로그인 필요</h1>
}
```

#### 코드 설명

```jsx
{

    // 로그인 여부 확인
    isLogin

    // true
    ?
    <h1>로그인 완료</h1>

    // false
    :
    <h1>로그인 필요</h1>

}
```

---

### && 연산자

```jsx
{
    isAdmin &&
    <button>관리자 메뉴</button>
}
```

#### 코드 설명

```jsx
{

    // true일 때만 출력
    isAdmin &&

    <button>관리자 메뉴</button>

}
```

---

### 예상 출력

```
로그인 완료
```

또는

```
로그인 필요
```

---

### 핵심 정리

- if문보다 삼항연산자를 많이 사용
- &&는 true일 때만 출력
- Component 자체를 조건에 따라 출력 가능

---

## 4. React Router (`06_ROUTE`)

### 설명

React는 기본적으로 SPA(Single Page Application)이다.

페이지를 새로고침하지 않고

URL만 변경하여 화면을 변경한다.

React Router가

현재 URL을 확인한 뒤

해당 Component를 화면에 출력한다.

---

### 실제 코드

```jsx
<BrowserRouter>

    <Routes>

        <Route path="/" element={<Home/>}/>

        <Route path="/about" element={<About/>}/>

        <Route path="/contact" element={<Contact/>}/>

    </Routes>

</BrowserRouter>
```

#### 코드 설명

```jsx
<BrowserRouter>

    <Routes>

        {/* 메인 페이지 */}
        <Route path="/" element={<Home/>}/>

        {/* 소개 페이지 */}
        <Route path="/about" element={<About/>}/>

        {/* 연락처 */}
        <Route path="/contact" element={<Contact/>}/>

    </Routes>

</BrowserRouter>
```

---

### 예상 출력

```
/

↓

Home Component

/about

↓

About Component

/contact

↓

Contact Component
```

---

### 핵심 정리

- path가 URL
- element가 출력될 Component
- URL에 따라 Component 변경

---

## 5. Layout과 Outlet (`06_ROUTE/Layout.jsx`)

### 설명

모든 페이지에서

Header

Menu

Footer

등은 계속 유지된다.

바뀌는 부분만 Outlet이 담당한다.

---

### 실제 코드

```jsx
<>
    <Menu/>

    <Outlet/>
</>
```

#### 코드 설명

```jsx
<>

    {/* 공통 메뉴 */}
    <Menu/>

    {/* 현재 Route 출력 */}
    <Outlet/>

</>
```

---

### 예상 출력

```
Menu

↓

Home

↓

About

↓

Contact
```

Menu는 그대로이고

Outlet만 변경된다.

---

### 핵심 정리

- 공통 화면은 Layout
- 변경되는 화면은 Outlet
- React Router에서 가장 많이 사용하는 구조

## 6. 실습 문제 (`05_EX.jsx`, `06_EX.jsx`)

### 설명

오늘 실습에서는

조건부 렌더링과

React Router를 직접 구현하였다.

조건에 따라

다른 Component를 출력하고

Router를 연결하면서

React의 화면 전환 원리를 학습하였다.

특히

- Route 등록
- Layout 연결
- Outlet 동작
- Component 분리
- 조건부 출력

과정을 직접 구현하였다.

---

### 핵심 정리

- Component를 분리하여 화면 구성
- 이벤트 발생 시 State 변경
- State에 따라 조건부 렌더링
- Route가 URL과 Component를 연결
- Outlet이 현재 Route를 출력

---

# 오늘 핵심 정리

React는 Component를 중심으로 화면을 구성하며,
이벤트를 통해 데이터를 변경하고,
조건부 렌더링으로 화면을 동적으로 변경한다.

React Router는 URL과 Component를 연결하여
페이지 이동 없이 필요한 화면만 변경하는 구조이며,
Layout과 Outlet을 이용하여 공통 화면과 변경되는 화면을 분리한다.

오늘 실습에서는 이러한 흐름을 직접 구현하면서
React 프로젝트의 기본 구조를 이해하는 데 집중하였다.
