## 1. Thymeleaf 데이터 바인딩 (`06_THYMELEAF/Controller/ThymeleafTestController.java`)

### 설명

Controller에서 `Model` 객체에 데이터를 담으면 Thymeleaf View에서 `${}` 표현식으로 접근할 수 있습니다.

기본 문자열, DTO 객체, List 데이터 모두 전달 가능합니다.

### 실제 코드

```java
model.addAttribute("name", "HongGilDong");

model.addAttribute(
    "dto",
    new PersonDTO("남길동",55,"대구")
);
```

리스트 전달:

```java
List<PersonDTO> list = new ArrayList<>();

for(int i=0;i<10;i++){
    list.add(new PersonDTO("TEST"+i,i,""));
}

model.addAttribute("list",list);
```

### 예상 출력

```txt
HongGilDong
PersonDTO(name=남길동, age=55, addr=대구)

TEST0
TEST1
TEST2
...
```

### 핵심 정리

- `Model.addAttribute()` → View 데이터 전달
- `${변수명}` → 템플릿 데이터 접근
- DTO / Collection 모두 전달 가능

## 2. Thymeleaf 표현식 / 반복문 / 조건문 (`06_THYMELEAF/templates/th/index.html`)

### 설명

Thymeleaf는 JSP EL과 비슷하게 `${}` 문법을 사용합니다.

객체 접근, 반복문, 조건문을 HTML 내부에서 처리할 수 있습니다.

### 실제 코드

DTO 접근:

```html
<span th:text="${dto.name}"></span>
<span th:text="${dto.age}"></span>
```

반복문:

```html
<th:block th:each="dto:${list}">
    <div th:text="${dto}"></div>
</th:block>
```

조건문:

```html
<th:block th:if="${isAuth}">
    <div>인증 완료!</div>
</th:block>

<th:block th:unless="${isAuth}">
    <div>인증 실패!</div>
</th:block>
```

### 예상 출력

```txt
남길동
55
대구

TEST0
TEST1
...

인증 완료!
```

### 핵심 정리

- `${}` → 변수 참조
- `th:each` → 반복문
- `th:if` → 조건문
- `th:unless` → 조건 false 처리

## 3. Thymeleaf 링크 처리 (`06_THYMELEAF/templates/th/index.html`)

### 설명

Thymeleaf는 URL 생성용 `@{}` 문법을 제공합니다.

파라미터를 안전하게 바인딩할 수 있습니다.

### 실제 코드

```html
<a th:href="@{/param/p01(name=${name})}">
```

다중 파라미터:

```html
<a th:href=
"@{/param/p06(
name=${dto.name},
age=${dto.age},
addr=${dto.addr}
)}">
```

### 예상 출력

```txt
/param/p01?name=HongGilDong

/param/p06?name=남길동&age=55&addr=대구
```

### 핵심 정리

- `th:href` → 동적 URL 생성
- `@{}` → QueryString 자동 생성
- 문자열 직접 연결보다 안전함

## 6. DataSource 설정 (`07_DATASOURCE/config/DataSourceConfig.java`)

### 설명

SpringBoot에서는 DB 연결 객체(`Connection`)를 직접 계속 생성하기보다 DataSource Bean으로 등록해서 관리합니다.

### 실제 코드

```java
@Configuration
public class DataSourceConfig {

    @Bean
    public DataSource dataSource() {

        DriverManagerDataSource ds =
                new DriverManagerDataSource();

        ds.setDriverClassName(
                "oracle.jdbc.driver.OracleDriver");

        ds.setUrl(
                "jdbc:oracle:thin:@localhost:1521:xe");

        ds.setUsername("system");
        ds.setPassword("1234");

        return ds;
    }
}
```

### 핵심 정리

- `@Configuration` → 설정 클래스 등록
- `@Bean` → Spring Bean 생성
- DataSource → DB 연결 객체 관리
- Connection 생성 코드 중복 감소

## 7. DAO 계층과 JDBC 구조 (`07_DATASOURCE/dao`)

### 설명

DAO(Data Access Object)는 DB 접근 전담 계층입니다.

Controller가 SQL을 직접 실행하지 않고 DAO를 통해 처리합니다.

### 처리 구조

```txt
Controller
 ↓
DAO
 ↓
DataSource
 ↓
DB
```

### 프로젝트 구조

```txt
dao
 ├─ MemoDAO
 └─ ExBookDAO

dto
 ├─ MemoDTO
 └─ BookDTO
```

### 핵심 정리

- Controller ↔ DB 직접 연결 X
- DAO가 SQL 처리 담당
- 유지보수성과 역할 분리 향상

## 8. DAO Insert 처리 (`07_DATASOURCE/dao/MemoDAO.java`)

### 설명

데이터 저장 시 JDBC `PreparedStatement`를 사용합니다.

SQL Injection 방지와 파라미터 바인딩을 위해 `?` Placeholder를 사용합니다.

### 실제 코드

```java
String sql =
"INSERT INTO tbl_memo VALUES(?,?,?)";

Connection conn =
        dataSource.getConnection();

PreparedStatement pstmt =
        conn.prepareStatement(sql);

pstmt.setInt(1,dto.getId());
pstmt.setString(2,dto.getText());
pstmt.setString(3,dto.getWriter());

pstmt.executeUpdate();
```

### 예상 출력

```txt
1행 삽입 완료
```

### 핵심 정리

- `Connection` → DB 연결
- `PreparedStatement` → SQL 실행 객체
- `executeUpdate()` → INSERT / UPDATE / DELETE

## 9. 조회 처리와 DTO 매핑 (`07_DATASOURCE/dao/MemoDAO.java`)

### 설명

조회 작업은 `ResultSet`으로 결과를 받아 DTO 객체로 변환합니다.

DB 결과 → Java 객체 변환 과정을 매핑(mapping)이라고 합니다.

### 실제 코드

```java
String sql =
"SELECT * FROM tbl_memo";

PreparedStatement pstmt =
        conn.prepareStatement(sql);

ResultSet rs =
        pstmt.executeQuery();

while(rs.next()) {

    MemoDTO dto =
            new MemoDTO();

    dto.setId(rs.getInt("id"));
    dto.setText(rs.getString("text"));
    dto.setWriter(
            rs.getString("writer")
    );

    list.add(dto);
}
```

### 예상 출력

```txt
MemoDTO(id=1,text=TEST,writer=USER1)
MemoDTO(id=2,text=HELLO,writer=USER2)
```

### 핵심 정리

- `executeQuery()` → SELECT
- `ResultSet` → 조회 결과 저장
- `rs.next()` → 다음 행 이동
- ResultSet → DTO 매핑

## 10. Controller + DAO 연동 (`07_DATASOURCE/controller`)

### 설명

Controller는 사용자 요청을 받고 DAO를 호출하여 DB 작업을 수행합니다.

조회 결과는 Model에 담아 View로 전달됩니다.

### 실제 코드

```java
@GetMapping("/list")
public String list(Model model)
        throws Exception {

    List<MemoDTO> list =
            memoDAO.selectAll();

    model.addAttribute(
            "list",
            list
    );

    return "memo/list";
}
```

### 처리 흐름

```txt
사용자 요청
   ↓
Controller
   ↓
memoDAO.selectAll()
   ↓
SQL 실행
   ↓
DTO List 반환
   ↓
Model 저장
   ↓
View 출력
```

### 핵심 정리

- Controller → 요청 처리
- DAO → DB 접근
- DTO → 데이터 전달 객체
- Model → View 데이터 전달

## 11. JDBC 자원 해제 처리

### 설명

JDBC 사용 후에는 반드시 자원을 정리해야 합니다.

미정리 상태가 되면 Connection Leak 문제가 발생할 수 있습니다.

### 실제 코드

```java
finally {

    if(rs!=null)
        rs.close();

    if(pstmt!=null)
        pstmt.close();

    if(conn!=null)
        conn.close();
}
```

### 핵심 정리

- `ResultSet` close
- `PreparedStatement` close
- `Connection` close
- 자원 누수 방지 필수
