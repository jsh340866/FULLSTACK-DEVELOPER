## 5. JPA CRUD API 연동 (`04_JPA/Post.jsx`, `04_JPA/List.jsx`, `04_JPA/postApi.js`)

### 설명

Spring Boot의 JPA CRUD API와 React를 연결했습니다.

등록, 조회, 수정, 삭제 요청을 API 함수로 분리하여 관리하고, 요청이 완료되면 목록을 다시 조회하여 화면을 최신 상태로 유지하는 구조를 학습했습니다.

---

### 실제 코드

```javascript
// postApi.js
export const getAll = () => axios.get(BASE_URL);

export const save = (post) =>
    axios.post(BASE_URL, post);
```

```javascript
// List.jsx
useEffect(() => {
    getAll()
        .then(resp => {
            setPosts(resp.data);
        })
        .catch(console.error);
}, []);
```

### 코드 설명

| 코드            | 설명            |
| ------------- | ------------- |
| `getAll()`    | 전체 게시글 조회     |
| `save()`      | 게시글 등록        |
| `useEffect()` | 최초 한 번 API 호출 |
| `setPosts()`  | 조회 결과를 화면에 출력 |

### 동작 흐름

```text
컴포넌트 실행 → useEffect() → Axios GET → Spring Boot → 게시글 목록 반환 → 화면 출력
```

### 예상 출력

```text
게시글 목록

1 홍길동
2 김철수
3 이영희
```

### 핵심 정리

* CRUD 요청은 API 파일로 분리하여 관리한다.
* `useEffect()`를 이용하여 최초 데이터를 조회한다.
* 조회 결과는 state에 저장하여 화면을 다시 렌더링한다.

> 💡 **실무에서는 CRUD API마다 별도의 API 모듈을 만들어 관리하는 경우가 많습니다.**

## 6. CRUD 완료 후 목록 갱신 (`04_JPA/Post.jsx`)

### 설명

등록이나 수정이 완료되더라도 화면은 자동으로 변경되지 않습니다.

따라서 요청이 성공하면 목록 조회 함수를 다시 호출하여 최신 데이터를 화면에 반영했습니다.

---

### 실제 코드

```javascript
save(post)

    .then(() => {

        getAll()
            .then(resp => {

                setPosts(resp.data);

            });

    });
```

### 코드 설명

| 코드           | 설명         |
| ------------ | ---------- |
| `save()`     | 게시글 저장     |
| `then()`     | 저장 완료 후 실행 |
| `getAll()`   | 최신 목록 조회   |
| `setPosts()` | 화면 갱신      |

### 동작 흐름

```text
등록 버튼 클릭 → POST 저장 → 저장 성공 → 목록 재조회 → 화면 갱신
```

### 예상 출력

```text
게시글 등록 완료

↓

새로운 게시글 목록 출력
```

### 핵심 정리

* 등록 후 목록을 다시 조회해야 최신 데이터가 표시된다.
* React는 서버 데이터가 변경되어도 자동으로 다시 조회하지 않는다.

## 7. FormData를 이용한 파일 업로드 (`05_UPLOAD/Upload.jsx`, `05_UPLOAD/uploadApi.js`)

### 설명

파일은 JSON으로 전송할 수 없기 때문에 **FormData** 객체를 사용했습니다.

텍스트 데이터와 파일을 함께 담아 Spring Boot로 전송하는 방법을 학습했습니다.

---

### 실제 코드

```javascript
const formData = new FormData();

formData.append("title", title);
formData.append("file", file);

upload(formData)
    .then(resp => {
        console.log(resp.data);
    });
```

### 코드 설명

| 코드           | 설명          |
| ------------ | ----------- |
| `FormData()` | 파일 전송 객체 생성 |
| `append()`   | 데이터 추가      |
| `file`       | 선택한 파일 객체   |
| `upload()`   | 업로드 API 호출  |

### 동작 흐름

```text
파일 선택 → FormData 생성 → Axios 업로드 → Spring Boot 저장 → 업로드 완료
```

### 예상 출력

```text
파일 업로드 성공
```

### 핵심 정리

* 파일 업로드는 반드시 `FormData`를 사용한다.
* 일반 데이터와 파일을 함께 전송할 수 있다.
* Axios가 `multipart/form-data` 형식으로 요청을 전송한다.

> 💡 **파일이 여러 개라면 `append()`를 여러 번 호출하여 추가할 수 있습니다.**

## 8. React Bootstrap을 이용한 화면 구성 (`05_UPLOAD`, `00_EX`)

### 설명

기본 HTML 대신 React Bootstrap 컴포넌트를 활용하여 화면을 구성했습니다.

Bootstrap 컴포넌트를 사용하면 UI를 빠르게 구현할 수 있습니다.

---

### 실제 코드

```jsx
<Card>

    <Card.Body>

        <Button
            variant="primary"
            onClick={handleSave}
        >
            저장
        </Button>

    </Card.Body>

</Card>
```

### 코드 설명

| 코드         | 설명           |
| ---------- | ------------ |
| `<Card>`   | 카드 레이아웃      |
| `<Button>` | Bootstrap 버튼 |
| `variant`  | 버튼 스타일       |
| `onClick`  | 이벤트 연결       |

### 동작 흐름

```text
컴포넌트 렌더링 → Bootstrap UI 출력 → 버튼 클릭 → 이벤트 실행
```

### 예상 출력

```text
Bootstrap 카드 화면

[ 저장 ]
```

### 핵심 정리

* React Bootstrap은 Bootstrap 컴포넌트를 React 형태로 제공한다.
* CSS를 직접 작성하지 않아도 빠르게 화면을 구성할 수 있다.

## 9. Todo 프로젝트 종합 실습 (`00_EX/TodoAdd.jsx`, `TodoList.jsx`, `ErrorPage.jsx`)

### 설명

지금까지 학습한 내용을 Todo 프로젝트에 모두 적용했습니다.

* 목록 조회
* 등록
* Validation
* Exception 처리
* ErrorPage 이동
* Router 연결

등을 하나의 프로젝트에서 구현하며 전체 흐름을 익혔습니다.

---

### 실제 코드

```javascript
saveTodo(todo)

    .then(() => {

        getTodos();

    })

    .catch(err => {

        navigate("/error", {
            state: err.response.data
        });

    });
```

### 코드 설명

| 코드           | 설명           |
| ------------ | ------------ |
| `saveTodo()` | Todo 등록      |
| `getTodos()` | 목록 재조회       |
| `catch()`    | 오류 처리        |
| `navigate()` | ErrorPage 이동 |

### 동작 흐름

```text
사용자 입력 → Todo 저장 → 성공 시 목록 갱신 / 실패 시 ErrorPage 이동
```

### 예상 출력

```text
Todo 등록 완료

↓

최신 목록 출력
```

또는

```text
등록 실패

↓

ErrorPage 출력
```

### 핵심 정리

* 지금까지 배운 API 연동과 예외 처리를 하나의 프로젝트에 적용하였다.
* CRUD와 Validation, Exception 처리를 함께 구현하는 흐름을 이해할 수 있다.

> 💡 **실무 프로젝트도 대부분 이런 구조(API 분리 → CRUD → 예외 처리 → 화면 갱신)로 구성됩니다.**

# 오늘 핵심 정리

* Axios를 이용하여 GET/POST 요청을 수행하고 Spring Boot와 연동하는 방법을 익혔다.

* `FormData`를 이용해 파일과 일반 데이터를 함께 업로드하는 방법을 학습하였다.
* Todo 프로젝트를 통해 지금까지 학습한 내용을 종합적으로 구현하였다.
