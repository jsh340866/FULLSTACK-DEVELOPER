## 1. MyBatis 환경 설정 (`Config`)

### 설명

SpringBoot에서 MyBatis를 사용하려면 DB 연결 객체와 MyBatis 객체 설정이 필요합니다.

핵심 객체:

- `DataSource`
- `SqlSessionFactory`
- `SqlSession`
- Mapper Scan

테스트 코드에서 실제 연결 확인까지 수행했습니다.

### 실제 코드

```java
@Autowired
private SqlSessionFactory sqlSessionFactory;

SqlSession sqlSession = sqlSessionFactory.openSession();
Connection conn = sqlSession.getConnection();
```

```java
@Autowired
private SqlSession sqlSession;

Connection conn = sqlSession.getConnection();
```

### 예상 출력

```text
com.mysql.cj.jdbc.ConnectionImpl@xxxx
```

### 핵심 정리

- `SqlSessionFactory` → SqlSession 생성 담당
- `SqlSession` → 실제 SQL 실행 담당
- MyBatis는 JDBC Connection 기반 동작

## 2. Annotation 기반 Mapper 작성 (`Domain/Common/Mapper`)

### 설명

MyBatis는 인터페이스에 SQL 어노테이션을 붙여 Mapper를 구성할 수 있습니다.

CRUD SQL을 Java 코드 안에서 직접 작성합니다.

### 실제 코드

```java
@Mapper
public interface MemoMapper {
```

INSERT

```java
@Insert(
"insert into tbl_memo values(#{id},#{title},#{writer},#{text},#{createAt})"
)
public int insert(MemoDTO memoDTO);
```

UPDATE

```java
@Update(
"update tbl_memo set text=#{text} where id=#{id}"
)
public int update(MemoDTO memoDTO);
```

DELETE

```java
@Delete(
"delete from tbl_memo where id=#{id}"
)
public int delete(Long id);
```

SELECT

```java
@Select("select * from tbl_memo")
public List<MemoDTO> selectALL();
```

### 예상 출력

```text
1
MemoDTO(id=55,title=TITLE55,...)
```

### 핵심 정리

- `@Insert`
- `@Select`
- `@Update`
- `@Delete`

만으로 SQL Mapper 구성 가능.

## 3. SelectKey 사용 (`MemoMapper`)

### 설명

INSERT 시 PK 값을 자동 생성하기 위해 `@SelectKey` 사용.

INSERT 이전/이후 특정 SQL 실행 가능.

### 실제 코드

```java
@SelectKey(
statement="SELECT max(id) FROM testdb.tbl_memo",
keyProperty="id",
before=false,
resultType=Long.class
)
```

### 핵심 정리

`@SelectKey`

→ INSERT 전/후 PK 생성 SQL 처리.

## 4. XML Mapper 작성 (`resources/mapper`)

### 설명

MyBatis는 XML 방식 SQL 정의도 지원합니다.

인터페이스 메서드명과 XML `id`가 연결됩니다.

### 실제 코드

```xml
<mapper namespace=
"com.example.demo.Domain.Common.Mapper.ProductMapper">
```

전체조회:

```xml
<select id="selectAllXML"
resultType=
"com.example.demo.Domain.Common.Dtos.ProductDTO">

    select * from tbl_product

</select>
```

INSERT XML:

```xml
<insert id="insertXML">
    insert into tbl_memo
    values(#{id},#{title},#{writer},#{text},#{createAt})
</insert>
```

### 예상 출력

```text
전체 상품 목록 조회 성공
```

### 핵심 정리

XML Mapper 특징:

- SQL 분리 가능
- 복잡한 쿼리 관리 편리
- 동적 SQL 작성 용이

## 5. 동적 SQL 처리 (`<if>`, `<where>`)

### 설명

조건 유무에 따라 SQL을 동적으로 생성할 수 있습니다.

검색 기능 구현에 매우 많이 사용됩니다.

Product 검색 조건:

- 상품명 keyword
- 최소 재고 minStock

### 실제 코드

```xml
<select id="searchXML"
parameterType="java.util.Map">

    select * from tbl_product

    <where>

        <if test="keyword != null">
            pname like concat('%',#{keyword},'%')
        </if>

        <if test="minStock != null">
            and stock >= #{minStock}
        </if>

    </where>

</select>
```

### 예상 출력

```text
keyword=111
minStock=111

조건에 맞는 상품 목록 반환
```

### 핵심 정리

MyBatis 동적 SQL 핵심 태그:

- `<if>`
- `<where>`
- `<choose>`
- `<foreach>`

## 6. DAO → Mapper 계층 연결 (`Domain/Common/Daos`)

### 설명

DAO는 Mapper를 감싸는 계층으로 사용했습니다.

흐름:

```text
Controller
   ↓
DAO
   ↓
Mapper
   ↓
Database
```

### 실제 코드

```java
@Autowired
private ProductMapper productMapper;
```

DAO 내부 호출:

```java
public int insert(ProductDTO dto){
    return productMapper.insert(dto);
}
```

검색 조건 Map 전달:

```java
Map<String,Object> params = new HashMap<>();

params.put("keyword",keyword);
params.put("minStock",minStock);

return productMapper.searchXML(params);
```

### 핵심 정리

DAO 역할:

- 비즈니스 중간 계층
- Mapper 호출 관리
- 파라미터 조립 담당

## 7. JDBC 방식과 MyBatis 방식 비교 (`MemoDAO / MemoDAO_BAK`)

### 설명

프로젝트에는 JDBC 버전과 MyBatis 버전 DAO가 같이 존재합니다.

비교 학습용 구조입니다.

### 실제 코드

JDBC 방식:

```java
Connection conn=dataSource3.getConnection();

PreparedStatement pstmt=
conn.prepareStatement(
"select * from tbl_memo"
);
```

MyBatis 방식:

```java
sqlSession.insert(
NAMESPACE+"insert",
dto
);
```

### 핵심 정리

JDBC 단점:

- Connection 직접 관리
- PreparedStatement 반복 작성

MyBatis 장점:

- SQL 매핑 자동화
- 객체 변환 지원
- 코드량 감소

## 8. Validation 적용 (`DTO`)

### 설명

DTO에서 Bean Validation 사용.

입력 검증을 자동 처리합니다.

### 실제 코드

```java
@NotBlank(
message="상품명은 필수 항목입니다."
)
private String pname;
```

```java
@NotNull(
message="가격은 필수 항목입니다."
)
private Integer price;
```

MemoDTO:

```java
@Email(
message="example@example.com 형식으로 입력하세요"
)
private String writer;
```

### 예상 출력

```text
상품명은 필수 항목입니다.
가격은 필수 항목입니다.
```

### 핵심 정리

주요 검증 어노테이션:

- `@NotBlank`
- `@NotNull`
- `@Email`

## 오늘 핵심 정리

- MyBatis는 **Annotation Mapper** 와 **XML Mapper** 모두 지원한다.
- `SqlSession` 이 실제 SQL 실행의 중심 객체이다.
- XML Mapper에서는 `<if>`, `<where>` 로 **동적 SQL** 구현 가능.
- DAO 계층이 Mapper를 감싸는 구조를 사용했다.
- JDBC보다 MyBatis가 SQL 매핑과 객체 변환을 훨씬 간결하게 처리한다.
