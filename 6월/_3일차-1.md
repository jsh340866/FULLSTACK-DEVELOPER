## 1. Pageable 생성 (`Controller/MemoController.java`)

### 설명

게시글을 페이지 단위로 조회하기 위해 Pageable 객체를 생성합니다.

### 실제 코드

```java
PageRequest pageRequest =
        PageRequest.of(pageNo,10);
```

### 예상 출력

```text
0페이지 → 10개 조회
1페이지 → 다음 10개 조회
```

### 핵심 정리

- 첫 번째 인자 : 페이지 번호
- 두 번째 인자 : 페이지 크기
- 페이지 번호는 0부터 시작

---

## 2. Page 객체 조회 (`Repository`)

### 설명

JPA는 조회 결과와 페이징 정보를 함께 담은 Page 객체를 제공합니다.

### 실제 코드

```java
Page<Memo> page =
        memoRepository.findAll(pageRequest);
```

### 예상 출력

```text
게시글 목록
전체 페이지 수
전체 게시글 수
```

### 핵심 정리

Page = 데이터 + 페이징 정보

---

## 3. 페이지 정보 확인 (`Page`)

### 설명

Page 객체를 통해 현재 페이지 상태를 확인할 수 있습니다.

### 실제 코드

```java
page.getNumber();
page.getTotalPages();
page.getTotalElements();
page.hasPrevious();
page.hasNext();
```

### 핵심 정리

| 메서드 | 의미 |
|----------|----------|
| getNumber() | 현재 페이지 |
| getTotalPages() | 전체 페이지 |
| getTotalElements() | 전체 게시글 |
| hasPrevious() | 이전 존재 |
| hasNext() | 다음 존재 |

---

## 4. 이전 버튼 구현 (`templates/list.html`)

### 설명

이전 페이지가 존재할 경우에만 버튼을 출력합니다.

### 실제 코드

```html
<th:block th:if="${page.hasPrevious()}">
    <a th:href="@{/memo/list(page=${page.number-1})}">
        이전
    </a>
</th:block>
```

### 예상 출력

```text
[이전]
```

### 핵심 정리

```java
page.hasPrevious()
```

를 이용하여 이전 페이지 존재 여부를 판단합니다.

---

## 5. 다음 버튼 구현 (`templates/list.html`)

### 설명

다음 페이지가 존재할 경우에만 버튼을 출력합니다.

### 실제 코드

```html
<th:block th:if="${page.hasNext()}">
    <a th:href="@{/memo/list(page=${page.number+1})}">
        다음
    </a>
</th:block>
```

### 예상 출력

```text
[다음]
```

### 핵심 정리

```java
page.hasNext()
```

를 이용하여 다음 페이지 존재 여부를 판단합니다.

---

## 6. 페이지 번호 출력 (`templates/list.html`)

### 설명

전체 페이지 수만큼 반복하여 페이지 번호를 생성합니다.

### 실제 코드

```html
<th:block th:each="i :
${#numbers.sequence(0,page.totalPages-1)}">
```

### 예상 출력

```text
1 2 3 4 5
```

### 핵심 정리

```java
#numbers.sequence()
```

를 이용하여 페이지 번호를 생성합니다.

---

## 7. PageRequest 예외 처리

### 설명

음수 페이지 번호를 전달하면 예외가 발생합니다.

### 실제 코드

```java
PageRequest.of(-1,10);
```

### 예상 출력

```text
Page index must not be less than zero
```

### 핵심 정리

페이지 번호는 반드시 0 이상이어야 합니다.

---

## 오늘 핵심 정리

```text
PageRequest 생성
       ↓
Repository 조회
       ↓
Page 객체 반환
       ↓
페이지 정보 확인
       ↓
이전/다음 버튼 출력
       ↓
페이지 번호 출력
```

- Page는 데이터와 페이징 정보를 함께 관리한다.
- 이전/다음 버튼은 hasPrevious(), hasNext()로 제어한다.
- 페이지 번호는 #numbers.sequence()로 생성한다.
- PageRequest의 페이지 번호는 0부터 시작한다.
