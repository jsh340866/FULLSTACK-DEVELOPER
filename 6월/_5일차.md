## 1. RestController 기본 구조 (`11_RESTCONTROLLER/controller`)

### 설명

기존 Controller는 View(JSP, Thymeleaf)를 반환합니다.

```java
@Controller
```

반면 RestController는 데이터를 반환합니다.

```java
@RestController
```

Spring이 반환 객체를 자동으로 JSON으로 변환합니다.

### 실제 코드

```java
@RestController
@RequestMapping("/rest")
public class RestTest1Controller {

    @GetMapping("/getText")
    public String t1(){
        return "HELLOWORLD";
    }

}
```

### 예상 출력

```text
HELLOWORLD
```

### 핵심 정리

- View가 아닌 데이터 반환
- JSON API 개발의 기본
- @ResponseBody 기능 포함

## 2. JSON 응답 처리 (`11_RESTCONTROLLER/controller`)

### 설명

객체를 반환하면 Spring이 자동으로 JSON으로 변환합니다.

이 과정을

```text
직렬화(Serialization)
```

라고 합니다.

### 실제 코드

```java
@GetMapping("/getJson")
public MemoDTO t2(){

    return MemoDTO.builder()
            .id(1L)
            .title("title1")
            .writer("user")
            .text("hello")
            .build();
}
```

### 예상 출력

```json
{
  "id":1,
  "title":"title1",
  "writer":"user",
  "text":"hello"
}
```

### 핵심 정리

- 객체 → JSON 자동 변환
- Jackson 라이브러리 사용
- REST API의 기본 응답 형태

## 3. XHR(XMLHttpRequest) 비동기 통신 (`11_RESTCONTROLLER/templates`)

### 설명

XHR은 페이지 전체를 새로고침하지 않고 서버와 통신할 수 있는 자바스크립트 객체입니다.

동작 순서

```text
브라우저
 ↓
XHR 요청
 ↓
REST API 호출
 ↓
JSON 응답
 ↓
화면 갱신
```

### 실제 코드

```javascript
const xhr = new XMLHttpRequest();

xhr.open("GET","/rest/getJson");

xhr.onload = function(){
    console.log(xhr.responseText);
}

xhr.send();
```

### 예상 출력

```json
{
  "id":1,
  "title":"title1",
  "writer":"user",
  "text":"hello"
}
```

### 핵심 정리

- 비동기 요청 가능
- 페이지 새로고침 불필요
- REST API 호출의 기본 기술
- Fetch API와 Axios의 기반 기술

## 4. RequestBody 사용 (`11_RESTCONTROLLER/controller`)

### 설명

클라이언트가 JSON 데이터를 보내면

```java
@RequestBody
```

를 이용하여 DTO 객체로 자동 변환합니다.

### 실제 코드

```java
@PostMapping("/rest/add")
public ResponseEntity<?> addMemo(
        @RequestBody MemoDTO memoDTO
){
    ...
}
```

### 요청 데이터

```json
{
  "title":"제목",
  "writer":"test@test.com",
  "text":"내용"
}
```

### 핵심 정리

- JSON → DTO 자동 변환
- REST API POST 요청 핵심
- Ajax/Fetch/Axios에서 많이 사용

## 5. ResponseEntity 활용 (`11_RESTCONTROLLER/controller`)

### 설명

ResponseEntity는 응답 데이터뿐 아니라 상태코드도 제어할 수 있습니다.

### 실제 코드

```java
return ResponseEntity
        .status(HttpStatus.OK)
        .body(list);
```

### 예상 출력

```http
200 OK
```

```json
[
  {...},
  {...}
]
```

### 핵심 정리

- 응답 데이터 제어
- 상태코드 제어
- REST API 실무 필수

## 6. 유효성 검사 (`11_RESTCONTROLLER/dto`)

### 설명

잘못된 데이터가 들어오는 것을 방지합니다.

### 실제 코드

```java
@NotBlank
private String title;

@NotBlank
@Email
private String writer;

@NotBlank
private String text;
```

```java
@PostMapping("/rest/add")
public ResponseEntity<?> addMemo(
        @Valid @RequestBody MemoDTO memoDTO,
        BindingResult bindingResult
){
}
```

### 예상 출력

```json
{
  "writer":"이메일 형식이 아닙니다."
}
```

### 핵심 정리

- 데이터 검증 자동 처리
- Validation 활용
- 서버 안정성 향상

## 오늘 핵심 정리

- RestController는 View가 아닌 데이터를 반환한다.
- 객체는 자동으로 JSON으로 변환된다.
- XHR을 이용하면 페이지 새로고침 없이 서버와 통신할 수 있다.
- @RequestBody는 JSON을 DTO 객체로 변환한다.
- ResponseEntity는 응답 데이터와 상태코드를 함께 제어한다.
- @Valid와 BindingResult를 이용해 입력값 검증이 가능하다.
- JPA CRUD와 REST API를 결합하여 게시판 기능을 구현할 수 있다.
- Pageable을 이용해 REST 방식의 페이징 처리가 가능하다.

## 한 줄 요약

> RestController는 JSON 기반 REST API를 제공하고, XHR은 해당 API를 비동기로 호출하여 화면을 동적으로 갱신하는 핵심 기술이다.
