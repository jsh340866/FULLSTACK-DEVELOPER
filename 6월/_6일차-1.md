## 1. Book REST API 구조 (`BookController`)

### 설명

모든 클라이언트(XHR, AJAX, Fetch, Axios)는 결국 동일한 REST API를 호출한다.

BookController가 데이터를 제공하는 서버 역할을 수행한다.

### 실제 코드

```java
@RestController
@RequestMapping("/book")
public class BookController {
}
```

전체 목록 조회

```java
@GetMapping
public List<BookDto> list(){
    return books;
}
```

단건 조회

```java
@GetMapping("/{id}")
public BookDto get(
    @PathVariable Long id
){
    return book;
}
```

### 예상 출력

```json
[
  {
    "id":1,
    "title":"JAVA",
    "author":"홍길동"
  }
]
```

### 핵심 정리

- REST API 서버 역할
- JSON 데이터 반환
- 모든 클라이언트가 동일 API 사용

## 2. XHR(XMLHttpRequest) (`xhr.html`)

### 설명

브라우저가 제공하는 가장 기본적인 HTTP 통신 객체이다.

직접 이벤트를 연결해야 하므로 코드가 길어진다.

### 실제 코드

```javascript
const xhr = new XMLHttpRequest();
```

요청 준비

```javascript
xhr.open(
    "GET",
    "/book"
);
```

응답 처리

```javascript
xhr.onload = ()=>{
    console.log(xhr.responseText);
};
```

전송

```javascript
xhr.send();
```

### 동작 순서

```text
1. 객체 생성
2. 요청 설정
3. 응답 이벤트 등록
4. send()
5. 서버 응답 수신
```

### 핵심 정리

- 모든 비동기 통신의 원조
- 직접 상태 관리 필요
- 코드가 복잡함

## 3. AJAX (`ajax.html`)

### 설명

jQuery가 XHR을 내부적으로 감싸서 사용한다.

코드가 훨씬 간결해진다.

### 실제 코드

```javascript
$.ajax({
    url:'/book',
    method:'GET',
    success:function(data){
        console.log(data);
    }
});
```

POST 요청

```javascript
$.ajax({
    url:'/book',
    method:'POST',
    contentType:'application/json',
    data:JSON.stringify(book)
});
```

### 내부 동작

```text
$.ajax()
 ↓
XHR 생성
 ↓
HTTP 요청
 ↓
응답 처리
```

### 핵심 정리

- XHR을 쉽게 사용
- jQuery 의존
- 레거시 프로젝트에서 자주 사용

---

## 4. Fetch API (`fetch.html`)

### 설명

브라우저 기본 내장 API이다.

Promise 기반으로 동작한다.

### 실제 코드

GET

```javascript
fetch('/book')
    .then(res=>res.json())
    .then(data=>{
        console.log(data);
    });
```

POST

```javascript
fetch('/book',{
    method:'POST',
    headers:{
        'Content-Type':'application/json'
    },
    body:JSON.stringify(book)
});
```

### 중요한 코드

JSON 변환

```javascript
res.json()
```

이 부분이 응답 문자열을 객체로 변환한다.

### 동작 구조

```text
fetch()
 ↓
Promise 생성
 ↓
then()
 ↓
JSON 변환
 ↓
데이터 사용
```

### 핵심 정리

- 브라우저 기본 제공
- Promise 기반
- 현재 표준 방식

---

## 5. Axios (`axios.html`)

### 설명

실무에서 가장 많이 사용하는 HTTP 라이브러리이다.

Fetch보다 코드가 더 간단하다.

### 실제 코드

GET

```javascript
axios.get('/book')
     .then(res=>{
         console.log(res.data);
     });
```

POST

```javascript
axios.post(
    '/book',
    {
        title:'JAVA',
        author:'홍길동'
    }
);
```

PUT

```javascript
axios.put(
    '/book/1',
    book
);
```

DELETE

```javascript
axios.delete(
    '/book/1'
);
```

### 중요한 코드

```javascript
res.data
```

Axios는 자동으로 JSON을 객체로 변환한다.

Fetch처럼

```javascript
res.json()
```

을 호출할 필요가 없다.

### 핵심 정리

- JSON 자동 변환
- 코드가 가장 짧음
- React 프로젝트에서 가장 많이 사용

## 6. Book 등록 흐름

### 설명

새 책을 추가할 때는 POST 요청을 사용한다.

### 실제 코드

클라이언트

```javascript
axios.post(
    '/book',
    {
        title:'SPRING',
        author:'김철수'
    }
);
```

서버

```java
@PostMapping
public BookDto create(
    @RequestBody BookDto dto
){
    books.add(dto);
    return dto;
}
```

### 데이터 흐름

```text
JSON 생성
 ↓
POST 요청
 ↓
@RequestBody
 ↓
BookDto 변환
 ↓
저장
 ↓
JSON 응답
```

### 핵심 정리

- JSON → DTO 자동 변환
- @RequestBody 사용

## 9. XHR / AJAX / Fetch / Axios 비교

### 설명

동일한 GET 요청 구현 비교

XHR

```javascript
const xhr = new XMLHttpRequest();
xhr.open("GET","/book");
xhr.send();
```

AJAX

```javascript
$.ajax({
    url:'/book'
});
```

Fetch

```javascript
fetch('/book');
```

Axios

```javascript
axios.get('/book');
```

### 핵심 정리

|방식|코드량|JSON처리|실무 사용|
|-----|-----|-----|-----|
|XHR|많음|직접 처리|거의 없음|
|AJAX|보통|직접 처리|레거시|
|Fetch|적음|res.json()|많음|
|Axios|가장 적음|자동 처리|매우 많음|

## 오늘 핵심 정리

- BookController가 REST API 서버 역할을 수행한다.
- XHR은 가장 기본적인 HTTP 통신 객체이다.
- AJAX는 XHR을 간단하게 사용하기 위한 jQuery 기능이다.
- Fetch는 Promise 기반 브라우저 표준 API이다.
- Axios는 JSON 자동 변환을 지원하여 가장 편리하다.
- Book CRUD를 통해 GET, POST, PUT, DELETE 요청 흐름을 학습하였다.
- 클라이언트의 JSON 데이터는 @RequestBody를 통해 DTO로 변환된다.
