## 오늘 배운 것

이번 예제에서는 Spring Boot 서버가 클라이언트 역할이 되어 외부 Open API를 호출하는 방법을 학습하였다.

기존 수업에서는

```text
브라우저
 ↓
Spring Server
```

구조였다면

이번에는

```text
Spring Server
 ↓
공공데이터 Open API
```

구조로 동작한다.

즉 Spring이 직접 HTTP 요청을 보내고 응답 JSON을 DTO 객체로 변환한다.

## 1. Open API 연동 전체 구조

### 설명

외부 API 호출 과정은 항상 동일한 흐름으로 진행된다.

```text
1. 요청 URL 생성
2. Query Parameter 추가
3. RestTemplate 생성
4. GET 요청 전송
5. JSON 응답 수신
6. DTO 매핑
7. 데이터 사용
```

### 실제 코드

```java
URI uri = UriComponentsBuilder
        .fromHttpUrl(server)
        .queryParam(...)
        .build()
        .toUri();
```

```java
RestTemplate restTemplate =
        new RestTemplate();
```

```java
ResponseEntity<Root> response =
        restTemplate.exchange(
                uri,
                HttpMethod.GET,
                null,
                Root.class
        );
```

### 핵심 정리

- Open API 호출 공식 패턴
- URL 생성
- 요청 전송
- 응답 DTO 변환

## 2. UriComponentsBuilder 사용

### 설명

API 요청 URL을 안전하게 생성하기 위해 사용한다.

직접 문자열을 연결하는 방식보다 훨씬 안전하다.

### 실제 코드

```java
URI uri = UriComponentsBuilder
        .fromHttpUrl(server)
        .queryParam("serviceKey", serviceKey)
        .queryParam("pageNo", pageNo)
        .queryParam("numOfRows", numOfRows)
        .queryParam("dataType", dataType)
        .queryParam("base_date", base_date)
        .queryParam("base_time", base_time)
        .queryParam("nx", nx)
        .queryParam("ny", ny)
        .encode()
        .build()
        .toUri();
```

### 실제 생성 URL 형태

```text
https://apis.data.go.kr
    ?serviceKey=...
    &pageNo=1
    &numOfRows=1000
    &base_date=20260609
```

### 핵심 정리

- URL 생성 전용 객체
- Query Parameter 자동 처리
- 인코딩 자동 수행

## 3. RestTemplate 사용

### 설명

Spring이 제공하는 HTTP 클라이언트이다.

외부 서버에 GET, POST 요청을 전송할 수 있다.

### 실제 코드

```java
RestTemplate restTemplate =
        new RestTemplate();
```

```java
ResponseEntity<Root> response =
        restTemplate.exchange(
                uri,
                HttpMethod.GET,
                null,
                Root.class
        );
```

### 코드 분석

```java
HttpMethod.GET
```

GET 요청

```java
null
```

헤더 없음

```java
Root.class
```

응답 JSON을 Root 객체로 변환

### 핵심 정리

- Spring HTTP Client
- 외부 API 호출 핵심 객체
- JSON → DTO 자동 변환

## 5. JSON 구조 분석

### 설명

기상청 API 응답은 중첩 구조로 되어 있다.

### 응답 구조

```json
{
  "response": {
    "header": {},
    "body": {
      "items": {
        "item": []
      }
    }
  }
}
```

### 이를 위해 만든 DTO

```java
Root
 └ Response
     ├ Header
     └ Body
         └ Items
             └ Item
```

### 실제 코드

```java
@Data
private static class Root{
    public Response response;
}
```

```java
@Data
private static class Response{
    public Header header;
    public Body body;
}
```

### 핵심 정리

- JSON 구조와 DTO 구조는 동일해야 함
- 자동 매핑 가능


- obsrValue가 실제 값

## 오늘 핵심 정리

- Spring Boot가 직접 외부 Open API를 호출하는 방법을 학습하였다.
- UriComponentsBuilder로 안전하게 URL을 생성하였다.
- RestTemplate으로 HTTP 요청을 전송하였다.
- 기상청 초단기 실황 API를 호출하여 날씨 정보를 조회하였다.
- 대구 버스 도착정보 API를 호출하여 실시간 정보를 조회하였다.
- JSON 응답 구조와 동일한 DTO를 작성하여 자동 매핑하였다.
- Open API 연동은 URL 생성 → 요청 → 응답 → DTO 변환 순서로 동작한다.
