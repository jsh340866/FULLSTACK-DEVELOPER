## 1. 동기 요청 처리 (`외부API연동/C02OpenWeatherMap/OpenWeatherMapController.java`)

### 설명

동기 요청은 요청을 보낸 후 응답이 올 때까지 기다리는 방식이다.

이번 예제에서는 Spring Boot 서버가 직접 OpenWeatherMap API를 호출하여 데이터를 받아온 뒤 화면에 전달하였다.

처리 순서

```text
브라우저
 ↓
Spring Boot
 ↓
OpenWeather API
 ↓
Spring Boot
 ↓
브라우저
```

응답이 완료될 때까지 다음 작업은 수행되지 않는다.

### 실제 코드

```java
RestTemplate restTemplate =
        new RestTemplate();

ResponseEntity<Root> response =
        restTemplate.exchange(
                uri,
                HttpMethod.GET,
                null,
                Root.class
        );
```

### 예상 출력

```text
요청 시작
응답 대기
날씨 데이터 수신
화면 출력
```

### 핵심 정리

- 요청 후 응답을 기다린다.
- 처리 순서가 보장된다.
- RestTemplate은 기본적으로 동기 방식이다.

## 2. 비동기 요청 처리 (`외부API연동/C02OpenWeatherMap/OpenWeather/index.html`)

### 설명

비동기 요청은 응답을 기다리지 않고 다음 작업을 수행하는 방식이다.

브라우저에서 fetch()를 이용하여 Spring Boot 서버에 요청을 보냈다.

처리 순서

```text
브라우저
 ↓
fetch 요청
 ↓
다음 코드 실행
 ↓
Spring Boot 처리
 ↓
응답 수신
 ↓
화면 갱신
```

### 실제 코드

```javascript
await fetch(`/OpenWeather/${lat}/${lng}`)
```

```javascript
await fetch(
`https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat=${lat}&lon=${lng}&layer=address`
)
```

### 예상 출력

```text
요청 전송
다음 작업 수행
응답 수신
데이터 출력
```

### 핵심 정리

- fetch는 비동기 요청 방식이다.
- 사용자 경험이 향상된다.
- 실시간 데이터 처리에 적합하다.

## 3. RestTemplate과 ResponseEntity (`외부API연동/C01OpenData`, `C02OpenWeatherMap`)

### 설명

RestTemplate은 외부 API 서버와 HTTP 통신을 담당하는 객체이다.

ResponseEntity는 HTTP 응답 전체를 저장하는 객체이다.

동작 흐름

```text
Spring Boot
 ↓
RestTemplate
 ↓
외부 API
 ↓
ResponseEntity
 ↓
DTO 객체 변환
```

### 실제 코드

```java
RestTemplate restTemplate =
        new RestTemplate();
```

```java
ResponseEntity<Root> response =
        restTemplate.exchange(
                uri,
                HttpMethod.GET,
                null,
                Root.class
        );
```

```java
Root root =
        response.getBody();
```

### 예상 출력

```text
200 OK
응답 데이터 수신
```

### 핵심 정리

- RestTemplate : 외부 API 호출 객체
- exchange() : HTTP 요청 전송
- ResponseEntity : 응답 전체 저장
- getBody() : 실제 데이터 추출

## 4. @RequestBody 와 @ResponseBody (`REST API`)

### 설명

JSON 데이터를 Java 객체로 변환하거나 Java 객체를 JSON 형태로 반환할 때 사용하는 어노테이션이다.

### 실제 코드

```java
@PostMapping("/test")
public void test(
        @RequestBody UserDto dto
){
}
```

```java
@ResponseBody
@GetMapping("/hello")
public String hello(){
    return "HELLO";
}
```

### 예상 출력

```json
{
  "name":"홍길동"
}
```

### 핵심 정리

- @RequestBody : JSON → Java 객체
- @ResponseBody : Java 객체 → JSON
- REST API에서 자주 사용된다.
