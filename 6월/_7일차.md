## 1. RestTemplate을 이용한 외부 API 호출 (`외부API연동/C01OpenData`)

### 설명

Spring Boot 서버가 다른 서버의 API를 호출하는 방법을 학습했습니다.

기존에는

```text
브라우저 → Spring Boot
```

구조였다면

이번에는

```text
브라우저
 ↓
Spring Boot
 ↓
공공데이터 API 서버
```

형태로 동작합니다.

즉, Spring Boot가 클라이언트 역할을 수행하여 외부 서버에 직접 요청을 보내고 응답을 받아옵니다.

---

### RestTemplate의 역할

`RestTemplate`은 Spring에서 제공하는 HTTP 통신 객체입니다.

주요 역할

- GET 요청 전송
- POST 요청 전송
- PUT 요청 전송
- DELETE 요청 전송
- 응답 데이터 수신
- JSON/XML → Java 객체 자동 변환

즉,

```text
외부 API 호출 전담 객체
```

라고 이해하면 됩니다.

---

### 전체 처리 흐름

```text
1. 요청 URL 생성
        ↓
2. RestTemplate 요청
        ↓
3. API 서버 응답
        ↓
4. ResponseEntity 수신
        ↓
5. DTO 객체 변환
        ↓
6. Controller 반환
```

---

### 실제 코드

```java
RestTemplate restTemplate =
        new RestTemplate();

ResponseEntity<Root> response =
        restTemplate.exchange(
                uri,
                HttpMethod.GET,
                null,
                Root.class
        );
```

응답 데이터 추출

```java
Root root =
        response.getBody();
```

결과 확인

```java
System.out.println(root);
```

---

### ResponseEntity란?

HTTP 응답 전체를 담는 객체입니다.

포함 정보

```text
응답 본문(body)
응답 상태코드(status)
응답 헤더(header)
```

예시

```java
ResponseEntity<Root> response
```

구조

```text
ResponseEntity
 ├ status : 200 OK
 ├ header
 └ body
```

실제 사용

```java
Root root =
        response.getBody();
```

---

### @ResponseBody란?

메서드 반환값을 View로 보내지 않고

직접 HTTP 응답 본문에 출력하는 어노테이션입니다.

예시

```java
@ResponseBody
@GetMapping("/test")
public String test(){
    return "HELLO";
}
```

결과

```text
HELLO
```

화면에 그대로 출력

---

### @RequestBody란?

클라이언트가 보낸 JSON 데이터를

Java 객체로 변환하는 어노테이션입니다.

예시

```java
@PostMapping("/user")
public void addUser(
    @RequestBody UserDto dto
){
}
```

클라이언트

```json
{
    "name":"홍길동",
    "age":20
}
```

자동 변환

```java
dto.getName();
dto.getAge();
```

---

### ResponseBody와 RequestBody 차이

|구분|역할|
|---|---|
|@RequestBody|JSON → Java 객체|
|@ResponseBody|Java 객체 → JSON|

---

### 예상 출력

```text
API 요청 성공

status : 200 OK

데이터 수신 완료
```

---

### 핵심 정리

- RestTemplate은 외부 API 통신 객체이다.
- GET, POST, PUT, DELETE 요청을 보낼 수 있다.
- JSON/XML 응답을 Java 객체로 자동 변환한다.
- ResponseEntity는 응답 전체를 담는 객체이다.
- @RequestBody는 JSON을 Java 객체로 변환한다.
- @ResponseBody는 Java 객체를 JSON으로 변환한다.
- 외부 API 연동의 핵심은 RestTemplate + DTO 매핑이다.

## 2. UriComponentsBuilder를 이용한 요청 URL 생성 (`C01OpenData`)

### 설명

공공데이터 API는 Query Parameter가 매우 많습니다.

직접 문자열을 이어붙이는 대신

UriComponentsBuilder를 사용하여 안전하게 URL을 생성했습니다.

---

### 실제 코드

```java
URI uri =
    UriComponentsBuilder.fromHttpUrl(server)
        .queryParam("serviceKey", serviceKey)
        .queryParam("pageNo", pageNo)
        .queryParam("numOfRows", numOfRows)
        .encode()
        .build()
        .toUri();
```

---

### 예상 출력

```text
https://apis.data.go.kr/...
?pageNo=1
&numOfRows=1000
```

---

### 핵심 정리

- URL 파라미터 자동 생성
- URL 인코딩 자동 처리
- 유지보수성이 높음
- 실무 API 개발에서 자주 사용

---

## 4. JSON/XML 응답 객체 매핑 (`C01OpenData`)

### 설명

API 응답 데이터를 Java 객체로 변환하는 방법을 학습했습니다.

중첩 구조가 많기 때문에 내부 클래스를 구성하여 매핑했습니다.

---

### 실제 코드

```java
@Data
private static class Body{
    private Items items;
}
```

```java
@Data
private static class Root{
    private Response response;
}
```

---

### 예상 출력

```text
Root
 └ Response
     └ Body
         └ Items
```

---

### 핵심 정리

- JSON 구조와 DTO 구조가 동일해야 함
- 중첩 응답은 중첩 클래스 사용
- Jackson이 자동 매핑 수행

## 5. 카카오 OAuth2 로그인 (`C03Kakao/KakaoLoginController.java`)

### 설명

카카오 로그인은 OAuth2 인증 방식을 사용합니다.

로그인 처리 과정

```text
사용자 로그인
 ↓
인가 코드(Code)
 ↓
Access Token 발급
 ↓
사용자 정보 요청
```

방식으로 진행됩니다.

---

### 실제 코드

```java
return "redirect:https://kauth.kakao.com/oauth/authorize"
       + "?client_id=" + CLIENT_ID
       + "&redirect_uri=" + REDIRECT_URI
       + "&response_type=code";
```

---

### 실제 코드

인가 코드 수신

```java
@GetMapping("/callback")
public String callback(String code)
```

---

### 핵심 정리

- OAuth2 인증 방식 사용
- 로그인 성공 시 Code 발급
- Code로 Access Token 발급
- Access Token으로 API 접근

---
