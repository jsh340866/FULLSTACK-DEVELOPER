## 1. 카카오 로그인 OAuth2 API 연동 (`외부API연동/C03Kakao/C02KakaoLoginController`)

### 설명

오늘 학습한 카카오 로그인은 OAuth2 인증 구조를 사용한다.

하지만 실제 학습의 핵심은 OAuth2 개념 자체보다 Spring에서 외부 API를 호출하는 패턴을 이해하는 것이다.

카카오 로그인 과정에서는 외부 API 호출 패턴이 두 번 반복된다.

```text
Authorization Code
↓
Access Token 발급 API 호출
↓
Access Token 획득
↓
사용자 정보 조회 API 호출
↓
사용자 정보 획득
```

---

### 실제 코드

#### URL 생성

```java
String url =
    "https://kauth.kakao.com/oauth/token";
```

토큰 발급 서버 주소를 지정한다.

---

#### 요청 데이터 생성

```java
MultiValueMap<String, String> params =
        new LinkedMultiValueMap<>();

params.add("grant_type","authorization_code");
params.add("client_id",CLIENT_ID);
params.add("redirect_uri",REDIRECT_URI);
params.add("code",code);
```

카카오 서버에 전달할 요청 데이터를 생성한다.

---

#### Header 생성

```java
HttpHeaders header =
        new HttpHeaders();

header.add(
    "Content-type",
    "application/x-www-form-urlencoded;charset=utf-8"
);
```

HTTP 요청 형식을 지정한다.

---

#### HttpEntity 생성

```java
HttpEntity<MultiValueMap<String,String>>
        entity =
        new HttpEntity<>(params,header);
```

Header와 Body를 하나의 요청 객체로 생성한다.

---

#### RestTemplate 생성

```java
RestTemplate restTemplate =
        new RestTemplate();
```

외부 API 호출 객체 생성

---

#### API 호출

```java
ResponseEntity<KakaoTokenResponse>
        response =
        restTemplate.exchange(
                url,
                HttpMethod.POST,
                entity,
                KakaoTokenResponse.class
        );
```

카카오 서버에 실제 요청을 수행한다.

---

#### 응답 DTO 매핑

```java
response.getBody()
```

```java
response.getBody().getAccessToken()
```

JSON 응답을 DTO 객체로 변환하여 사용한다.

---

### 예상 출력

```text
Access Token 발급 성공
```

```text
사용자 정보 조회 성공
```

### 핵심 정리

* URL 생성
* Params 생성
* Header 생성
* HttpEntity 생성
* RestTemplate 생성
* exchange() 호출
* ResponseEntity 수신
* DTO 매핑

카카오 로그인은 외부 API 연동 패턴을 가장 잘 보여주는 예제이다.

## 2. 네이버 로그인 OAuth2 API 연동 (`외부API연동/C04Naver/NaverLoginController`)

### 설명

네이버 로그인 역시 카카오 로그인과 동일한 구조를 사용한다.

API 서버 주소만 다를 뿐 요청 생성부터 응답 처리까지 동일한 패턴으로 구현된다.

OAuth2 표준 구조를 기반으로 Access Token을 발급받고 사용자 정보를 조회한다.

---

### 실제 코드

#### URL 생성

```java
String url =
        "https://nid.naver.com/oauth2.0/token";
```

---

#### 요청 데이터 생성

```java
params.add("grant_type","authorization_code");
params.add("client_id",CLIENT_ID);
params.add("client_secret",CLIENT_SECRET);
params.add("code",code);
params.add("state",state);
```

---

#### Header 생성

```java
HttpHeaders headers =
        new HttpHeaders();
```

---

#### HttpEntity 생성

```java
HttpEntity entity =
        new HttpEntity(params,headers);
```

---

#### API 호출

```java
ResponseEntity<NaverTokenResponse>
        response =
        restTemplate.exchange(
                url,
                HttpMethod.POST,
                entity,
                NaverTokenResponse.class
        );
```

---

#### 사용자 정보 조회

```java
String userUrl =
        "https://openapi.naver.com/v1/nid/me";
```

```java
headers.add(
        "Authorization",
        "Bearer " + accessToken
);
```

```java
ResponseEntity<NaverUserResponse>
        response =
        restTemplate.exchange(
                userUrl,
                HttpMethod.GET,
                entity,
                NaverUserResponse.class
        );
```

---

### 예상 출력

```text
네이버 사용자 정보 조회 성공
```

### 핵심 정리

* 카카오 로그인과 동일한 API 연동 구조 사용
* Access Token 발급
* 사용자 정보 조회
* JSON → DTO 변환

String url = "...";

MultiValueMap<String,String> params =
