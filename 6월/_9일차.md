## 1. REST API 호출 구조 (`12_RESTFULAPI/OpenWeatherMapController`)

### 설명

이번 프로젝트 대부분의 외부 API 연동은 동일한 패턴으로 구성되어 있습니다.

REST API 호출 시 일반적으로 다음 순서로 처리됩니다.

```text
URL 생성
↓
Header 생성
↓
Body 생성
↓
HttpEntity 생성
↓
RestTemplate 호출
↓
ResponseEntity 수신
↓
DTO 매핑
```

Spring에서 가장 많이 사용하는 외부 API 연동 방식입니다.

### 실제 코드

```java
ResponseEntity<Root> response =
    restTemplate.exchange(
        uri,
        HttpMethod.GET,
        null,
        Root.class
    );
```

### 예상 출력

```json
{
  "main": {
    "temp": 24.3
  },
  "weather": [
    {
      "description": "clear sky"
    }
  ]
}
```

### 핵심 정리

- RestTemplate은 동기 방식 HTTP 클라이언트
- exchange() 메서드로 GET/POST 모두 처리 가능
- 응답 결과는 ResponseEntity로 수신

## 2. OAuth2 로그인 구조 (`12_RESTFULAPI/KakaoLoginController`, `NaverLoginController`, `GoogleLoginController`)

### 설명

카카오, 네이버, 구글 로그인은 모두 OAuth2 기반으로 동작합니다.

동일한 인증 흐름을 따릅니다.

```text
사용자 로그인 요청
↓
인가코드(code) 발급
↓
Access Token 요청
↓
Access Token 발급
↓
사용자 정보 조회
↓
로그인 완료
```

실무에서도 거의 동일한 구조로 사용됩니다.

### 실제 코드

```java
MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
params.add("grant_type", "authorization_code");
params.add("client_id", clientId);
params.add("code", code);
```

### 예상 출력

```json
{
  "access_token":"eyJ...",
  "refresh_token":"abc..."
}
```

### 핵심 정리

- OAuth2 핵심은 Access Token 발급
- 로그인 자체보다 Token 관리가 중요
- 카카오, 네이버, 구글 모두 동일한 구조

## 3. HttpHeaders와 HttpEntity 활용 (`OAuth2 공통`)

### 설명

외부 API 호출 시 Header와 Body를 하나의 객체로 묶어서 전달합니다.

Spring에서는 HttpEntity를 사용합니다.

### 실제 코드

```java
HttpHeaders headers = new HttpHeaders();
headers.setContentType(MediaType.APPLICATION_JSON);

HttpEntity<?> entity =
    new HttpEntity<>(body, headers);
```

### 예상 출력

```http
Content-Type: application/json
Authorization: Bearer xxxx
```

### 핵심 정리

- HttpHeaders는 요청 헤더 생성
- HttpEntity는 Header + Body 묶음
- RestTemplate와 함께 자주 사용

## 4. Access Token과 Bearer 인증 (`GoogleCalendar`, `OAuth2 공통`)

### 설명

OAuth2 로그인 이후 발급된 Access Token으로 인증을 수행합니다.

대부분의 외부 API는 Bearer 인증 방식을 사용합니다.

### 실제 코드

```java
headers.setBearerAuth(
    googleTokenResponse.getAccess_token()
);
```

### 예상 출력

```http
Authorization: Bearer eyJhbGciOi...
```

### 핵심 정리

- Access Token은 사용자 인증 수단
- 로그인 이후 모든 API 호출에 사용
- Bearer 방식이 가장 일반적
