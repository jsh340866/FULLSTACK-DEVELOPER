## 1. 학습 목표

- 회귀 문제의 **표준 파이프라인 7단계**(문제정의 → 데이터 → EDA → 전처리 → 분할/학습 → 평가 → 내보내기)를 손으로 실행한다
- `LinearRegression`으로 **단순 선형회귀 → 다중 선형회귀**로 확장하며 특성이 늘 때 성능이 어떻게 변하는지 본다
- `MAE / RMSE / R²`의 의미를 구분하고, `statsmodels`의 **OLS로 계수의 통계적 유의성(p-value)** 까지 확인한다

---

## 2. 전체 한 줄 흐름

```
CSV 읽기 → 결측/상관 확인(EDA) → 결측 채우기 → y 분리 →
train_test_split → LinearRegression.fit → predict → MAE/RMSE/R² →
(특성 추가 · 원핫인코딩 · LightGBM으로 개선) → OLS로 유의성 검증
```

## 5. 데이터 전처리

### 5-1. 결측 컬럼을 타입별로 분리

```python
null_series = train.isnull().sum()

# 결측이 있으면서(object) 문자형인 컬럼 이름만
null_object_series  = null_series[(null_series>0) & (train.dtypes=='object')].index
# 결측이 있으면서(float64) 숫자형인 컬럼 이름만
null_float64_series = null_series[(null_series>0) & (train.dtypes=='float64')].index
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `(null_series>0)` | 결측이 **실제로 있는** 컬럼만 다루려고 | 결측 개수가 0보다 큰지 True/False 마스크 |
| `& (train.dtypes=='object')` | 문자형은 **최빈값**, 숫자형은 **중앙값**으로 채우는 전략이 달라서 | 두 조건을 동시에 만족(불리언 AND)하는 컬럼만 |
| `.index` | 채우기 반복문에 쓸 **컬럼 이름 목록**이 필요 | 조건을 통과한 컬럼의 이름(Index)만 추출 |

> `boolean indexing` = pandas 필터링의 핵심 패턴. `df[조건]` 형태로 조건에 맞는 것만 남긴다.

### 5-2. train 기준값으로 train·test를 함께 채우기

```python
num_cols = null_float64_series   # 숫자형
cat_cols = null_object_series    # 범주형

for c in num_cols:
    m = train[c].median()        # ⭐ train의 중앙값
    train[c] = train[c].fillna(m)
    test[c]  = test[c].fillna(m)

for c in cat_cols:
    m = train[c].mode()[0]       # ⭐ train의 최빈값
    train[c] = train[c].fillna(m)
    test[c]  = test[c].fillna(m)

print('남은 결측치:', train.isnull().sum().sum(), test.isnull().sum().sum())
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `train[c].median()` | 숫자형 결측은 극단값에 강한 **중앙값**으로 대체 | 그 컬럼의 중앙값 하나를 구한다 |
| `train[c].mode()[0]` | 범주형은 평균이 없으니 **가장 흔한 값**으로 대체. `[0]`은 최빈값이 여러 개일 수 있어 첫 번째만 | 최빈값(가장 자주 나온 범주) |
| **test도 train의 `m`으로 채움** | test 자체 통계로 채우면 **정보 누수(leakage)** 발생 → 반드시 train 기준 | 검증/실전에서 미래 정보가 새어들지 않게 하는 핵심 원칙 |

> **출력:** `남은 결측치: 0 0` → 전처리 완료.

### 5-3. 정답(y) 분리

```python
y = train['Item_Outlet_Sales']                        # 맞혀야 할 값
train = train.drop(columns=['Item_Outlet_Sales'])     # 특성에서 정답 제거
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `y = train['...']` | 모델에 "정답"을 따로 넘겨야 하므로 분리 | 타깃 컬럼만 Series로 뽑는다 |
| `train.drop(columns=[...])` | 정답이 특성에 남아 있으면 **답을 보고 답을 맞히는** 컨닝이 됨 | 지정 컬럼을 제거한 새 DataFrame 반환 |

## 6. 모델링 ①: 단순 선형회귀 (특성 1개)

```python
from sklearn.linear_model import LinearRegression
X1 = train[['Item_MRP']]                 # ⭐ 대괄호 2개 = 2차원(DataFrame)
lr1 = LinearRegression().fit(X1, y)
print('기울기:', round(lr1.coef_[0], 2), '| 절편:', round(lr1.intercept_, 2))
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `train[['Item_MRP']]` | sklearn은 X를 **2차원**으로 요구 (`[[ ]]` 필수) | 대괄호 1개는 1차원 Series, 2개는 2차원 DataFrame |
| `.fit(X1, y)` | 데이터에서 최적의 직선(기울기·절편)을 학습 | X와 y의 관계를 최소제곱으로 맞춘다 |
| `.coef_[0]` / `.intercept_` | 학습된 직선식을 눈으로 확인 | 기울기(가중치)와 절편 |

> **출력:** `기울기: 15.58 | 절편: 3.47`
> → **매출 ≈ 15.58 × MRP + 3.47**. 가격이 1 오르면 매출이 약 15.58 오른다는 뜻.

### 6-1. 검증 분할 후 평가

```python
from sklearn.model_selection import train_test_split
X_tr, X_val, y_tr, y_val = train_test_split(X1, y, test_size=0.2, random_state=0)
lr = LinearRegression().fit(X_tr, y_tr)
pred = lr.predict(X_val)
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `train_test_split(...)` | 학습에 안 쓴 데이터로 **일반화 성능**을 재려고 | 데이터를 학습용/검증용으로 쪼갠다 |
| `test_size=0.2` | 20%를 시험지로 남김 | 검증셋 비율 |
| `random_state=0` | 매번 같은 분할 → **재현 가능** | 난수 고정 씨앗 |
| **튜플 언패킹** `X_tr, X_val, y_tr, y_val =` | 한 번에 4개 반환값을 각 변수로 받음 | 반환된 4개 조각을 순서대로 변수에 할당 |

```python
import numpy as np
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
rmse = np.sqrt(mean_squared_error(y_val, pred))
print('MAE :', round(mean_absolute_error(y_val, pred), 1))
print('RMSE:', round(rmse, 1))
print('R2  :', round(r2_score(y_val, pred), 4))
```

| 지표 | 무슨 뜻인가 | 해석 |
|---|---|---|
| **MAE** | 예측이 평균적으로 얼마나 빗나갔나(절댓값 평균) | 작을수록 좋음, 단위가 매출과 같아 직관적 |
| **RMSE** | 오차를 제곱해 평균 후 루트 → **큰 오차에 민감** | 작을수록 좋음, 이상치에 민감 |
| **R²** | 모델이 매출 변동을 설명하는 비율(0~1) | 1에 가까울수록 좋음 |

> **실제 출력:** `MAE 996.6 | RMSE 1336.2 | R² 0.3123`
> → 특성 1개(MRP)만으론 매출 변동의 **약 31%만** 설명. 특성을 늘려야 한다.

## 7. 모델링 ②: 다중 선형회귀 (원핫인코딩으로 전 특성 사용)

```python
X = train.drop(columns=['Item_Identifier'])   # 식별용 ID는 예측에 무의미 → 제거
X_test = test.drop(columns=['Item_Identifier'])

all_oh = pd.get_dummies(pd.concat([X, X_test], axis=0))  # ⭐ train+test 합쳐 인코딩
X      = all_oh.iloc[:len(train)]     # 다시 train 부분
X_test = all_oh.iloc[len(train):]     # 다시 test 부분
print('결측:', X.isnull().sum().sum(), '| 컬럼:', X.shape[1])
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `drop(columns=['Item_Identifier'])` | 상품 고유 ID는 규칙성이 없어 학습에 방해 | 식별자 컬럼 제거 |
| `pd.get_dummies(...)` | 선형회귀는 숫자만 먹으므로 **문자 범주 → 0/1 컬럼**으로 변환 | 원핫인코딩(범주마다 컬럼 하나) |
| `pd.concat([X, X_test])` 후 인코딩 | train·test에 **같은 컬럼 집합**을 보장(한쪽에만 있는 범주 문제 방지) | 두 데이터를 세로로 붙여 함께 인코딩 |
| `.iloc[:len(train)]` / `.iloc[len(train):]` | 인코딩 후 다시 원래대로 분리 | 앞 train 길이만큼 / 그 이후로 잘라냄 |

> **출력:** `컬럼: 45` → 원핫으로 컬럼이 12개에서 45개로 늘어남.

```python
X_tr, X_val, y_tr, y_val = train_test_split(X, y, test_size=0.2, random_state=0)
lr = LinearRegression().fit(X_tr, y_tr)
pred = lr.predict(X_val)
# MAE 801.0 | RMSE 1060.3 | R2 0.5669
```

> **비교:** R² **0.31 → 0.57**로 상승. 특성을 늘리니 설명력이 크게 좋아졌다.

## 9. OLS로 계수의 통계적 유의성 검증

```python
import statsmodels.api as sm
Xc = sm.add_constant(train[['Item_MRP']])   # ⭐ 절편항 추가
ols = sm.OLS(y, Xc).fit()
print(ols.summary().tables[1])              # coef, p-value 표
```

| 코드 | 왜 썼는가 | 무슨 뜻인가 |
|---|---|---|
| `sm.add_constant(...)` | statsmodels는 절편을 **자동으로 안 넣어서** 직접 추가 | 값이 1인 상수 컬럼을 붙인다(절편 계산용) |
| `sm.OLS(y, Xc).fit()` | 계수뿐 아니라 **p-value 등 통계량**까지 얻으려고 | 최소제곱 회귀를 적합 |
| `.summary().tables[1]` | 계수·유의성 표만 콕 집어서 봄 | 요약표 중 계수 테이블 |

> **출력:** `Item_MRP coef 15.58, P>|t| 0.000` → **p < 0.05, 통계적으로 유의**.
> `const coef 3.47, P>|t| 0.934` → 절편은 유의하지 않음.
> **확인 포인트:** sklearn 기울기 15.58 = OLS coef 15.58 로 정확히 일치 → 두 도구가 같은 답을 낸다.

## 10. 오늘 배운 것 요약

- 회귀 파이프라인은 **읽기 → EDA → 전처리 → 분할 → 학습 → 평가**의 반복. 결측은 **train 기준값**으로 train·test를 함께 채워 누수를 막는다
- sklearn의 X는 **2차원**이어야 하고(`[[ ]]`), 문자 범주는 **원핫인코딩**으로 숫자화한다. train·test를 합쳐 인코딩해야 컬럼이 어긋나지 않는다
- 특성 1개(R² 0.31) → 여러 개(0.57)로 설명력이 크게 오르지만, **잘 고른 3개**면 전체와 거의 동등 → 특성 선택이 관건
- `MAE`(직관적), `RMSE`(큰 오차 민감), `R²`(설명력) 세 지표를 함께 본다
- **LightGBM**은 비선형을 잡아 소폭 개선(0.568 → 0.576), `OLS`는 계수의 **유의성(p-value)** 을 준다. sklearn 계수와 OLS 계수가 일치함을 확인
