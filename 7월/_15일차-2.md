## 1. 학습 목표

- **목적에 따라 그래프를 고르는 기준**을 잡는다 (변화 / 분포 / 관계)
- 그래프를 그리기 전에 **표(DataFrame)로 먼저 확인**하는 순서를 몸에 붙인다
- 같은 그래프라도 **무엇을 축·색에 놓느냐**에 따라 이진분류·다중분류·회귀를 진단할 수 있음을 익힌다

---

## 2. 핵심 원칙 — 그래프는 "목적"으로 고른다

| 알고 싶은 것 | 그래프 | 함수 | 축 배치 |
|---|---|---|---|
| 시간에 따른 **변화** | 선 그래프 | `plt.plot(x, y)` | x=시간, y=값 |
| 한 값의 **분포(퍼진 모양)** | 히스토그램 | `plt.hist(v, bins=20)` | x=값 구간, y=개수 |
| 두 값의 **관계** | 산점도 | `plt.scatter(x, y)` | x=원인 후보, y=결과 |

> 💡 그래프는 결국 **숫자 표를 그림으로 바꾼 것**이다. 그래서 항상 순서는 `표 확인(head·describe)` → `그래프`.

### 도구 + 예시 데이터 준비

```python
import numpy as np                                # 난수·수치 계산
import pandas as pd                               # 표(DataFrame)
import matplotlib.pyplot as plt                   # 그래프
%matplotlib inline                                # 노트북 안에 그림 출력

x = np.linspace(0, 10, 100)                       # 0~10을 100칸으로 (시간 흐름 흉내)
y = np.sin(x)                                     # 오르내리는 값
age = np.random.normal(35, 10, 500)               # 나이 500명 (평균 35, 표준편차 10)
ad_spend = np.random.uniform(100, 1000, 50)       # 광고비 50건 (100~1000 균등)
sales = ad_spend * 2.5 + np.random.normal(0, 500, 50)   # 매출 = 광고비×2.5 + 잡음
```

| 함수 | 하는 일 | 기억 포인트 |
|---|---|---|
| `np.linspace(0, 10, 100)` | 0~10을 **100등분한 배열** | 개수 지정 (간격 아님) |
| `np.random.normal(35, 10, 500)` | 정규분포 난수 | (평균, 표준편차, 개수) |
| `np.random.uniform(100, 1000, 50)` | 균등분포 난수 | (최소, 최대, 개수) |

> ⚠️ `np.random`에 **시드(seed)를 안 넣으면 실행할 때마다 값이 바뀐다**. 결과를 고정하려면 `np.random.seed(0)` — 1부의 `random_state=0`과 같은 역할이다.

## 3. 그리기 전에 표로 확인 (EDA)

```python
df = pd.DataFrame({'ad_spend': ad_spend, 'sales': sales})
print('데이터 크기(행, 열):', df.shape)           # (50, 2)
df.head()
df.describe().round(1)
```

**출력 (요약 통계)**

| 통계 | ad_spend | sales |
|---|---|---|
| count | 50.0 | 50.0 |
| mean | 484.4 | 1144.0 |
| std | 241.9 | 779.4 |
| min | 136.5 | **-639.6** |
| max | 974.0 | 2965.4 |

> ⚠️ **매출 최솟값이 음수(-639.6)** 로 나왔다. 잡음의 표준편차(500)가 너무 커서 생긴 값으로, 현실에는 존재할 수 없다. **합성 데이터는 물리적으로 말이 되는지 반드시 검토**해야 한다는 좋은 예. (`describe()`로 min/max를 먼저 보는 이유가 이것)

## 5. 히스토그램 — 한 값의 분포

```python
plt.hist(age, bins=20, color='skyblue', edgecolor='black')   # 구간 20개로 개수 세기
plt.axvline(age.mean(), color='red', linestyle='dashed')     # 평균 위치에 세로선
plt.title('Age distribution')
plt.xlabel('age')                                 # x = 나이(값 구간)
plt.ylabel('count')                               # y = 그 구간의 인원수
plt.show()
```

| 인자 | 역할 |
|---|---|
| `bins=20` | 구간(막대) 개수. **너무 적으면 뭉개지고, 너무 많으면 들쭉날쭉** |
| `edgecolor='black'` | 막대 경계선 → 붙어 있는 막대 구분 |
| `plt.axvline(값)` | 세로 기준선 (평균·중앙값 표시용) |

> 💡 히스토그램의 y축은 **값이 아니라 "개수"** 다. 막대 그래프(`plt.bar`)와 헷갈리기 쉬운 지점.

## 6. ★ 실전 (이진분류) — 클래스별 히스토그램

특성 하나를 **클래스별로 겹쳐 그리면**, 그 특성만으로 두 그룹이 갈리는지가 눈에 보인다.

```python
from sklearn.datasets import load_breast_cancer
bc = load_breast_cancer(as_frame=True).frame
print('데이터 크기:', bc.shape, '| target 0=악성, 1=양성')   # (569, 31)

for cls, name, color in [(0, 'malignant(0)', 'tomato'),
                         (1, 'benign(1)',    'steelblue')]:
    plt.hist(bc[bc['target'] == cls]['mean radius'],   # 그 클래스 행만 골라서
             bins=25, alpha=0.6, label=name, color=color)   # alpha=반투명 → 겹쳐 보임
plt.title('mean radius by class (breast cancer)')
plt.xlabel('mean radius'); plt.ylabel('count')
plt.legend()                                       # 범례 (색↔클래스 대응)
plt.show()
```

**결과 해석**

- 악성(빨강) 봉우리가 양성(파랑)보다 **오른쪽으로 치우침** → 악성일수록 세포핵 반지름이 크다
- 두 분포가 어느 정도 갈려 있음 → `mean radius`는 **분류에 도움이 되는 특성**

> 💡 이게 **특성 선택(feature selection)의 눈으로 하는 버전**이다. 겹침이 심한 특성은 그 특성만으론 분류에 약하다는 뜻.
> 💡 `alpha`(투명도)와 `label`+`legend`는 겹쳐 그리기의 필수 세트.

## 8. ★ 실전 (다중분류) — 종별 산점도, 색으로 그룹 구분

```python
from sklearn.datasets import load_iris
iris = load_iris(as_frame=True)
X, yv = iris.data, iris.target                    # X=특성 4개, yv=종(0/1/2)
print('데이터 크기:', X.shape, '| 종 이름:', list(iris.target_names))   # (150, 4)

sc = plt.scatter(X['petal length (cm)'], X['petal width (cm)'],
                 c=yv, cmap='viridis', alpha=0.8, s=40)   # c=종 → 색으로 구분
plt.xlabel('petal length (cm)'); plt.ylabel('petal width (cm)')
plt.title('Iris species by petal size')
plt.colorbar(sc, label='species (0/1/2)')          # 색막대
plt.show()
```

**결과 해석**

- 왼쪽 아래 한 무리(setosa)는 **완전히 분리** → 꽃잎 크기만으로 100% 구분 가능
- versicolor / virginica는 오른쪽 위에서 **살짝 겹침** → 이 두 종의 경계가 모델의 실제 난이도

> 💡 **`c=`는 "3번째 차원"이다.** 2D 산점도에 색을 얹으면 정보 하나를 더 보여줄 수 있다.
> ⚠️ `colorbar`는 원래 **연속값**용이다. 0/1/2 같은 범주에는 `legend`가 더 정확하다:
> ```python
> for i, name in enumerate(iris.target_names):
>     m = (yv == i)
>     plt.scatter(X.loc[m, 'petal length (cm)'], X.loc[m, 'petal width (cm)'], label=name)
> plt.legend()
> ```

## 9. ★ 실전 (회귀) — 산점도 + 추세선

회귀 = 정답이 **숫자(연속값)** 인 문제. 분류처럼 0/1이 아니다.

```python
from sklearn.datasets import load_diabetes
db = load_diabetes(as_frame=True)
bmi  = db.data['bmi']                             # 특성: 표준화된 BMI
prog = db.target                                  # 정답: 1년 뒤 질병 진행도(숫자)
print('데이터 크기:', db.data.shape)               # (442, 10)

plt.scatter(bmi, prog, alpha=0.5, s=25, color='seagreen')
m, b = np.polyfit(bmi, prog, 1)                   # 1차(직선) 맞추기 → 기울기 m, 절편 b
xs = np.linspace(bmi.min(), bmi.max(), 100)       # 직선을 그릴 x값들
plt.plot(xs, m * xs + b, color='red', linewidth=2)   # y = m*x + b
plt.xlabel('BMI (standardized)'); plt.ylabel('disease progression')
plt.title('Diabetes: BMI vs progression')
plt.show()
```

**결과 해석**

- 점들이 **우상향**으로 퍼지고 추세선도 오른쪽 위 → BMI가 클수록 진행도도 높은 **양의 관계**
- 다만 점의 흩어짐이 크다 → BMI 하나만으론 설명력이 부족, 다른 특성이 더 필요

| 코드 | 의미 |
|---|---|
| `np.polyfit(x, y, 1)` | **1차 다항식(직선) 회귀** → `(기울기, 절편)` 반환 |
| `np.polyfit(x, y, 2)` | 2차 곡선 (차수만 바꾸면 됨) |
| `m * xs + b` | 맞춘 직선의 y값 계산 |

> 💡 `np.polyfit`은 사실상 **최소제곱 선형회귀**다. `LinearRegression().fit()`과 같은 답을 준다 — 그림용 빠른 버전이라고 보면 된다.

## 11. 전체 흐름 한 줄 정리

```
표 확인 (head · describe)          ← 먼저 숫자로 본다
   │
   ▼
목적 정하기
   ├─ 변화  ▶ plt.plot     (x=시간)
   ├─ 분포  ▶ plt.hist     (+ 클래스별 겹쳐 그리기 → 분류 가능성 진단)
   └─ 관계  ▶ plt.scatter  (+ c=클래스 → 그룹 / + 추세선 → 회귀)
   │
   ▼
꾸미기: title · xlabel · ylabel · legend · grid
   │
   ▼
plt.show()   ← 반드시 마지막
```

## 12. 오늘 배운 것 요약 (2부)

- 그래프는 **목적으로 고른다**: 변화=선 / 분포=히스토그램 / 관계=산점도
- **표 → 그래프** 순서. `describe()`의 min/max로 말이 안 되는 값(음수 매출)을 먼저 잡아낸다
- 히스토그램의 y축은 값이 아니라 **개수**, `bins`가 해상도를 결정한다
- **클래스별로 겹쳐 그리면** 그 특성이 분류에 쓸모 있는지 눈으로 판별할 수 있다 (특성 선택의 시각 버전)
- 산점도의 `c=`는 **정보 한 겹을 더 얹는 3번째 차원** — 다중분류 진단에 유용
- `np.polyfit(x, y, 1)`로 추세선을 얹으면 회귀 관계의 방향·세기가 즉시 보인다
- 결국 **같은 그래프라도 무엇을 축과 색에 놓느냐**로 분류·회귀 문제를 들여다볼 수 있다
- 실무 함정 2개: **한글 폰트 깨짐**, **시드 미고정으로 매번 달라지는 난수**

### 1부와 이어지는 지점

1부에서 IsolationForest로 유방암 데이터의 이상치 29개를 찾았다. 2부의 클래스별 히스토그램을 쓰면 **그 29개가 분포의 어느 쪽 꼬리에 있는지** 를 눈으로 확인할 수 있다 — 숫자 판정과 그림 확인을 짝지으면 "이 이상치가 오류인지 신호인지" 판단이 훨씬 빨라진다.
