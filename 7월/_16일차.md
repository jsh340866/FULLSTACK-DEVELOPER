## 1. 학습 목표

- FastAPI로 **가장 작은 서버**를 띄우고 Docker로 컨테이너화한다 (`/health` 확인)
- **Pydantic 모델·CORS·경로/쿼리 파라미터** 등 API의 기본 입출력 패턴을 익힌다
- **SQLite**를 붙여 메모 데이터의 **CRUD(생성·조회·수정·삭제)** API를 완성한다

## 2. 01INIT — 최소 서버 세팅 (서버가 뜨는지 확인)

### 핵심 코드 (`main.py`)

```python
from fastapi import FastAPI

app = FastAPI(title="ML API 첫걸음")

@app.get("/health")          # GET /health 주소를 만든다
def health():
    return {"status": "UP"}  # dict 를 return 하면 자동으로 JSON
```

- `@app.get("/health")` : GET 요청을 받을 **주소(엔드포인트)** 를 만든다
- 함수가 **dict 를 return** 하면 FastAPI가 자동으로 **JSON** 으로 변환해준다

### Docker로 띄우기

```dockerfile
# Dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8001
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8001"]
```

```yaml
# docker-compose.yml
services:
  ml:
    build: .                # 지금 폴더의 Dockerfile 로 상자를 만든다
    container_name: ml_sample_1
    ports:
      - "8001:8001"         # 내 컴퓨터 8001 → 상자 안 8001
    restart: unless-stopped # 꺼지면 자동으로 다시 켜기
```

```bash
docker compose up --build     # 빌드 + 실행
# 확인: http://localhost:8001/health  →  {"status":"UP"}
# 자동 문서: http://localhost:8001/docs (Swagger UI)
```

> ⚠️ `ports: "8001:8001"` 은 `호스트:컨테이너` 순서. `--host 0.0.0.0` 이어야 컨테이너 밖에서 접속된다.

## 3. 02기본기능 — 요청/응답의 기본 패턴

### 3-1. CORS 허용 (React/Spring Boot에서 호출 가능하게)

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(CORSMiddleware, allow_origins=["*"],
                   allow_methods=["*"], allow_headers=["*"])
```

- 다른 출처(프론트엔드)에서 API를 부르려면 **CORS 허용**이 필요하다
- 실습용은 `["*"]`(전체 허용)이지만, 실제 배포에서는 특정 도메인만 허용하는 게 안전하다

### 3-2. 요청 본문(Body) 검증 — Pydantic

```python
from pydantic import BaseModel
from typing import Dict, Any

class PredictRequest(BaseModel):
    features: Dict[str, Any]   # {"gu": 3, "month": 6, ...}

@app.post("/predict")
def do_predict(req: PredictRequest):   # ← 자동으로 검증 + 문서화
    return {"받은_features": req.features}
```

- `BaseModel` 을 상속해 **요청 본문의 모양(스키마)** 을 미리 선언한다
- 타입이 안 맞으면 FastAPI가 **자동으로 422 에러 + 검증**을 해주고, **Swagger 문서**에도 반영된다

### 3-3. 경로 파라미터 vs 쿼리 파라미터

```python
# 경로 파라미터: 주소의 일부를 변수로 받는다
@app.get("/predictions/{pid}")     # /predictions/3  →  pid = 3
def get_one(pid: int):
    return {"요청한_id": pid}

# 쿼리 파라미터: 주소 뒤 ?이름=값 (기본값 지정 가능)
@app.get("/predictions")           # /predictions?limit=10  →  limit = 10
def list_all(limit: int = 50):     # 안 주면 50
    return {"최대개수": limit}
```

| 구분 | 형태 | 예시 | 용도 |
|---|---|---|---|
| 경로 파라미터 | `/{변수}` | `/predictions/3` | 특정 자원 지목 (단건 조회 등) |
| 쿼리 파라미터 | `?이름=값` | `/predictions?limit=10` | 필터·개수 등 부가 조건 (기본값 가능) |

### 3-4. 설정 파일로 폼 자동 생성 (`feature_spec.json`)

```python
import json
spec = json.load(open("feature_spec.json", encoding="utf-8"))

@app.get("/spec")
def get_spec():
    """입력 항목 정의(라벨·선택지) - FN(프론트) 폼 자동 생성에 사용"""
    return spec
```

```json
{
  "title": "구별 수요 예측 모델",
  "features": [
    { "name": "gu", "label": "자치구", "type": "select",
      "options": [ {"value":1,"text":"강남구"}, {"value":2,"text":"강동구"}, {"value":3,"text":"강북구"} ] },
    { "name": "month", "label": "월", "type": "number", "min": 1, "max": 12 }
  ]
}
```

- 입력 항목 정의를 **코드가 아닌 JSON 파일**로 분리 → 프론트엔드가 `/spec` 을 읽어 **입력 폼을 자동 생성**할 수 있다
- 항목이 바뀌어도 **JSON만 수정**하면 되므로 유지보수가 쉽다

## 4. 03CRUD — SQLite로 진짜 데이터 다루기

### 전체 구조

```
main.py  (API 엔드포인트: POST/GET/PUT/DELETE)
   │  호출
   ▼
store.py (DB 로직: init_db / create / get / list_all / update / delete)
   │
   ▼
memos.db (SQLite 파일 — 서버를 꺼도 데이터가 남는다)
```

> 💡 처음엔 `memos = []` 처럼 **메모리(리스트)** 에 저장 → 서버를 끄면 사라진다.
> 그래서 **SQLite 파일 DB**로 바꿔 데이터를 영구 저장한다.

### 4-1. DB 준비 (`store.py`)

```python
import sqlite3
DB_PATH = "memos.db"   # DB 는 파일 하나로 생긴다

def _con():
    con = sqlite3.connect(DB_PATH)
    con.row_factory = sqlite3.Row  # 결과를 dict 처럼 쓰기 위함
    return con

def init_db():   # 앱 시작 시 1회 — 테이블 생성
    con = _con()
    try:
        con.execute("""
            CREATE TABLE IF NOT EXISTS memos (
                id         INTEGER PRIMARY KEY AUTOINCREMENT,
                text       TEXT NOT NULL,
                created_at TEXT NOT NULL
            )
        """)
        con.commit()
    finally:
        con.close()
```

- `CREATE TABLE IF NOT EXISTS` : 이미 있으면 건너뛰므로 **여러 번 실행해도 안전**
- `?` **플레이스홀더**로 값을 넣어 **SQL 인젝션을 예방**한다 (문자열 직접 조합 ❌)
- 연결은 `try / finally` 로 **항상 close** 한다

### 4-2. CRUD 4대 동작 (HTTP 메서드 ↔ 함수)

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
import store
store.init_db()

app = FastAPI()

class Memo(BaseModel):
    text: str

@app.post("/memos", status_code=201)   # C : 생성 (201 Created)
def create_memo(m: Memo):
    return store.create(m.text)

@app.get("/memos")                      # R : 목록
def list_memos():
    return store.list_all()

@app.get("/memos/{mid}")                # R : 단건
def get_memo(mid: int):
    return store.get(mid)

@app.put("/memos/{mid}")                # U : 수정
def update_memo(mid: int, m: Memo):
    return store.update(mid, m.text)

@app.delete("/memos/{mid}")             # D : 삭제
def delete_memo(mid: int):
    return store.delete(mid)
```

| 동작 | HTTP 메서드 | 주소 | store 함수 |
|---|---|---|---|
| Create (생성) | POST | `/memos` | `store.create()` |
| Read (목록) | GET | `/memos` | `store.list_all()` |
| Read (단건) | GET | `/memos/{mid}` | `store.get()` |
| Update (수정) | PUT | `/memos/{mid}` | `store.update()` |
| Delete (삭제) | DELETE | `/memos/{mid}` | `store.delete()` |

> ⚠️ `status_code=201` : 생성 성공은 관례상 **201 Created** 를 돌려준다.
> ⚠️ 없는 자원을 조회/수정/삭제하면 `raise HTTPException(404, ...)` 로 **404** 를 반환하는 게 정석 (실습 코드엔 개선 여지 있음).

## 5. 오늘 배운 것 요약

- FastAPI는 **함수가 dict 를 return** 하면 자동으로 **JSON** 을 만들고, `/docs` **Swagger 문서**도 자동 생성한다
- **Pydantic 모델**로 요청 본문을 선언하면 **자동 검증 + 문서화**가 된다
- 주소로 값 받기: **경로 파라미터(`/{id}`)** 는 자원 지목, **쿼리 파라미터(`?limit=`)** 는 부가 조건
- 프론트 연동 대비: **CORS 허용** + 입력 정의를 **`feature_spec.json`** 으로 분리해 **폼 자동 생성** 기반 마련
- 데이터 영속화: 메모리 리스트(휘발) → **SQLite 파일 DB**, `store.py` 로 DB 로직을 분리하고 **CRUD ↔ POST/GET/PUT/DELETE** 를 매핑했다
