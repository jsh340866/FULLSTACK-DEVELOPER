# 1. React Router로 로그인 화면 구성 (`FN/src/App.js`)

### 설명

React Router를 이용하여 로그인, 로그아웃, 회원가입 등의 페이지를 구성했습니다.

---

### 실제 코드

```jsx
<Routes>
    <Route path="/" element={<Main />} />
    <Route path="/login" element={<Login />} />
    <Route path="/logout" element={<Logout />} />
    <Route path="/join" element={<Join />} />
    <Route path="/user" element={<User />} />
</Routes>
```

---

### 코드 설명

| 코드        | 설명          |
| --------- | ----------- |
| `Routes`  | URL별 화면 연결  |
| `Route`   | 컴포넌트 매핑     |
| `/login`  | 로그인 페이지     |
| `/logout` | 로그아웃 처리 페이지 |

---

### 한 줄 흐름

```
사용자 클릭
      ↓
React Router
      ↓
Login / Logout 화면 이동
```

---

### 예상 출력

```
MAIN | USER | JOIN | LOGIN | LOGOUT
```

---

### 핵심 포인트

* React Router가 화면 이동을 담당
* URL에 따라 로그인/로그아웃 컴포넌트 실행

---

# 2. 로그인 요청 보내기 (`FN/src/components/Login.jsx`)

### 설명

사용자가 입력한 아이디와 비밀번호를 Axios로 Spring Boot `/login`에 전송했습니다.

---

### 실제 코드

```jsx
await axios.post(
    "http://localhost:8080/login",
    { username, password },
    {
        headers:{ "Content-Type":"application/json" },
        withCredentials:true
    }
);
```

---

### 코드 설명

| 코드                | 설명            |
| ----------------- | ------------- |
| `axios.post()`    | POST 요청       |
| `username`        | 아이디 전달        |
| `password`        | 비밀번호 전달       |
| `withCredentials` | 쿠키(JWT) 함께 전달 |

---

### 한 줄 흐름

```
아이디 입력
      ↓
Axios POST
      ↓
Spring Boot 로그인
      ↓
JWT 발급
```

---

### 예상 출력

```
LOGIN PAGE

USERNAME
PASSWORD

LOGIN
```

로그인 성공 시

```
메인 페이지 이동
```

---

### 핵심 포인트

* 로그인은 POST 요청으로 수행
* JSON 형태로 사용자 정보를 전달
* `withCredentials`를 통해 인증 쿠키를 함께 주고받음

---

# 3. 로그인 상태 확인 (`FN/src/components/Login.jsx`)

### 설명

페이지가 열리면 현재 JWT가 유효한지 먼저 검사했습니다.

---

### 실제 코드

```jsx
useEffect(() => {
    axios.get(
        "http://localhost:8080/validate",
        { withCredentials:true }
    );
}, []);
```

---

### 코드 설명

| 코드              | 설명               |
| --------------- | ---------------- |
| `useEffect`     | 컴포넌트 최초 실행       |
| `/validate`     | 토큰 검증 요청         |
| `navigate("/")` | 이미 로그인 상태면 메인 이동 |

---

### 한 줄 흐름

```
페이지 진입
      ↓
토큰 검사
      ↓
유효
      ↓
메인 이동
```

---

### 예상 출력

```
토큰검증성공
→ 메인 페이지
```

또는

```
토큰검증실패
→ 로그인 유지
```

---

### 핵심 포인트

* 로그인 페이지 진입 시 중복 로그인 방지
* JWT가 살아있으면 다시 로그인할 필요 없음

---

# 4. 로그아웃 처리 (`FN/src/components/Logout.jsx`)

### 설명

로그아웃 페이지에 진입하면 Spring Boot의 `/logout`을 호출하여 인증 정보를 삭제했습니다.

---

### 실제 코드

```jsx
await axios.post(
    "http://localhost:8080/logout",
    {},
    { withCredentials:true }
);

navigate("/login");
```

---

### 코드 설명

| 코드                | 설명        |
| ----------------- | --------- |
| `/logout`         | 로그아웃 요청   |
| `withCredentials` | 쿠키 전달     |
| `navigate()`      | 로그인 화면 이동 |

---

### 한 줄 흐름

```
Logout 진입
      ↓
POST /logout
      ↓
JWT 삭제
      ↓
Login 이동
```

---

### 예상 출력

```
LOGOUT PAGE

로그아웃 처리중...
```

이후

```
LOGIN PAGE
```

---

### 핵심 포인트

* 로그아웃 성공 여부와 관계없이 로그인 화면으로 이동
* 서버에서 Refresh Token 및 인증 쿠키 제거

---

# 5. Spring Security 인증 처리 (`BN/src/main/java/com/example/demo/Config/SecurityConfig.java`)

### 설명

Spring Security가 로그인, JWT 인증, 로그아웃을 모두 관리하도록 설정했습니다.

---

### 실제 코드

```java
http
    .csrf(csrf -> csrf.disable())
    .cors(cors -> {})
    .sessionManagement(
        session ->
            session.sessionCreationPolicy(
                SessionCreationPolicy.STATELESS
            )
    );
```

---

### 코드 설명

| 코드               | 설명           |
| ---------------- | ------------ |
| `csrf.disable()` | CSRF 비활성화    |
| `cors()`         | React 요청 허용  |
| `STATELESS`      | 세션 대신 JWT 사용 |

---

### 한 줄 흐름

```
React 요청
      ↓
Spring Security
      ↓
JWT 검사
      ↓
인증 완료
```

---

### 예상 출력

```
JWT 인증 성공
```

---

### 핵심 포인트

* 세션을 사용하지 않는 Stateless 방식
* 모든 인증을 JWT 기반으로 처리

---

# 6. 로그인 API와 사용자 인증 (`BN/src/main/java/com/example/demo/Controller/UserRestController.java`)

### 설명

React에서 전달한 로그인 정보를 받아 인증을 수행하고 JWT 발급 과정을 진행했습니다.

---

### 실제 코드

```java
@PostMapping("/login")
```

```java
Authentication authentication =
    authenticationManager.authenticate(...);
```

---

### 코드 설명

| 코드                 | 설명               |
| ------------------ | ---------------- |
| `@PostMapping`     | 로그인 요청 처리        |

| `RedisUtil`        | Refresh Token 저장 |

---

### 한 줄 흐름

```
React 로그인 요청
      ↓
AuthenticationManager
      ↓
사용자 인증
      ↓
JWT 생성
      ↓
React 응답
```

---

### 예상 출력

```
로그인 성공
JWT 발급 완료
```

---

### 핵심 포인트

* AuthenticationManager가 사용자 인증 담당
* JWT와 Refresh Token을 생성하여 로그인 유지

# 7. React ↔ Spring Boot 인증 전체 흐름

### 설명

오늘 수업의 핵심은 React와 Spring Boot가 JWT를 이용하여 로그인부터 로그아웃까지 하나의 인증 흐름으로 연결되는 과정을 이해하는 것이었습니다.

---

### 한 줄 흐름

```
React 로그인 요청
        →
Spring Security 인증
        →
JWT 발급
        →
브라우저 쿠키 저장
        →
API 요청 시 JWT 자동 전달
        →
Spring Security JWT 검증
        →
인증된 사용자 접근 허용
        →
로그아웃 요청
        →
Refresh Token 삭제 + 쿠키 제거
        →
로그인 화면 이동
```

---

### 핵심 포인트

* React는 화면과 요청만 담당
* Spring Security가 인증과 권한을 처리
* JWT로 로그인 상태를 유지
* `withCredentials`를 통해 인증 쿠키를 자동 전송
* 로그아웃 시 서버와 브라우저의 인증 정보를 함께 제거

---

# 오늘 핵심 정리

* React Router로 로그인/로그아웃 화면을 구성했다.
* Axios를 이용하여 Spring Boot 로그인 API와 통신했다.
* JWT를 발급받아 인증을 처리하는 구조를 이해했다.
* `withCredentials`를 사용하여 인증 쿠키를 주고받았다.
* Spring Security가 JWT 검증과 사용자 인증을 담당했다.
* 로그아웃 시 Refresh Token과 쿠키를 제거하여 인증을 종료했다.
