## 2. 파이썬 기초 — 변수와 자료구조

### 2-1. 변수와 자료형

```python
age = 25            # 정수 int
height = 173.5      # 실수 float
name = '홍길동'      # 문자열 str
is_student = True   # 불리언 bool
print(type(age))    # <class 'int'>
```

| 자료형 | 예시 | 용도 |
|---|---|---|
| `int` | `25` | 개수, 나이 등 정수 |
| `float` | `173.5` | 측정값, 확률, 정확도 |
| `str` | `'홍길동'` | 텍스트 데이터 |
| `bool` | `True` / `False` | 조건, 필터 결과 |

### 2-2. f-string — 변수를 문자열에 삽입

```python
score = 92
print(f'{name}님의 점수는 {score}점입니다.')
print(f'평균과의 차이: {score - 80}점')      # 중괄호 안에서 연산도 가능

# 포맷 지정 (ML 평가 출력에서 필수)
acc = 0.85283
print(f'정확도: {acc:.4f}')   # 0.8528 (소수 4자리)
print(f'정확도: {acc:.1%}')   # 85.3% (퍼센트)
```

### 2-3. 리스트 — 순서가 있는 값 모음

```python
scores = [90, 85, 77, 60, 100]
scores[0]      # 90   (인덱스는 0부터)
scores[-1]     # 100  (음수는 뒤에서부터)
scores[0:3]    # [90, 85, 77]  (슬라이싱, 끝 인덱스 제외)
len(scores)    # 5
scores.append(88)   # 값 추가
```

### 2-4. 딕셔너리 — 키:값 쌍

```python
person = {'이름': '홍길동', '나이': 25, '점수': 92}
person['이름']          # 키로 값 꺼내기
person.keys()           # 키 목록
person.values()         # 값 목록
person['합격'] = True    # 새 키 추가

# 안전 접근: 없는 키도 에러 없이
d = {'age': 25}
d.get('city')           # None (에러 안 남)
d.get('city', '서울')    # 없으면 기본값 '서울'
```

### 2-5. 튜플과 중첩 자료구조

```python
# 튜플: 수정 불가한 값 묶음 → 함수 다중 반환의 정체
point = (3, 5)
x, y = point            # 언패킹

# 리스트 안 딕셔너리 = DataFrame의 재료
rows = [{'이름': '홍길동', '점수': 90}, {'이름': '김철수', '점수': 85}]
rows[0]['이름']          # '홍길동'
```

> 💡 `[{...}, {...}]` 구조는 pandas `DataFrame`으로 바로 변환되는 형태라 눈에 익혀두면 좋다.

## 3. 파이썬 기초 — 제어문과 함수

### 3-1. 조건문 if / elif / else

```python
score = 82
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
else:
    grade = 'C'
# 82점 → B
```

### 3-2. 반복문 for / while

```python
for s in scores:          # 리스트 순회
    print('점수:', s)
for i in range(3):        # 0, 1, 2
    print('반복', i)

n = 3
while n > 0:              # 조건이 참인 동안
    print(n)
    n = n - 1             # ⚠️ 조건을 바꾸지 않으면 무한 반복
```

### 3-3. 연산자 정리

```python
7 // 3, 7 % 3, 2 ** 3        # 몫 2, 나머지 1, 거듭제곱 8
3 == 3, 3 != 5, 5 >= 5       # 비교 → True/False
True and False, not True     # 논리 연산
90 in [90, 85]               # 멤버십 검사 → True
```

### 3-4. 함수 정의

```python
def get_grade(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    return 'C'

# 기본값 인자 — ML 라이브러리 사용법의 핵심
def make_user(name, age=20, city='서울'):
    return f'{name} / {age}세 / {city}'
make_user('홍길동')                       # 기본값 사용
make_user('김철수', age=30, city='부산')  # 이름=값 지정
```

> 💡 `RandomForestClassifier(random_state=0)`, `train_test_split(test_size=0.2)` 처럼 ML 코드의 옵션 지정이 전부 이 **키워드 인자** 문법이다.

### 3-5. 다중 반환과 언패킹

```python
def min_max(nums):
    return min(nums), max(nums)     # 튜플로 2개 반환
low, high = min_max([3, 7, 1, 9])   # 언패킹
```

> 💡 `X_train, X_val, y_train, y_val = train_test_split(X, y)` 가 바로 이 패턴 — 4개 반환값을 한 번에 나눠 받는 것.

### 3-6. 리스트 컴프리헨션 — 한 줄 필터/변환

```python
scores = [90, 85, 77, 60]
passed = [s for s in scores if s >= 80]   # [90, 85]  조건 필터
doubled = [s * 2 for s in scores]          # 각 값 변환
```

## 5. NumPy — 배열(ndarray) 기초

### 왜 NumPy인가?

- 파이썬 리스트보다 **훨씬 빠른 수치 연산** (C로 구현)
- pandas, scikit-learn 등 모든 ML 라이브러리의 데이터가 결국 NumPy 배열
- **반복문 없이** 배열 전체에 연산을 적용 (벡터 연산)

### 5-1. 배열 생성

```python
import numpy as np
a = np.array([1, 2, 3, 4])   # 리스트 → 배열
np.zeros(3)                  # [0. 0. 0.]
np.ones(3)                   # [1. 1. 1.]
np.arange(0, 10, 2)          # [0 2 4 6 8]  (0~10 미만, 2씩)
```

### 5-2. 배열 속성

| 속성 | 의미 | 예시 결과 |
|---|---|---|
| `a.shape` | 크기(행, 열) | `(4,)` / `(2, 3)` |
| `a.ndim` | 차원 수 | `1` / `2` |
| `a.dtype` | 원소 타입 | `int64` |

### 5-3. 인덱싱과 슬라이싱

```python
a = np.array([10, 20, 30, 40, 50])
a[0], a[-1], a[1:4]      # 10, 50, [20 30 40]

m = np.array([[1, 2, 3],
              [4, 5, 6]])   # shape (2, 3)
m[0]        # [1 2 3]   첫 행
m[0, 2]     # 3         0행 2열
m[:, 1]     # [2 5]     모든 행의 1번 열
```

> 💡 `m[:, 1]` 패턴은 `pred[:, 1]` — 예측 확률에서 '양성(1)일 확률' 열만 뽑을 때 그대로 쓰인다.

### 5-4. 벡터 연산 — 반복문 없이 한 번에

```python
a = np.array([1, 2, 3, 4])
a * 2       # [2 4 6 8]      각 원소에 곱
a + 10      # [11 12 13 14]
a + a       # [2 4 6 8]      같은 위치끼리
a.mean()    # 2.5
```

### 5-5. 불리언 인덱싱 — 조건 필터

```python
a = np.array([10, 25, 30, 5, 40])
a > 20        # [False  True  True False  True]
a[a > 20]     # [25 30 40]  ← 조건이 True인 값만
```

> 💡 pandas의 `df[df['Age'] > 20]` 필터링이 바로 이 원리다.

### 5-6. axis 집계 — 방향을 정한 계산

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])
m.sum()          # 21       전체 합
m.sum(axis=0)    # [5 7 9]  열별 합 (세로 방향)
m.sum(axis=1)    # [6 15]   행별 합 (가로 방향)
m.mean(), m.max(), m.std()   # 평균, 최대, 표준편차
```

> ⚠️ `axis=0`은 **세로(행을 따라 내려가며)**, `axis=1`은 **가로(열을 따라 옆으로)** — 헷갈리기 쉬우니 "없어지는 축"이 axis라고 기억하면 편하다.

### 5-7. reshape — 모양 바꾸기

```python
a = np.arange(6)        # [0 1 2 3 4 5]
a.reshape(2, 3)         # 2행 3열
a.reshape(3, 2)         # 3행 2열
a.reshape(-1, 1)        # -1 = 자동 계산 → 6행 1열
```

> 💡 `reshape(-1, 1)`은 sklearn에 1차원 데이터를 넣을 때 "2차원으로 바꿔라"는 에러 해결에 항상 등장한다.

## 6. 오늘 배운 것 요약

- 파이썬의 **4대 기본형(int/float/str/bool)** 과 **리스트·딕셔너리·튜플**, 그리고 `[{...}, {...}]` 중첩 구조가 DataFrame의 재료임을 확인했다
- **if/for/while + 함수 + 리스트 컴프리헨션**으로 데이터를 필터·변환하는 기본기를 다졌다
- **키워드 인자, 다중 반환·언패킹, enumerate/zip, sorted+lambda** 는 ML 코드에서 그대로 반복되는 핵심 패턴이다
- NumPy는 **벡터 연산 + 불리언 인덱싱 + axis 집계 + reshape** 네 가지가 핵심 — 반복문 없이 배열 전체를 다루는 사고방식이 pandas/sklearn으로 그대로 이어진다
