================================================
정처기 실기 SQL 작성형 정리 (1·2세트)
================================================

[핵심 뼈대 5개]

1) 테이블 생성 + 제약조건
CREATE TABLE t (
    c INT PRIMARY KEY,
    ...,
    FOREIGN KEY (c) REFERENCES p(c) ON DELETE CASCADE
);

2) 테이블 수정
ALTER TABLE t ADD ... / MODIFY ... / DROP COLUMN ...;

3) 삽입
INSERT INTO t (c1, c2) VALUES (v1, v2);

4) 권한 부여/회수
GRANT SELECT ON t TO user WITH GRANT OPTION;
REVOKE SELECT ON t FROM user CASCADE;

5) 조회 어순 (고정)
SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY ...;

------------------------------------------------

Q1. 테이블 생성 (제약조건 풀세트)
조건: 사원번호 정수·기본키 / 이름 가변문자20·빈값불가 /
      급여 정수·기본값3000 / 부서코드 문자3자리·부서 참조·삭제시 NULL

CREATE TABLE 사원 (
    사원번호 INT PRIMARY KEY,
    이름 VARCHAR(20) NOT NULL,
    급여 INT DEFAULT 3000,
    부서코드 CHAR(3),
    FOREIGN KEY (부서코드) REFERENCES 부서(부서코드) ON DELETE SET NULL
);

* 각 컬럼 정의 뒤 콤마, 마지막만 제외
* "삭제 시 NULL" = ON DELETE SET NULL / "함께 삭제" = ON DELETE CASCADE
* REFERENCES 테이블(컬럼) - 컬럼명 괄호 필수

------------------------------------------------

Q2. 테이블 수정 (ALTER 3종)

ALTER TABLE 사원 ADD 이메일 VARCHAR(50);        <- 추가
ALTER TABLE 사원 MODIFY 이름 VARCHAR(40);       <- 자료형 변경
ALTER TABLE 사원 DROP COLUMN 급여;              <- 삭제

* 추가 ADD / 변경 MODIFY / 삭제 DROP COLUMN
* COLUMN은 DROP에만 붙음

------------------------------------------------

Q3. 유니크 인덱스

CREATE UNIQUE INDEX email_idx ON 사원(이메일);

* 어순 고정: CREATE [UNIQUE] INDEX 인덱스명 ON 테이블명(컬럼명)
* "중복 불가" = UNIQUE (SELECT의 DISTINCT와 혼동 주의)

------------------------------------------------

Q4. 뷰 + 갱신 제한

CREATE VIEW v_고액연봉 AS
SELECT 사원번호, 이름 FROM 사원 WHERE 급여 >= 5000
WITH CHECK OPTION;

* "조건 위반 데이터 입력 방지" = WITH CHECK OPTION

------------------------------------------------

Q5. INSERT (일부 컬럼)

INSERT INTO 사원 (사원번호, 이름) VALUES (101, '박영희');

* 일부 컬럼만 넣을 땐 컬럼 목록 필수, 나머지는 DEFAULT/NULL
* INSERT INTO - INTO 누락 주의, 문자값 작은따옴표

------------------------------------------------

Q6. UPDATE + 조건

UPDATE 사원 SET 급여 = 급여 * 1.1 WHERE 부서코드 = 'D01';

* SET = 바꿀 값 / WHERE = 대상 행 (역할 반전 주의)
* 자기 값 기반 갱신: SET 급여 = 급여 * 1.1

------------------------------------------------

Q7. JOIN ~ ON

SELECT 사원.이름, 부서.부서명
FROM 사원 JOIN 부서 ON 사원.부서코드 = 부서.부서코드;

* 동명 컬럼 존재 시 테이블명.컬럼명 접두사 필수
* SELECT 절 컬럼 나열 사이 콤마 확인

------------------------------------------------

Q8. GRANT / REVOKE

GRANT SELECT, UPDATE ON 사원 TO LEE;
REVOKE UPDATE ON 사원 FROM LEE;

* GRANT는 TO, REVOKE는 FROM
* "재부여 불가" = WITH GRANT OPTION을 안 붙이는 것 (기본값)

================================================
감점 체크리스트 (검산 루틴)
================================================

1. 나열 항목 사이 콤마 (컬럼 정의 / SELECT 절 / 권한 목록)
2. INSERT INTO - INTO 누락
3. DROP COLUMN - COLUMN 누락
4. REFERENCES 테이블(컬럼) - 컬럼 괄호 누락
5. ON DELETE - FOREIGN KEY 안에서는 CASCADE 단독 불가
6. GRANT TO / REVOKE FROM 혼동
7. WHERE 누락 (UPDATE/DELETE 전체 행 적용 사고)
