

오라클 데이터베이스에서 내일 날짜를 조회하는 방법으로 올바른 것은?
답안과 정답

1번
SELECT TO_CHAR(SYSDATE-1, 'YYYYMMDD')
FROM DUAL;
2번
내 답안
SELECT TO_DATE(SYSDATE-1, 'YYYYMMDD')
FROM DUAL;
3번
정답
SELECT TO_CHAR(SYSDATE+1, 'YYYYMMDD')
FROM DUAL;
4번
SELECT TO_DATE(SYSDATE+1, 'YYYYMMDD')
FROM DUAL;

###
정답 : 3번
💡 왜 3번이 정답일까요?
오라클에서 "내일 날짜"를 구하려면 현재 날짜와 시간을 의미하는 SYSDATE에 +1을 해주어야 해요!

SYSDATE : 오늘 날짜
SYSDATE - 1 : 어제 날짜 (1일을 뺌)
SYSDATE + 1 : 내일 날짜 (1일을 더함) 🌟
따라서 '내일'을 구하는 연산은 +1이 들어간 3번과 4번 중에 나와야 해요.

❌ 2번 답안이 오답인 이유와 TO_CHAR vs TO_DATE 차이점
승원님께서 고르신 2번은 '날짜 계산 방향(-1)'과 '형변환 함수 선택' 두 가지 이유 때문에 오답이 되었어요.
① 날짜 계산 방향 오류 (-1)
SYSDATE - 1을 하게 되면 내일이 아니라 어제 날짜가 나오게 된답니다.

② 함수 선택 오류 (TO_DATE 사용)
SYSDATE + 1의 결과는 이미 날짜(DATE) 데이터 타입이에요.
- TO_CHAR(날짜, '포맷'): 날짜 데이터를 문자로 예쁘게 출력할 때 사용해요. (3번이 정답인 이유!)
- TO_DATE(문자, '포맷'): '20260518' 같은 문자열을 날짜 데이터로 바꿀 때 사용해요. 날짜 타입인 SYSDATE를 첫 번째 인자로 넣으면 오라클이 내부적으로 문자로 바꿨다 다시 날짜로 바꾸는 과정에서 에러(오류)가 발생하거나 엉뚱한 값이 나올 수 있어요.

# TO_CHAR(SYSDATE+1, 'YYYYMMDD')

다음 SQL문 중에서 결괏값이 다른 하나는?
답안과 정답

1번
SELECT CONCAT('0', '5')
FROM DUAL
2번
SELECT TRIM('05')
FROM DUAL
3번
정답
SELECT EXTRACT(MONTH
FROM DATE '2022 - 05 - 01')
FROM DUAL;
4번
내 답안
SELECT SUBSTR(TO_CHAR ('20220504'), 5,2)
FROM DUAL

###
정답 : 3번

💡 핵심 요약: 왜 3번만 결괏값이 다를까요?
이 문제의 핵심은 "문자열 '05'인가, 아니면 숫자 5인가!"의 차이예요.
1번, 2번, 4번의 결과: 모두 '05' (앞에 0이 붙은 문자열)

3번(정답)의 결과: 5 (앞에 0이 없는 숫자)

3번 (정답): SELECT EXTRACT(MONTH FROM DATE '2022-05-01') FROM DUAL;
해설: EXTRACT(MONTH FROM ...) 함수는 날짜 데이터에서 '월' 정보를 숫자형(NUMBER)으로 추출해 주는 함수예요.

결과: 2022년 5월 1일에서 월을 추출하면 문자가 아니라 순수한 숫자 5가 돼요! 오라클에서 숫자는 앞에 0을 붙여서 05로 표현하지 않고 그냥 5로 출력하기 때문에, 이 보기만 결괏값이 다릅니다. 🌟
