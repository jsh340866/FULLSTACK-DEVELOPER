
- ROUND(a,b) : b까지 반올림
- TRUNC(a,b) : b이하 버림
- TO_DATE('2024/05', 'YYYY/MM') : 2024/05/01, 1일부터 시작
- LAST_DAY(TO_DATE('2024/05/14', 'YYYY/MM/DD')) : 2024/05/31, 마지막날 31일
- LAG(컬럼, n, 기본값) : 뒤를 돌아봐!
	- 컬럼: 가져올 데이터가 있는 컬럼
	- n (오프셋): 몇 번째 이전 행을 가져올지 지정 (이번 문제에서는 2)
	- 기본값: 이전 행이 없을 때 표시할 값 (생략 시 NULL)
- ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW: 
	- 윈도우의 범위를 "해당 파티션의 시작점부터 현재 읽고 있는 행까지"로 지정하는 규칙이에요.
	- RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW : 
		- 기본값 (RANGE)
		- 동작 자체는 ROWS랑 비슷하지만 정렬 기준 값이 같은 행들은 누적 합계 수치가 똑같이 나와버림
- WHERE V1 NOT IN (SELECT V1 FROM TAB2);
	- NOT IN 은 같은 값이 있는지 확인
	- 단, NULL값이 하나라도 있으면 데이터를 읽을수없다.

- WHERE V1 NOT EXISTS (SELECT V1 FROM TAB2);
	- NOT EXISTS 는 같은 값이 잇는지 확인
	- NULL값이 있어도 빈값으로 데이터를 출력
- SELECT COL1, COL2, COL3, NTILE(3)
  OVER(ORDER BY COL3) AS NTILE2
  FROM Mytest
	- Mytest의 정보를 가져와 NTILE2라는 이름으로 col3을 기준으로 co1,co2,co3에 나온 데이터 행 수를 3으로 나눠 분배해라
