
- ROUND(a,b) : b까지 반올림
- TRUNC(a,b) : b이하 버림
- TO_DATE('2024/05', 'YYYY/MM') : 2024/05/01, 1일부터 시작
- LAST_DAY(TO_DATE('2024/05/14', 'YYYY/MM/DD')) : 2024/05/31, 마지막날 31일
- LAG(컬럼, n, 기본값) : 뒤를 돌아봐!
	- 컬럼: 가져올 데이터가 있는 컬럼
	- n (오프셋): 몇 번째 이전 행을 가져올지 지정 (이번 문제에서는 2)
	- 기본값: 이전 행이 없을 때 표시할 값 (생략 시 NULL)
- ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW: 
	- 윈도우의 범위를 "해당 파티션의 시작점부터 현재 읽고 있는 행까지"로 지정하는 규칙이에요.
	- RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW : 
		- 기본값 (RANGE)
		- 동작 자체는 ROWS랑 비슷하지만 정렬 기준 값이 같은 행들은 누적 합계 수치가 똑같이 나와버림
