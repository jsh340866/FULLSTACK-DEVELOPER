팀원1(문제유형 분석)과 팀원2(자료 검토·보완)의 결과물을 팀장이 원문 공식과 대조 검증한 뒤 통합했습니다. 모든 계산 예제는 재검산을 마쳤습니다.

팀장 종합 코멘트 통합 우선순위

두 팀원의 결과물은 서로 다른 각도에서 같은 약점을 가리키고 있어 교차 검증이 잘 됐습니다.

① 계산형 문제 — 최우선 대비 영역

  • 지니지수 / 엔트로피 (3-6, 3과목 보완 3-3)
  • 연관분석 3지표: 지지도·신뢰도·향상도 (3-11)
  • 혼동행렬 전체 지표 (4-1 · 원문에 숫자예제 0개 → 보완)
  • 확률분포 기댓값·분산 (2-11 · 원문은 이항분포뿐 → 9종 분포표 보완)
  • VIF / 오즈비 (3-3, 3-6)

② 원문 자체의 공백 — 목차엔 있는데 본문에 없음

  • 1과목 「분석 작업 계획」 (데이터 확보 계획·분석 절차)
  • 1과목 「데이터 변환」
  • 1과목 「분석 로드맵 3단계」
  • 4과목 「분석모형 융합·최종모형 선정」

③ 함정 선택지 — 가장 많이 틀리는 지점

  • 공분산 = 0 ≠ 독립
  • 스피어만 계수는 비선형에서도 ±1 가능
  • 부스팅만 병렬처리 불가
  • 박스플롯은 평균 표시 안 함
  • 집락추출(군집 내 이질적) ↔ 층화추출(군집 내 동질적)
  • 표본분산은 n-1로 나눔 / p-value의 정확한 의미

④ 최종 학습 순서 권고

  1. 원문 공백 4곳 보충 학습
  2. 계산형 최우선 5종 반복 연습
  3. 함정 선택지 최우선 항목 암기
  4. 나머지 문제유형·보완사항 전체 학습
검증 메모 — p.34의 Z검정(모표준편차 기지)과 p.35의 t검정(표본표준편차) 예제는 동일한 검정통계량(−2.0)을 갖지만, 임계값 차이(1.96 vs 2.306)로 결론이 기각↔채택으로 뒤집힙니다. "어느 검정을 써야 하는가"를 묻는 함정 문항의 재료로 매우 적합하니 한 세트로 묶어 학습하길 권합니다.
