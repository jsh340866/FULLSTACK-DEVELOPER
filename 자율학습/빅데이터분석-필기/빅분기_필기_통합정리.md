```
r = Cov(X,Y) / (σx·σy)
예) 공분산 12, σx=3, σy=8 → r = 12/(3×8) = 0.5

● 상관분석 유의성 검정 — H0: ρ=0, t = r√(n-2)/√(1-r²) ~ t(n-2)
☞ 독립⇒r=0은 참이지만, r=0⇒독립은 거짓 (선형관계만 측정하므로 곡선관계는 존재 가능)
```

### 2-3. 표본분산의 n-1 및 자유도 개념 함정 설명 부재
**위치**: 추론통계 - 점추정 (p.33) / 기초통계량 (p.27)
**부족한 점**: n-1로 나누는 이유, 표준편차 vs 표준오차 구분 등 계산문제 최다 실수 지점 미설명.

```
● 모분산(n으로 나눔) vs 표본분산(n-1로 나눔, 불편추정량 위해)
● 표준편차(σ, 개별 데이터 흩어짐) vs 표준오차(σ/√n, 표본평균의 흩어짐)
  ☞ 신뢰구간·가설검정 공식엔 항상 표준오차 사용
예) 표본 2,4,6,8 → 평균5, 편차제곱합20, s²=20/3=6.67 (20/4=5로 계산하면 오답)
```

### 2-4. 1종/2종 오류·검정력·p-value 판단 규칙 설명 부족
**위치**: 추론통계 - 가설검정 (p.33~34)
**부족한 점**: 검정력(1-β) 개념 부재, p-value 정의·판단규칙이 한 줄뿐.

```
● 1종 오류(α, 참인 H0 기각) / 2종 오류(β, 거짓 H0 채택) / 검정력=1-β
 ☞ α↓이면 β↑ (Trade-Off), 둘 다 줄이려면 표본 크기 n을 늘려야 함
● p-value ≤ α → 기각 / p-value > α → 채택
 ☞ 자주 나오는 오답: "p-value는 귀무가설이 참일 확률이다"(틀림),
   "p-value가 작으면 효과 크기가 크다"(틀림 — 우연이 아닐 가능성을 의미)
```

### 2-5. 표본추출법 - 집락 vs 층화 비교표 부재 (최다 혼동 지점)
**위치**: 기술통계 - 표본추출 (p.30)
**부족한 점**: "군집 내 이질적/동질적" 서술이 떨어져 있어 시험장에서 뒤집힘.

```
● 집락(군집) 추출 — 집락 전체를 통째로 뽑음, 집락 내 이질적/집락 간 동질적 (예: 3개 학급 통째로)
● 층화 추출 — 모든 층에서 나눠 뽑음, 층 내 동질적/층 간 이질적 (예: 전학년에서 10명씩)
 ☞ 암기: '집락'은 통째로 뽑으니 안이 다양(이질적)해야 대표성 있음
   '층화'는 나눠서 뽑으니 각 층 안이 비슷(동질적)해야 층을 나눈 의미가 있음
● 비확률 표본추출(편의·판단·할당·눈덩이)은 통계적 추론에 부적합
```

### 2-6. 시각적 데이터 탐색 - 차트별 용도 설명 0줄
**위치**: 데이터 탐색 기초 - 시각적 데이터 탐색 (p.28)
**부족한 점**: 그림만 있고 설명 없음. 히스토그램 vs 막대그래프 차이는 매 회차 단골.

```
● 히스토그램: 연속형 변수 분포, 막대 간격 없음, 축 순서 변경 불가
● 막대그래프: 범주형 변수 비교, 막대 간격 있음, 축 순서 변경 가능

 ☞ 산점도행렬은 다변량 데이터의 변수쌍 관계를 한번에 파악할 때 사용
```

### 3-2. 정준상관분석 1줄 + 요인분석 요인회전 명칭만 나열
**위치**: 고급 분석기법 - 다변량 분석 (p.48~49)
**부족한 점**: 정준상관분석 정의 1줄, 요인회전은 이름만 나열되어 있어 직각/사각회전 차이 대응 불가. PCA vs FA 비교도 부재.

```
● 정준상관분석 — 두 변수 '집단' 간 상관관계 분석 (일반상관은 변수 1↔1)
● 요인회전 — 직각회전(VARIMAX 등, 요인 간 독립 가정) vs 사각회전(OBLIMIN 등, 요인 간 상관 허용)
 ☞ 회전해도 총 설명분산 합은 불변, 배분만 달라짐
● PCA vs FA — PCA는 전체분산 사용·변수→합성(서열 있음), FA는 공통분산만 사용·요인→변수 설명(서열 없음), 요인회전은 FA만 수행
```

### 3-3. 의사결정나무 - 불순도 지수는 있으나 '정보이득' 계산이 없음
**위치**: 분석기법 - 의사결정나무 (p.42)
**부족한 점**: 지니·엔트로피 공식은 있으나 분리 기준 선택 방식(정보이득)이 없음. 분할 전후 지니지수 감소량 계산 문항 최근 출제.

```
정보이득 = 부모 불순도 − Σ(자식 비율×자식 불순도)
예) 부모 10개(A5,B5) 지니=0.5, 분할 후 왼쪽6개(A5,B1)지니=0.278, 오른쪽4개(A0,B4)지니=0
 → 가중평균=0.167, 정보이득=0.5-0.167=0.333
☞ 정지규칙(사전)은 성장을 미리 멈춤 vs 가지치기(사후)는 끝까지 키운 뒤 잘라냄
```

### 3-4. 군집 알고리즘 3종 비교표 부재
**위치**: 분석기법 - 군집분석 (p.46~47)
**부족한 점**: 계층적/K-means/DBSCAN이 각각 서술만 되어 있어 "군집 수 사전지정 불필요한 것은?" 등 판단이 느려짐. 연결법 5종 특징(사슬효과 등)도 없음.

```
● 비교: 계층적(유사도,K불필요,이상치민감) / K-means(거리,K필요,매우민감) /
  DBSCAN(밀도,K불필요,강건,Eps·MinPts) / SOM(신경망,격자)
● 최단연결법: 계산 간단하나 '사슬효과' 발생 / 와드연결법: SSE 증가 최소화, 가장 널리 사용
☞ DBSCAN — 핵심점/경계점/잡음점 용어, K-means는 WCSS 최소화·지역최적해 위험
```

### 3-5. 앙상블 - 배깅 vs 부스팅 비교표 부재
**위치**: 고급 분석기법 - 앙상블 분석 (p.52~53)
**부족한 점**: 편향-분산 관점 대비가 없어 4과목 과대/과소적합과 연결이 안 됨.

```
● 배깅: 병렬, 복원추출, 동일가중치, 분산 감소 목적, 이상치 영향 적음 (랜덤포레스트)
● 부스팅: 순차, 가중치 조정, 오분류에 큰 가중치, 편향 감소 목적, 이상치 민감 (AdaBoost·GBM·XGBoost)
☞ 랜덤포레스트=배깅+변수 무작위 선택(개별 나무 간 상관↓), OOB≈36.8%로 별도 검증셋 없이 평가 가능
```

### 3-6. 회귀 t검정 vs F검정 비교 + 로지스틱 오즈비 해석 계산 부재
**위치**: 분석기법 - 회귀분석 / 로지스틱 회귀분석 (p.41~42)
**부족한 점**: "회귀계수는 t검정, 모형은 F검정" 두 줄뿐. 오즈비 해석(exp(β)) 계산도 없음.

```
● 회귀계수 t검정(H0:βi=0) vs 모형 F검정(H0:β1=…=βk=0) — 단순회귀에선 F=t²로 동일
 ☞ 함정: 모형 F검정이 유의해도 개별 변수는 유의하지 않을 수 있음(다중공선성 존재 시)
● 오즈비 = exp(β) — β=0.693이면 오즈비≈2.0 (오즈 2배 ≠ 확률 2배)
 ☞ 로지스틱 회귀는 최대우도법으로 추정, 적합도는 이탈도·우도비검정으로 평가
```

**위치**: 분석 환경 구축 - 분석 도구 선정 (p.38) / 분석모형 선정 (p.38)
**부족한 점**: 나열만 되어 있어 대응 관계가 안 보임.

```
● 분류·예측=지도학습 / 군집·연관규칙·차원축소=비지도학습
● R(통계특화,시각화 강력,느림) vs Python(범용,딥러닝 강함,빠름)
● SVM 커널 4종 — 선형/다항/RBF(가장 범용)/시그모이드, 커널트릭으로 연산량 절감
```

### 4-2. 혼동행렬 - 공식만 있고 숫자 계산 예시 없음

**부족한 점**: 계산식은 있으나 숫자 예제가 0개. 매 회차 2~3문제 계산형 최다 출제 구간. 행/열 방향(예측 vs 실제) 혼동 주의도 필요.

```
예) TP=40,FP=10,FN=20,TN=30(총100) → 정확도0.70, 정밀도0.80, 재현율0.667, 특이도0.75, F1=0.727

☞ 상황별 지표: 암진단·사기탐지→재현율 우선 / 스팸분류→정밀도 우선 / 불균형 심함→F1·AUC 사용(정확도는 무의미)
☞ AUC 기준: 0.9~1.0 Excellent / 0.8~0.9 Good / 0.7~0.8 Fair / 0.5 무작위 추측
```

### 4-3. 회귀 평가지표 계산 예시 및 지표 간 차이 설명 부재
**위치**: 분석모형 평가 - 평가 지표 - 회귀모델 평가지표 (p.57)
**부족한 점**: 어떤 상황에 어떤 지표를 쓰는지, MAPE 한계(실제값 0일 때 계산 불가) 등 미설명. 결정계수 함정(변수 추가 시 R² 항상 증가)도 강조 필요.

```
예) (10,12)(20,18)(30,33) → MAE=2.33, MSE=5.67, RMSE=2.38, MAPE=13.3%
☞ 항상 MAE ≤ RMSE
☞ R²는 변수를 추가하면 무의미한 변수라도 절대 감소하지 않음 → 다중회귀는 Adjusted R² 사용
☞ 단순회귀에서 R² = (피어슨 상관계수 r)²
```

### 4-4. 편향-분산 관계와 학습곡선 판독 기준 부족
**위치**: 분석모형 진단 (p.58) / 과대적합 방지 (p.60)
**부족한 점**: "왜 그런지", "학습곡선에서 어떻게 판별하는지"가 없음.

```
총 오차 = 편향² + 분산 + 줄일 수 없는 오차
● 과소적합: 훈련·검증오차 둘 다 높음(격차 작음) / 과대적합: 훈련오차↓ 검증오차↑(격차 큼, 변곡점=조기종료 지점)
☞ 모델 복잡도↑ → 편향↓ 분산↑ (Trade-Off), 규제는 분산을 줄이는 대신 편향을 약간 키움
```

### 4-5. 시각화 유형 총정리표 부재 (차트가 4개 섹션에 산재)
**위치**: 분석결과 시각화 전체 (p.65~67)
**부족한 점**: "○○차트는 어느 시각화 유형인가" 분류 문항(매 회차 1~2개) 대응할 통합표 없음.

```
분포(파이·트리맵·모자이크·히스토그램·박스플롯)
```
