빅분기 필기 정리 - 딥러닝 & 머신러닝
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 분산·공분산
- 분산: 값들이 자기 평균에서 얼마나 흩어졌는지, (X-μ)^2의 평균
- 공분산: 두 변수가 같은 방향(+)/반대 방향(-)으로 움직이는 정도, Cov(A,B) = E[(A-μA)(B-μB)]
- 공분산 행렬: 대각선 = 각 변수 분산, 비대각선 = 변수쌍 공분산, 대칭행렬 (Cov(A,B)=Cov(B,A))

2. 표본평균의 분산
- E(X̄) = μ (표본크기 n과 무관, 항상 성립)
- Var(X̄) = σ²/n → n↑ 이면 분산↓ (표본평균은 μ로 수렴, 큰 수의 법칙)
- 표본분산: n-1로 나눔 (불편추정량 보정)

3. PCA vs SVD vs LDA (텍스트/차원축소)
  구분      PCA                   SVD                     LDA
  대상      공분산행렬(정사각)      원본행렬(m×n, 직사각OK)   텍스트(문서)
  방법      고유값분해 → 고유벡터/고유값   바로분해 → U,Σ,V(특이벡터/특이값)   확률분포(디리클레), 깁스샘플링
  활용      변수 차원축소           LSA(TDM+SVD=잠재의미분석)   토픽모델링
  핵심어    분산 최대화 방향        행(U)+열(V) 두 방향        문서=토픽 확률혼합

- 암기: SVD→LSA / 확률기반→LDA(잠재 디리클레 할당)
- 요인분석: PCA와 달리 "잠재요인이 변수를 만든다"는 가정 (방향 반대)

4. 확률/기댓값
- E(X) = Σ(값 × 확률)
- 이항분포 X~B(n,p): E(X)=np, Var(X)=np(1-p)
- 초기하분포(비복원추출): 매 시행 확률 변함, 종속적, n≤N

5. IQR / Box Plot
- IQR = Q3-Q1 (가운데 50% 범위) / Range = 최댓값-최솟값 (다른 개념)
- 이상치 기준: Q1-1.5×IQR 미만 or Q3+1.5×IQR 초과

6. 표본추출
- 층화추출: 층 내부 동질, 층 간 이질 → 모든 층에서 골고루 추출
- 군집추출: 군집 내부 이질(모집단 축소판), 군집 간 동질 → 일부 군집만 통째로 전수조사

7. 클래스 불균형
- 언더샘플링(다수↓) / 오버샘플링(소수↑, 단순복제)
- SMOTE: 단순복제 아님! 소수클래스 데이터 간 보간(합성)으로 새 데이터 생성

8. 점추정 vs 구간추정
- 점추정: 모수를 하나의 값으로 추정
- 구간추정: 점추정치 기준으로 신뢰수준 반영한 범위 제공

9. 상관계수
  구분      피어슨      스피어만
  기준      원본값      순위
  관계      선형(직선)   단조(증가/감소 전반, 곡선 OK)
  이상치    취약        강함

- 상관관계 없음(=0) ≠ 독립 (비선형 관계면 상관계수 0이어도 관계 있을 수 있음)

10. 회귀분석
- 선형회귀: 종속변수 연속형, OLS로 계수추정
- 로지스틱회귀: 종속변수 범주형(0/1), 시그모이드로 0~1 확률 출력, MLE로 추정
- 독립변수는 정규분포 가정 불필요 (X 아무 분포나 OK)
- 정규성 가정 대상 = 오차항(잔차), X 아님
- 4대 가정 (선/독/등/정): 선형성 / 독립성(오차 간 패턴없음, 자기상관X) / 등분산성 / 정규성(오차)
- R²: 설명력 (변수 늘리면 무조건 증가) → Adjusted R²로 보정
- 다중공선성: 독립변수끼리 상관 높음 → 개별영향력 구분 어려움 → VIF 10 이상이면 문제
- 릿지(L2, 제곱, 계수 0 안됨) vs 라쏘(L1, 절댓값, 계수 0 가능=변수선택)

빅분기 필기 정리 - 딥러닝 & 머신러닝
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1. 딥러닝 기본 흐름]

뉴런(Neuron)
 - 입력 → 선형결합(w1x1+w2x2+...+b) → 활성화함수 → 출력
 - 하나의 데이터 파이프라인
 - 출력값 100개 = 그 층 뉴런 100개

인공신경망(ANN)
 - 뉴런들이 여러 층으로 쌓여 연결된 전체 구조

학습 사이클 (반복)
 ① 순전파 : 입력 → 뉴런들 통과 → 출력값 산출
 ② 오차(손실) 계산 : 출력값 vs 정답 비교 → 손실함수(Loss)
 ③ 역전파 : 오차 기준, 가중치별 "얼마나 고칠지" 계산(기울기)
            ※ 수정 X, 계산만 함
 ④ 경사하강법 : 기울기만큼 가중치 실제 수정
 ⑤ 반복(①로)

에포크(epoch) : 전체 데이터셋을 몇 바퀴 돌릴지
배치(batch) : 한 번에 넣는 데이터 묶음
이터레이션 : 가중치 수정 1회 (배치 1개 처리마다)
조기종료(Early Stopping) : 성능 정체 시 epoch 다 안 채우고 자동 중단


[2. 활성화 함수]

- 선형 계산 결과를 "비선형"으로 바꿔주는 함수
- 층마다, 뉴런마다 반복 적용됨 (로지스틱회귀 연결함수와 다른 점 = 반복여부)

 Sigmoid : S자 곡선, 범위 0~1, 이진분류 출력층
 Tanh    : S자 곡선, 범위 -1~1 (Sigmoid 개선판), 은닉층
 ReLU    : 대각선 ㄴ자, 음수는 0 처리, 은닉층 표준(계산빠름, 기울기소실 완화)
 Softmax : 여러 값 → 확률분포(합=1), 다중분류 출력층

※ 로지스틱회귀 시그모이드 = 연결함수(1번만 적용, 끝)
※ 신경망 시그모이드 = 활성화함수(반복적용, 다음층으로 이어짐)
  → 함수는 동일, 역할/횟수가 다름


[3. 과적합 방지 - 규제]

노이즈 : 진짜 패턴과 무관한 우연한 잡음/오차 (이상치는 노이즈의 한 종류)
과적합 : 가중치가 커지며 노이즈까지 억지로 맞추려는 현상(선이 삐뚤빼뚤)

규제 = 손실함수에 "가중치 크기" 페널티 추가 → 역전파 계산에 반영되어
       가중치가 과도하게 커지는 것 억제

 릿지(Ridge, L2) : 가중치 제곱해서 페널티 → 전체적으로 골고루 작아짐
 라쏘(Lasso, L1) : 가중치 절댓값 페널티 → 불필요한 가중치 아예 0(특성선택 효과)
 ※ 라쏘가 항상 좋은 건 아님 (다중공선성 있을 때 불안정할 수 있음)

다중공선성 : 독립변수들끼리 서로 강하게 상관되어 있는 상태


[4. SVM - 서포트벡터머신]

- 마진이 최대가 되는 초평면(경계선)을 찾는 분류 알고리즘
- 딥러닝과 별개의 독립적 알고리즘 (순전파/역전파 안 씀)

 초평면(hyperplane) : 데이터를 나누는 경계선
 서포트벡터         : 경계선과 가장 가까운 데이터들
 마진               : 초평면-서포트벡터 거리, 최대화가 목표
 커널함수           : 저차원→고차원 변환, 안 나눠지는 데이터를 나눠지게 만듦
                      (활성화함수와 다른 개념 - 값 변환 X, 차원 자체를 늘림)

 하드마진 : 오류 절대 비허용
 소프트마진 : 어느정도 오류 허용 → 이상치에 안정적, 실무 표준


[5. 연관분석]

- "A를 사면 B도 산다" 같은 함께 등장하는 패턴(규칙) 찾기
- 방향성 있음 (A→B와 B→A는 다를 수 있음)

 지지도(Support)    : 전체 중 A,B 동시등장 비율
 신뢰도(Confidence)  : A 산 사람 중 B도 산 비율
 향상도(Lift)        : 우연 대비 얼마나 더 강하게 연관되었나 (>1 이면 양의 연관)

 대표 알고리즘 : Apriori (연관분석=개념/목표, Apriori=그걸 찾는 알고리즘)


[6. 군집분석 (Clustering)]

- 비지도학습, 정답 없이 "벡터 간 거리가 가깝다(비슷하다)" 기준으로 그룹화
- 대표 알고리즘 : K-means (중심점 반복 이동시키며 그룹 나눔)

 ※ 이름 헷갈리는 K 3형제
   K-means : 비지도, 그룹(군집) 개수
   KNN     : 지도학습, 이웃 개수로 분류/예측
   K-Fold  : 모델 검증방법, 데이터를 K조각 내서 교차검증


[7. 거리/유사도 측정법]

 (연속형)
 유클리디안 : 직선 최단거리, 가장 많이 씀
 맨하튼     : 격자형 이동거리
 체비셰프   : 두 축 차이 중 최댓값만
 표준화     : 유클리디안을 표준편차로 나눠 스케일 보정
 민코프스키 : 유클리디안+맨하튼을 파라미터로 아우르는 일반화 공식(포함관계)
 마할라노비스 : 표준화 + 변수 간 상관관계까지 반영

 (범주형/방향)
 자카드 유사도 : 교집합/합집합, 두 집합의 겹침 비율 (대칭적)
 코사인 유사도 : 벡터 길이는 무시, 방향(각도)만 비교
               1=같은방향 / 0=무관 / -1=반대방향
               → 문서 길이 달라도 내용 패턴 비슷하면 높은 유사도

오늘 학습 정리 (군집분석 ~ 텍스트마이닝/트랜스포머)
====================================================

■ 1. 군집분석 (Clustering)
----------------------------------------------------
- 계층적 군집분석
  · 트리구조(덴드로그램), 병합적/분할적
  · 군집 하나하나 묶어가며 계속 합치거나, 하나의 군집을 계속 쪼갬
  · 사전에 군집 개수(k) 지정 불필요
  · 대표 방법: 최단연결법, 최장연결법, 평균연결법, 중심연결법, Ward's method
  · 한번 합쳐지면 되돌릴 수 없음(비가역적) - 탐욕적(greedy) 알고리즘이라
    매 단계 가장 가까운 두 군집을 합치고 재검토하지 않음
  · 가지치기(pruning)는 이 비가역성과 별개 - 완성된 덴드로그램을
    어느 높이에서 자를지 정하는 "해석 단계"의 문제

- 비계층적 군집분석
  · 군집 개수 k를 사전에 지정, 개체를 k개 군집 중 하나로 배정
  · 대표: K-means (중심점 기준 배정 후 중심 재계산 반복)

■ 2. 다변량분석 (Multivariate Analysis)
----------------------------------------------------
- 3개 이상의 변수를 동시에 고려해 관계/구조를 분석하는 통계기법 전체를
  가리키는 큰 범주(우산) 개념
- 하위 기법: 다중회귀분석, 판별분석, MANOVA, 군집분석, PCA, 요인분석, MDS 등

- PCA (주성분분석)
  · 변수들의 선형결합으로 새로운 축(주성분)을 만들어 정보를 압축
  · 오차(고유분산) 개념 없음 - 전체 분산을 최대한 보존
  · 통계적 모형 가정 없는 수학적 변환

- 요인분석 (Factor Analysis)
  · 관측변수들 뒤에 숨어서 그 변수들을 "만들어낸" 잠재요인을 역으로 추정
  · 관측변수 = 잠재요인 + 고유오차(공통분산과 오차를 분리)
  · 결과물: 요인적재량(요인1, 요인2와 각 변수의 관련도 수치)
  · 요인 개수/관련도는 통계가 찾아주지만, 요인에 이름 붙이고 해석하는 건
    분석자의 몫 (원본 데이터에는 없던, 분석으로 추정해낸 개념)

- 시계열분석 vs 다변량분석
  · 서로 다른 축 (변수 개수 기준 vs 시간 축 기준) → 독립적으로 조합 가능
  · 예: 단변량 시계열, 다변량 시계열(VAR) 등

■ 3. 시계열분석 (Time Series Analysis)
----------------------------------------------------
- 시간 순서대로 관측된 데이터를 분석, 미래를 예측하는 기법
- 관측치 간 독립을 가정하지 않고 자기상관(과거→현재 영향)을 다룸

[4가지 구성요소]
- 추세(Trend): 장기적 증가/감소 방향성
- 계절성(Seasonality): 고정된 주기로 반복 (예: 매년 여름 아이스크림 매출↑)
- 순환(Cycle): 불규칙하고 계절성보다 긴 주기 반복 (예: 경기순환)
- 불규칙 요인(Irregular/Noise): 위 세 가지로 설명 안 되는 무작위 변동
- 분해 모델: 가법모델(Y=추세+계절성+순환+불규칙) / 승법모델(Y=추세×계절성×순환×불규칙)

[정상성 Stationarity]
- 시간이 지나도 평균, 분산, 공분산이 일정하게 유지되는 상태
- 조건: 평균 일정 / 분산 일정 / 공분산이 시차(lag)에만 의존
- 비정상 예: 주가 (추세와 변동성 변화로 평균·분산이 안 일정)
- 검정: ADF 검정, KPSS 검정

[차분 Differencing] - 정상성 확보를 위한 전처리
- Y'_t = Y_t - Y_(t-1) (직전 "실제값"을 뺌)
- 추세 제거 → 평균을 일정하게 만듦
- 계절 차분: 한 주기 전 값과의 차이 (계절성 제거)
- ARIMA의 d(차분 횟수)에 해당

[자기상관 Autocorrelation, ACF]
- 같은 변수가 시차(lag)를 두고 자기 자신과 얼마나 상관관계 갖는지
- 시계열분석의 전제("과거가 현재에 영향") 확인 지표

[PACF 편자기상관함수]
- 중간 시점들의 간접 영향을 제거한, 순수하게 직접적인 상관관계만 측정
- ACF: 간접 경로 포함 / PACF: 직접 경로만
- AR 차수(p) 결정에 사용, ACF는 MA 차수(q) 결정에 사용

[백색잡음 White Noise]
- 평균 0(일정), 분산 일정, 자기상관 0 → 완전 무작위, 예측 불가능한 상태
- 잔차 = 실제값 - "모델의 예측값" (차분과는 다른 개념! 차분은 "직전 실제값"을 뺌)
- 좋은 모델일수록 잔차가 백색잡음에 수렴해야 함
  → 잔차에 패턴(자기상관)이 남아있다 = 모델이 못 잡아낸 정보가 남았다는 뜻
  → 잔차가 백색잡음이다 = 뽑아낼 수 있는 정보를 모델이 다 흡수했다는 뜻
- Ljung-Box 검정으로 잔차의 백색잡음 여부 검정

[시계열 모형 발전 순서]
AR(과거 값 참고, 차수 p, PACF로 결정)
 + MA(과거 오차 참고, 차수 q, ACF로 결정)
 = ARMA (정상 데이터 전용)
 + 차분(I)
 = ARIMA(p,d,q) (비정상 데이터도 가능, 단변량)
 + 계절성
 = SARIMA(p,d,q)(P,D,Q)_m
 * 다변량이면 VAR (여러 변수가 서로 영향, 시간에 따라 동시 모델링)

[전체 분석 흐름]
원본 데이터 → 정상성 검증(시각화+ADF검정) → 비정상이면 차분 반복(d 결정)
→ 정상화된 데이터 ACF(q 결정)/PACF(p 결정) → ARIMA(p,d,q) 적합
→ 잔차 백색잡음 검증(Ljung-Box) → 통과하면 완성, 아니면 p·q 재조정

■ 4. 베이지안 기법 (Bayesian Methods)
----------------------------------------------------
- 확률을 "고정값"이 아니라 "데이터가 들어올 때마다 업데이트되는 믿음의 정도"로 봄
- 빈도주의: 모수는 세상에 이미 정해진 고정값 → 데이터로 그 참값을 추정(찾아냄)
  (지금까지 배운 ARIMA, K-means 등 대부분 빈도주의 접근)
- 베이지안: 모수 자체를 불확실성으로 보고 확률분포로 표현
  → 사전확률(Prior)에서 시작해 데이터(우도, Likelihood)로 업데이트하여
     사후확률(Posterior) 도출, 계속 반복 업데이트

베이즈 정리: P(가설|데이터) = P(데이터|가설) × P(가설) / P(데이터)

대표 기법: 베이지안 추론, 나이브 베이즈, 베이지안 네트워크, 
          베이지안 최적화, MCMC

■ 5. 인공신경망 (ANN, Artificial Neural Network)
----------------------------------------------------
- 뉴런(노드)이 가중치·편향으로 계산 후 활성화함수로 비선형 변환
  z = w1x1+w2x2+...+b, y = 활성화함수(z)
- 학습 과정: 순전파(예측) → 손실함수로 오차 측정 → 역전파(가중치 수정)
  → 경사하강법으로 반복(epoch)
- 학습률(learning rate): 가중치를 얼마나 크게 바꿀지 결정하는 값
  → 학습률 스케줄러(예: ReduceLROnPlateau): 훈련 상황에 따라 학습률 자동 조절

[ANN 하위 구조]
ANN
 ├─ DNN: 은닉층 2개 이상, 완전연결(Fully Connected), 공간/순서 고려 없음
 ├─ CNN: 이미지 등 공간적 패턴에 특화. 합성곱층(필터로 지역 특징 추출)
 │        + 풀링층(크기 축소) + 완전연결층
 ├─ RNN: 순서 데이터(시계열, 텍스트) 특화. 이전 시점 정보(은닉상태)를
 │        다음 시점으로 전달 h_t = f(x_t, h_(t-1))
 │        └─ LSTM: RNN의 장기기억 소실(기울기 소실) 문제를
 │                  게이트로 "기억/망각" 선택 조절해 개선
 ├─ 오토인코더: 입력=목표로 삼아 압축(인코딩)-복원(디코딩)을 학습
 │              뉴런 수가 점점 줄어드는 구간=인코더, 병목(잠재공간)=핵심 정보,
 │              다시 늘어나는 구간=디코더
 │              용도: 차원축소, 이상치 탐지(복원손실↑=이례적 데이터),
 │                    노이즈제거, 생성모델(VAE 등)의 기반
 │              (PCA와 유사하나 비선형 압축 가능이 차이)
 └─ Transformer: RNN 계열의 발전형이 아니라 별도 갈래.
                  순차처리 대신 어텐션(Attention)으로 문장 전체를 병렬 처리
                  Self-Attention: Query/Key/Value로 모든 단어쌍 관련도 계산
                  위치 인코딩으로 순서 정보 별도 주입
                  인코더만 사용→BERT, 디코더만 사용→GPT (둘 다 LLM)

■ 6. 텍스트마이닝 (Text Mining)
----------------------------------------------------
처리 흐름: 원본 텍스트 → 전처리(토큰화, 불용어제거, 형태소분석)
          → 벡터화(숫자로 변환) → 분석/모델링

[통계 기반 - 빈도 중심]
- TDM(Term-Document Matrix): 문서별 단어 등장 빈도를 행렬로 표현
- TF-IDF: 단어빈도(TF) × 역문서빈도(IDF)
  → 특정 문서엔 자주, 다른 문서엔 드문 단어일수록 높은 점수(핵심어 판별)

[단어 수준 기반 - 의미/문맥 중심]
- Word2Vec: 주변 단어와의 거리 기반 벡터화 (CBOW/Skip-Gram), 문맥 무관 고정벡터
- FastText: 단어를 더 작은 조각(subword)으로 쪼개 벡터 계산,
            신조어·오탈자도 처리 가능
- ELMo: 양방향 언어모델, 문맥에 따라 같은 단어도 다른 벡터를 가짐
- (이후) Transformer 기반 BERT, GPT로 발전 → 문맥 반영이 더욱 정교해짐

[분석/모델링 활용]
- 감성분석, 토픽모델링(LDA - 요인분석과 유사한 사고방식), 문서분류,
  개체명인식(NER), 텍스트요약

전체 요약 트리
====================================================
군집분석 (계층적/비계층적)
다변량분석 (PCA, 요인분석 등 포함하는 상위 범주)
시계열분석 (정상성-차분-자기상관-백색잡음 → ARIMA/SARIMA/VAR)

[ 앙상블 분석 (Ensemble Learning) ]

정의
- 여러 개의 모델을 결합해 단일 모델보다 안정적이고 정확한 예측을 만드는 방법
- 개별 모델의 편향(bias)/분산(variance) 문제를 서로 상쇄시켜 성능 향상

핵심 원리
- 집단지성과 유사 → 한 전문가보다 여러 전문가 의견 종합이 더 정확

──────────────────────────────
1. 배깅 (Bagging) - 분산 줄이기
──────────────────────────────
- 원본 데이터에서 중복 허용 샘플링(부트스트랩)
- 여러 서브셋을 독립적으로 병렬 학습
- 결과를 평균/투표로 결합
- 대표 모델 : 랜덤 포레스트
- 특징      : 과적합 방지에 효과적

──────────────────────────────
2. 부스팅 (Boosting) - 편향 줄이기
──────────────────────────────
- 모델을 순차적으로 학습
- 이전 모델이 틀린 데이터에 가중치 부여
- 다음 모델이 그 오류를 보완하는 방식
- 대표 모델 : XGBoost, LightGBM, AdaBoost
- 특징      : 성능 우수, 과적합 위험은 배깅보다 큼

──────────────────────────────
3. 스태킹 (Stacking) - 메타 학습
──────────────────────────────
- 서로 다른 모델(로지스틱 회귀 + 랜덤포레스트 + SVM 등)의
  예측 결과를 입력값으로 사용
- 이를 종합 판단하는 메타 모델을 추가로 학습

──────────────────────────────
비교 요약
──────────────────────────────
기법    | 목적       | 학습 방식  | 대표 알고리즘
--------|-----------|-----------|------------------
배깅    | 분산 감소  | 병렬       | 랜덤 포레스트
부스팅  | 편향 감소  | 순차       | XGBoost, LightGBM
스태킹  | 모델 다양성 활용 | 병렬+메타 | 커스텀 조합

실무 참고
- 캐글 등 실전에서는 XGBoost/LightGBM 계열 부스팅이 가장 많이 쓰임
