1. 프로그래밍 언어 활용 (가장 중요!)

C언어 포인터 및 배열

* *p는 값, &p는 주소 의미
* 배열 이름 그 자체는 첫 번째 요소의 주소값
* scanf("%d", &a); 처럼 입력 시에는 주소 연산자(&) 필수

Java 클래스 및 상속

* 생성자: 클래스명과 동일한 이름의 메서드, 객체 생성 시 자동 호출 (반환형 없음)
* 오버라이딩(Overriding): 상속받은 메서드를 재정의 (다형성 구현)
* 오버로딩(Overloading): 같은 이름의 메서드를 매개변수 개수/타입만 다르게 하여 여러 개 정의
* static: 객체 생성 없이 클래스 이름으로 직접 접근 가능한 변수/메서드

Python 특이 문법

* 리스트 슬라이싱: a[1:4]는 인덱스 1부터 3까지만 포함
* range(5): 0, 1, 2, 3, 4 생성 (끝 숫자는 미포함)
* 세트(Set): 중복을 허용하지 않는 집합 자료구조

연산자 우선순위 암기법

* [증 - 산 - 관 - 논 - 대] (증감, 산술, 관계, 논리, 대입 연산자 순)

2. 소프트웨어 설계 및 개발 방법론

객체지향 설계 5대 원칙 (SOLID)

* 단일 책임 원칙 (SRP): 하나의 클래스는 하나의 책임만 가짐
* 개방 폐쇄 원칙 (OCP): 확장에는 열려 있고 변경에는 닫혀 있어야 함
* 리스코프 치환 원칙 (LSP): 자식 클래스는 언제나 부모 클래스를 대체할 수 있어야 함
* 인터페이스 분리 원칙 (ISP): 사용하지 않는 인터페이스는 구현하지 않도록 분리함
* 의존역전 원칙 (DIP): 변화하기 쉬운 것보다 변화가 없는 것에 의존해야 함 (인터페이스 의존)

결합도(Coupling) 낮은 순 (좋음에서 나쁨)

* [데 - 스 - 제 - 외 - 공 - 내] (데이터, 스탬프, 제어, 외부, 공통, 내용)

응집도(Cohesion) 높은 순 (좋음에서 나쁨)

* [기 - 순 - 통 - 절 - 시 - 논 - 우] (기능, 순차, 통신, 절차, 시간, 논리, 우연)

디자인 패턴 분류

* 생성 패턴: 빌더, 프로토타입, 싱글톤, 추상 팩토리, 팩토리 메서드
* 구조 패턴: 어댑터, 브리지, 데코레이터, 퍼사드, 프록시
* 행위 패턴: 옵저버, 전략, 템플릿 메소드, 커맨드, 상태, 방문자

애자일(Agile) 4대 핵심 가치

* 개인과 상호작용, 작동하는 소프트웨어, 고객 협력, 변화에 대응

3. 데이터베이스 및 SQL 응용

정규화 단계 암기법

* [도 - 부 - 이 - 결 - 다 - 조] (원자값, 부분함수 제거, 이행함수 제거, 결정자 분리, 다치 종속 제거, 조인 속성 이용)

트랜잭션 ACID 특징

* 원자성(Atomicity): 모두 반영되거나 전혀 반영되지 않음 (All or Nothing)
* 일관성(Consistency): 실행 성공 후 언제나 일관된 시스템 상태 유지
* 격리성(Isolation): 둘 이상의 트랜잭션이 서로 끼어들지 못함
* 영속성(Durability): 성공 결과는 영구적으로 보존됨

SQL 제어어(DCL)

* GRANT(권한 부여), REVOKE(권한 취소)

스키마(Schema) 3계층

* 외부 스키마: 사용자나 개발자 관점의 뷰
* 개념 스키마: 전체적인 논리 구조, 통합된 모든 사용자 관점
* 내부 스키마: 물리적 저장장치 관점의 구조

키(Key)의 종류

* 후보키: 유일성과 최소성을 모두 만족하는 키
* 슈퍼키: 유일성은 만족하지만 최소성은 만족하지 못하는 키
* 기본키: 후보키 중에서 특별히 선택된 주키 (Null 불가, 중복 불가)
* 외래키: 다른 테이블의 기본키를 참조하는 키

4. 운영체제(OS) 및 네트워크

OSI 7계층 암기법

* [물 - 데 - 네 - 전 - 세 - 표 - 응] (물리, 데이터링크, 네트워크, 전송, 세션, 표현, 응용)

TCP vs UDP

* TCP: 연결형, 신뢰성 보장, 흐름 제어 및 혼잡 제어 제공
* UDP: 비연결형, 신뢰성 낮음, 대시 속도가 빠름

HRN 스케줄링 우선순위 공식

* (대기 시간 + 서비스 시간) / 서비스 시간
* 계산된 값이 클수록 우선순위가 높음

페이지 교체 알고리즘

* FIFO: 가장 먼저 들어와서 오래 있던 페이지 교체
* LRU: 가장 오랫동안 사용되지 않은 페이지 교체
* LFU: 참조 횟수가 가장 적은 페이지 교체

교착상태(Deadlock) 발생 4가지 조건

* [상 - 점 - 비 - 환] (상호배제, 점유와 대기, 비선점, 환형대기)

5. 정보보안 및 테스트 기법

암호화 알고리즘 종류

* 대칭키: AES, DES, ARIA, SEED
* 비대칭키: RSA, ECC
* 해시(단방향): SHA-256, MD5

화이트박스 테스트 검증 기준

* 구문 커버리지, 결정 커버리지, 조건 커버리지

블랙박스 테스트 기법

* 동등 분할, 경계값 분석, 결정 테이블, 상태 전이, 에러 예측

테스트 진행 단계 암기법

* [단 - 통 - 시 - 인] (단위 테스트, 통합 테스트, 시스템 테스트, 인수 테스트)

품질 및 테스트 법칙

* 살충제 패러독스: 동일한 테스트 케이스를 반복하면 새로운 결함을 찾을 수 없음
* 파레토 법칙: 전체 결함의 80%는 특정 20%의 모듈에서 집중적으로 발생함

6. 신기술 및 보안 공격 기법

* 스니핑(Sniffing): 네트워크상에서 흘러 다니는 패킷을 엿보는 행위
* 스푸핑(Spoofing): 승인받은 정상 사용자인 것처럼 IP, MAC 주소 등을 속이는 행위
* 파밍(Pharming): 가짜 사이트로 접속을 유도하는 기법 (DNS 변조 등)
* 랜섬웨어(Ransomware): 파일을 암호화하여 인질로 잡고 몸값을 요구하는 악성코드
* 형상 관리(SCM): 소프트웨어 변경 사항을 체계적으로 관리하는 활동 (Git, SVN 등)
