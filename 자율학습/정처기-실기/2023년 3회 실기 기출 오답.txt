[실기] 23년 3회 기출 오답 노트

■ 문제
정보전달의 기본단위를 53바이트 셀 단위로 사용하는 비동기식 시분할 다중화 방식의 패킷형 전송 기술을 무엇인지 영어 약자로 쓰시오.

■ 내 답변
SMTP

■ 정답
ATM (Asynchronous Transfer Mode)

■ 핵심 키워드
- 53바이트 셀 (헤더 5바이트 + 데이터 48바이트)
- 비동기식 시분할 다중화
- 고속 패킷 교환 기술

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 정답인 ATM (비동기 전송 모드)
- 데이터를 고정된 크기인 53바이트의 '셀(Cell)' 단위로 나누어 전송하는 기술입니다.
- 문제에서 '53바이트 셀', '비동기식 시분할 다중화'라는 말이 나오면 정답은 ATM입니다.

2. 내가 적은 SMTP (간이 우편 전송 프로토콜)
- SMTP는 인터넷에서 이메일(E-mail)을 보낼 때 사용하는 프로토콜입니다.
- 네트워크 하위 전송 기술인 ATM과는 완전히 다른 개념입니다.

#include <stdio.h>
int main() {
    char* p="KOREA";
    printf("%s\n", p);
    printf("%s\n", p+1);
    printf("%c\n", *p);
    printf("%c\n", *(p+3));
    printf("%c\n", *p+4);
    return 0;
}

##
정답 : 
KOREA
OREA
K
E
O

###
    printf("%c\n", *p+4);

!!*(p+4)가 아닌 *p+4입니다!!!
역참조 연산자 *가 덧셈 +보다 우선순위가 높아, *p를 먼저 계산한 뒤 4를 더합니다.

- *p = 'K'
  - 방법 1: 알파벳 순서로 K에서 4칸 이동 → K → L → M → N → O → O
  - 방법 2: 
ASCII
 코드로 계산 → 'K'(75) + 4 = 79 = O

[실기] 23년 3회 / 25년 3회 기출 오답 노트

■ 문제
다음은 서버 접근통제의 유형이다. 괄호 ( ) 안에 들어갈 용어를 쓰시오. (단, 영어 약어로 작성하시오.)

- ( ① )은/는 규칙 기반(Rule-Based) 접근통제 정책으로, 객체에 포함된 정보의 허용 등급과 접근 정보에 대하여 주체가 갖는 접근 허가 권한에 근거하여 객체에 대한 접근을 제한하는 방법이다.

- ( ② )은/는 중앙 관리자가 사용자와 시스템의 상호 관계를 통제하며 조직 내 맡은 역할(Role)에 기초하여 자원에 대한 접근을 제한하는 방법이다.

- ( ③ )은/는 신분 기반(Identity-Based) 접근통제 정책으로, 주체나 그룹의 신분에 근거하여 객체에 대한 접근을 제한하는 방법이다.

■ 내 답변
① MAC
② RBAC
③ MAC (오답)

■ 정답
① MAC (Mandatory Access Control)
② RBAC (Role-Based Access Control)
③ DAC (Discretionary Access Control)

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 접근통제 3대 유형 확실하게 구별하기

① MAC (강제 접근통제)
- 키워드: 규칙 기반(Rule-Based), 허용 등급, 접근 권한
- 시스템이 결정한 보안 등급에 따라 강제적으로 제어하는 방식입니다.

② RBAC (역할기반 접근통제)
- 키워드: 역할(Role), 중앙 관리자
- 사용자의 신분이 아닌 조직 내에서의 '역할'과 '직책'에 따라 권한을 부여합니다.

③ DAC (임의 접근통제)
- 키워드: 신분 기반(Identity-Based), 주체나 그룹의 신분
- 데이터의 소유자가 '임의로' 다른 사용자에게 접근 권한을 부여할 수 있는 방식입니다.
- ③번 문제에서 '신분 기반(Identity-Based)'이라는 결정적인 힌트가 나왔으므로 정답은 DAC입니다!
