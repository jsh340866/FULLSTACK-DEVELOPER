[실기] 23년 3회 기출 오답 노트

■ 문제
정보전달의 기본단위를 53바이트 셀 단위로 사용하는 비동기식 시분할 다중화 방식의 패킷형 전송 기술을 무엇인지 영어 약자로 쓰시오.

■ 내 답변
SMTP

■ 정답
ATM (Asynchronous Transfer Mode)

■ 핵심 키워드
- 53바이트 셀 (헤더 5바이트 + 데이터 48바이트)
- 비동기식 시분할 다중화
- 고속 패킷 교환 기술

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 정답인 ATM (비동기 전송 모드)
- 데이터를 고정된 크기인 53바이트의 '셀(Cell)' 단위로 나누어 전송하는 기술입니다.
- 문제에서 '53바이트 셀', '비동기식 시분할 다중화'라는 말이 나오면 정답은 ATM입니다.

2. 내가 적은 SMTP (간이 우편 전송 프로토콜)
- SMTP는 인터넷에서 이메일(E-mail)을 보낼 때 사용하는 프로토콜입니다.
- 네트워크 하위 전송 기술인 ATM과는 완전히 다른 개념입니다.

    printf("%c\n", *(p+3));
    printf("%c\n", *p+4);
    return 0;
}

###
    printf("%c\n", *p+4);

!!*(p+4)가 아닌 *p+4입니다!!!
역참조 연산자 *가 덧셈 +보다 우선순위가 높아, *p를 먼저 계산한 뒤 4를 더합니다.

- *p = 'K'
  - 방법 1: 알파벳 순서로 K에서 4칸 이동 → K → L → M → N → O → O
  - 방법 2: 
ASCII
 코드로 계산 → 'K'(75) + 4 = 79 = O

[실기] 23년 3회 / 25년 3회 기출 오답 노트

■ 문제
다음은 서버 접근통제의 유형이다. 괄호 ( ) 안에 들어갈 용어를 쓰시오. (단, 영어 약어로 작성하시오.)

- ( ① )은/는 규칙 기반(Rule-Based) 접근통제 정책으로, 객체에 포함된 정보의 허용 등급과 접근 정보에 대하여 주체가 갖는 접근 허가 권한에 근거하여 객체에 대한 접근을 제한하는 방법이다.

- ( ② )은/는 중앙 관리자가 사용자와 시스템의 상호 관계를 통제하며 조직 내 맡은 역할(Role)에 기초하여 자원에 대한 접근을 제한하는 방법이다.

- ( ③ )은/는 신분 기반(Identity-Based) 접근통제 정책으로, 주체나 그룹의 신분에 근거하여 객체에 대한 접근을 제한하는 방법이다.

■ 내 답변
① MAC
② RBAC
③ MAC (오답)

■ 정답
① MAC (Mandatory Access Control)
② RBAC (Role-Based Access Control)
③ DAC (Discretionary Access Control)

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 접근통제 3대 유형 확실하게 구별하기

① MAC (강제 접근통제)
- 키워드: 규칙 기반(Rule-Based), 허용 등급, 접근 권한
- 시스템이 결정한 보안 등급에 따라 강제적으로 제어하는 방식입니다.

② RBAC (역할기반 접근통제)
- 키워드: 역할(Role), 중앙 관리자
- 사용자의 신분이 아닌 조직 내에서의 '역할'과 '직책'에 따라 권한을 부여합니다.

③ DAC (임의 접근통제)
- 키워드: 신분 기반(Identity-Based), 주체나 그룹의 신분
- 데이터의 소유자가 '임의로' 다른 사용자에게 접근 권한을 부여할 수 있는 방식입니다.
- ③번 문제에서 '신분 기반(Identity-Based)'이라는 결정적인 힌트가 나왔으므로 정답은 DAC입니다!

■ 문제
괄호 ( ) 안에 들어갈 클라우드 유형을 보기 중에서 고르시오.

보기: SaaS / IaaS / PaaS

(①) 서버, 스토리지 같은 시스템 자원을 클라우드 서비스로 제공한다.
(②) 인프라를 생성, 관리하는 복잡함 없이 애플리케이션을 개발, 실행, 관리할 수 있게 하는 플랫폼을 클라우드 서비스로 제공한다.
(③) 소프트웨어 및 관련 데이터를 클라우드 서비스로 제공한다.

■ 내 답변
① IaaS
② PaaS
③ SaaS

■ 정답
① IaaS
② PaaS
③ SaaS

------------------------------------------

★ 핵심 개념 정리 (다 맞혔음! 칭찬해! 👏) ★

1. 클라우드 서비스 유형(Service Models) 핵심 키워드 정리

① IaaS (Infrastructure as a Service, 인프라형 서비스)
- 키워드: 서버, 스토리지, 시스템 자원(인프라)
- 가장 하위 단계의 클라우드 서비스로, 하드웨어 자원을 가상화하여 제공하는 방식입니다.

② PaaS (Platform as a Service, 플랫폼형 서비스)
- 키워드: 애플리케이션 개발/실행/관리, 플랫폼
- 개발자가 복잡한 인프라 관리 신경 쓰지 않고, 소스 코드만 올려서 바로 서비스할 수 있는 개발 환경(런타임, DB 등)을 제공하는 방식입니다.

③ SaaS (Software as a Service, 소프트웨어형 서비스)
- 키워드: 소프트웨어 및 관련 데이터 제공
- 사용자가 웹 브라우저나 앱을 통해 클라우드에 설치된 완제품 소프트웨어를 그대로 이용하는 방식입니다.

■ 문제
다음에서 설명하는 라우팅 프로토콜을 쓰시오.

- IGP 중 거리벡터 알고리즘에 기초한 라우팅 프로토콜이다.
- 홉 수의 제한이 있고, UDP 프로토콜을 사용하는 라우팅 프로토콜이다.

■ 내 답변
?

■ 정답
RIP (Routing Information Protocol)

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 정답인 RIP 핵심 특징 암기하기

- 내부 라우팅 프로토콜(IGP): 같은 자율 시스템(AS) 내에서 사용됩니다.
- 거리 벡터(Distance Vector) 알고리즘: 벨만-포드 알고리즘 기반으로, 목적지까지의 '거리(홉 수)'와 '방향(넥스트 홉)'만을 고려합니다.
- 홉 수(Hop Count) 제한: 최대 홉 수는 15로 제한되며, 16은 도달할 수 없는 네트워크를 의미합니다. (소규모 네트워크에 적합)
- UDP 프로토콜 사용: 520번 포트를 사용하여 라우팅 정보를 주기적으로(30초) 이웃 라우터들과 공유합니다.

2. 시험 대비 비교 팁 (헷갈리기 쉬운 OSPF)

- OSPF (Open Shortest Path First)
  - RIP의 홉 수 제한 한계를 극복하기 위해 만들어진 프로토콜입니다.
  - '거리 벡터'가 아닌 '링크 상태(Link State)' 알고리즘(다익스트라 알고리즘)을 사용합니다.
  - 변화가 있을 때만 정보를 전송하므로 대규모 네트워크에 적합하며, 전송 계층 프로토콜인 TCP/UDP를 사용하지 않고 IP 패킷에서 직접 동작합니다.

■ 문제
내부 네트워크의 사설 IP 주소를 인터넷상의 공인 IP 주소로 변환하여 IPv4 주소 부족 문제를 해결하고 보안을 강화하는 기술은 무엇인가?

보기: IP / ICMP / ARP / 라우팅 프로토콜 / RARP / IGMP / NAT

■ 내 답변
RARP (오답)

■ 정답
NAT (Network Address Translation)

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. 정답인 NAT (네트워크 주소 변환) 핵심 암기하기
- 역할: 사설 IP 주소를 공인 IP 주소로 상호 변환해 주는 기술입니다.
- 목적 1 (주소 절약): 하나의 공인 IP를 여러 개의 사설 IP가 공유할 수 있어 IPv4 주소 부족 문제를 완화합니다.
- 목적 2 (보안 강화): 외부 인터넷망에서는 내부 사설 IP 주소가 숨겨지기 때문에 내부 네트워크를 보호하는 보안 효과가 있습니다.

2. 내가 적은 RARP 및 보기 프로토콜 헷갈리지 않기!

- RARP (Reverse ARP): 물리적 주소(MAC 주소)를 알고 있을 때 IP 주소를 찾아주는 역주소 결정 프로토콜입니다. (IP를 MAC으로 바꾸는 것은 ARP)
- ICMP: IP 패킷 전송 중 에러 처리와 상태 보고를 위한 프로토콜입니다. (Ping 명령어에서 사용)
- IGMP: 멀티캐스트 그룹에 가입한 호스트들을 관리하기 위한 프로토콜입니다.


1. NAT(Network Address Translation) 
	- 사설 IP 주소를 공인 IP 주소로 변환하여 IPv4 주소 부족을 해결하고 보안을 강화하는 기술
2. RARP(Reverse Address Resolution Protocol) 
	- 물리적 주소(MAC 주소)를 알고 있을 때 IP 주소를 찾아주는 역주소 결정 프로토콜
3. ARP(Address Resolution Protocol) 
	- IP 주소를 알고 있을 때 물리적 주소(MAC 주소)를 찾아주는 주소 결정 프로토콜
4. IP(Internet Protocol) 
	- 인터넷망에서 패킷을 목적지 호스트까지 전달하기 위해 사용하는 주소 지정 및 라우팅 프로토콜
5. ICMP(Internet Control Message Protocol) 
	- IP 패킷 전송 중 발생하는 에러 처리와 네트워크 상태 보고를 위한 프로토콜
6. IGMP(Internet Group Management Protocol) 
	- 멀티캐스트 호스트가 자신이 속한 그룹을 라우터에 알리기 위해 사용하는 인터넷 그룹 관리 프로토콜

- 사용자가 비밀번호를 제공하지 않고 다른 웹사이트나 애플리케이션의 접근 권한을 부여할 수 있게 하는 개방형 표준기술이다.
- 구글, 페이스북 등의 외부 계정을 기반으로 토큰을 이용하여 간편하게 회원가입 및 로그인할 수 있는 기술이다.

OTP

■ 정답
OAuth (Open Authorization)

------------------------------------------

★ 핵심 개념 정리 및 오답 분석 ★

1. OAuth(Open Authorization) - 인터넷 사용자들이 비밀번호를 노출하지 않고 구글, 페이스북 등의 외부 계정 권한을 토큰 방식으로 위임받아 간편 로그인 및 회원가입을 할 수 있게 해주는 개방형 표준 인증 프로토콜
2. OTP(One-Time Password) - 무작위로 생성되는 일회용 비밀번호를 통해 사용자를 인증하는 보안 기술 (로그인할 때마다 매번 새로운 비밀번호를 입력하는 방식)
