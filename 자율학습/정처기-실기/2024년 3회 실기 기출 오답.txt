
#include <stdio.h>
void func(int **arr, int size){
    int i;
    for(i=0;i<size;i++){
        *(*arr+i)=(*(*arr+i)+i) % size;
    }
}
int main(){
    int arr[]={3, 1, 4, 1, 5};
    int *p=arr;
    int **pp=&p;

    func(pp, 5);
    printf("%d", arr[2]);
    return 0;
}


####

*(*arr+i) = arr[i]

arr[i] = (arr[i] + i) % size

문제	
다음 괄호 ( ) 안에 들어갈 용어를 작성하시오.

( )은/는 네트워크의 구성 및 유지를 위해 기지국이나 액세스 포인트와 같은 기반 네트워크 장치를 필요로 하지 않는 네트워크로 노드(Node)들에 의해 자율적으로 구성되는 구조이다. 긴급 구조, 긴급회의, 전쟁터에서의 군사 네트워크로 활용된다.
답변	
WAN

정답
애드 혹 네트워크 또는 Ad-hoc Network 또는 Adhoc Network

애드 혹 네트워크 (Ad-hoc Network)
- 기지국이나 AP 같은 기반 장치(인프라) 없이 노드들이 자율적으로 구성하는 임시 네트워크
- 키워드: 기지국 없음, 임시, 긴급 구조, 전쟁터 군사망

WAN (Wide Area Network, 광역 통신망)
- 전 세계나 국가, 도시 같이 매우 넓은 지리적 범위를 연결하는 네트워크 (예: 인터넷)
- 키워드: 매우 넓은 범위, 기지국/통신선로 등 거대한 기반 장치(인프라) 필수 요구
