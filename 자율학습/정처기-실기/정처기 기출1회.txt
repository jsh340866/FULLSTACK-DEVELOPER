## 📝 [오답 노트] 정보처리기사 - 네트워크 프로토콜

### 🔍 문제 (image_64e0a1.png 참고)
IP의 동작 과정에서의 전송 오류가 발생하는 경우 오류 정보를 전송하는 목적으로 사용하는 프로토콜로, Ping-of-Death에서도 사용하는 프로토콜은 무엇인가?

* **보기:** ICMP, RARP, IP, 라우팅 프로토콜, NAT, IGMP, ARP
* **나의 답변:** NAT (X)
* **정답:** ICMP (O)

---

### 💡 핵심 개념 정답 해설

#### 1. 정답: ICMP (Internet Control Message Protocol, 인터넷 제어 메시지 프로토콜)
* **주요 역할:** IP 프로토콜의 약점인 **비연결성 및 불완전성**을 보완하기 위해 사용됩니다. 네트워크 내에서 **전송 오류를 보고**하고, 네트워크 상태를 **진단(Ping)**하는 역할을 수행해요.
* **문제 키워드 매칭:**
  * *"전송 오류가 발생하는 경우 오류 정보를 전송"* ➡️ ICMP의 고유 기능
  * *"Ping-of-Death에서 사용"* ➡️ ICMP 패킷(Ping)을 비정상적으로 크게 만들어 시스템을 다운시키는 대표적인 공격 기법

#### 2. 오답 체크: NAT (Network Address Translation)가 아닌 이유
* **주요 역할:** 제한된 **공인 IP**를 절약하기 위해, 내부 네트워크의 여러 **사설 IP**를 하나의 공인 IP 주소로 변환해 주는 기술이에요. (예: 가정용 공유기)
* **탈락 이유:** 오류 보고나 네트워크 진단과는 전혀 관련이 없는 '주소 변환 및 보안' 기술이므로 답이 될 수 없어요.

---

### 📌 함께 출제되는 중요 프로토콜 요약 테이블

| 프로토콜 | 핵심 키워드 및 역할 |
| :--- | :--- |
| **ICMP** | 네트워크 **오류 보고**, **Ping** 진단, Ping-of-Death 공격에 악용 |
| **ARP** | 논리 주소(**IP**) ➡️ 물리 주소(**MAC**)로 변환 |
| **RARP** | 물리 주소(**MAC**) ➡️ 논리 주소(**IP**)로 역변환 |
| **IGMP** | 멀티캐스트 **그룹 관리** 및 멤버십 유지 |
| **IP** | OSI 3계층 프로토콜, 데이터 패킷의 **경로 지정(라우팅)** 담당 |

---

### 🧠 한 줄 암기 팁!
> 네트워크에 **오류**가 나서 **Ping**(핑)을 날릴 땐, **IC**U(중환자실)가 연상되는 **ICMP**를 기억하자!
