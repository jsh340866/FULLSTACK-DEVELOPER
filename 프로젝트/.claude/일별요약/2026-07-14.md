## 2. Pandas 기초 — Series vs DataFrame

### 왜 구분해야 하나?

- `Series`는 1차원 데이터(값 하나짜리 열), `DataFrame`은 여러 Series를 묶은 2차원 표
- 같은 컬럼을 꺼내도 **대괄호 개수**에 따라 타입이 달라진다

```python
menu = pd.Series(['비빔밥', '김치찌개', '된장찌개'])
price = pd.Series([10000, 9000, 8000])
df = pd.DataFrame({'메뉴': menu, '가격': price})

df['메뉴']     # Series (대괄호 1개)
df[['메뉴']]   # DataFrame (대괄호 2개, 표 모양 유지)
```

> 💡 `df['가격']` 처럼 Series로 꺼내면 이후 그래프나 통계 함수에 바로 쓰기 편하고, `df[['가격']]` 처럼 DataFrame으로 꺼내면 다른 표와 합치거나 열을 추가하기 편하다.

### loc vs iloc

| 구분 | 기준 | 범위 지정 시 |
|---|---|---|
| `loc` | 라벨(인덱스 이름, 컬럼명) | **끝 포함** |
| `iloc` | 위치(정수) | **끝 제외** |

```python
df.loc[df['가격'] >= 9000, ['메뉴', '가격']]   # 조건 필터 + 열 선택
df.iloc[0:2, 0:2]                            # 앞 2행, 앞 2열 (2는 미포함)
```

### 열 추가 + 조건부 값 수정

```python
df['할인가'] = (df['가격'] * 0.9).astype(int)         # 새 열 추가 (정수형 변환)
df.loc[df['메뉴'] == '김치찌개', '가격'] = 9500        # 조건에 맞는 값만 수정
df = df.drop(columns=['할인가'])                       # 열 삭제
```

### 정렬 · 조건 필터 · 이름 변경

```python
df.sort_values(by='가격', ascending=True)              # ascending=True 오름차순, False 내림차순
df[(df['원산지'] == '국내산') & (df['가격'] >= 9000)]   # 조건은 각각 괄호로 감싸고 & 로 연결
df.rename(columns={'메뉴': 'menu', '가격': 'price'})    # 컬럼명 영어로 변경
```

## 3. Pandas — 파일 입출력 & 전처리

### CSV 저장/불러오기

```python
df.to_csv('menu.csv', index=False)   # index=False: 행번호 저장 안 함 (제출 파일 기본)
```

### 데이터 파악


### 결측치 처리

- **수치형** → 중앙값(median)으로 채움
- **범주형** → 최빈값(mode)으로 채움

```python
df3['가격'] = df3['가격'].fillna(df3['가격'].median())
df3['원산지'] = df3['원산지'].fillna(df3['원산지'].mode()[0])
```

### 인코딩 (문자 → 숫자)

```python
grade.map({'합격': 1, '불합격': 0})   # 라벨 인코딩 — 2개 범주(0/1)일 때
pd.get_dummies(df2)                   # 원핫 인코딩 — 범주가 여러 개인 열 전체를 0/1 열로 변환
```

### 집계 & 이어붙이기

```python
df.groupby('타입')['가격'].mean()               # 그룹별 평균 (EDA 핵심)
pd.concat([df2.head(1), df2.tail(1)], axis=0)   # 위아래로 이어붙이기 (train+test 합칠 때 사용)
```

## 4. 머신러닝 — 이진분류 실습 (Adult Income 데이터셋)

`04머신러닝/01지도학습/01이진분류` 폴더에서 소득이 `<=50K` 인지 `>50K` 인지 예측하는 이진분류 모델을 처음부터 끝까지 실습했다.

### 전체 흐름

```
데이터 로드 → EDA → 결측치/인코딩 전처리 → train/val 분할 → 모델 학습 → 평가
```

### 4-1. 데이터 로드 & EDA

```python
train = pd.read_csv('train.csv')   # (29304, 16)
test = pd.read_csv('test.csv')     # (3257, 15) — income 컬럼 없음(예측 대상)

train.info()          # workclass, occupation, native.country 등에 결측치 존재
train.describe()      # age 최소값이 -38처럼 이상치도 확인됨
```

- `seaborn.boxplot`으로 수치형 컬럼들의 분포·이상치를 시각적으로 확인

### 4-2. 결측치 처리

```python
num_cols = ['age', 'hours.per.week']
cat_cols = ['workclass', 'occupation', 'native.country']

for c in num_cols:
    m = train[c].median()        # train 기준으로 계산한 값을 test에도 동일 적용
    train[c] = train[c].fillna(m)
    test[c] = test[c].fillna(m)

for c in cat_cols:
    m = train[c].mode()[0]
    train[c] = train[c].fillna(m)
    test[c] = test[c].fillna(m)
```

> 💡 train 기준값을 test에도 그대로 적용하는 이유: test 데이터 정보가 학습 과정에 섞이지 않도록(데이터 누수 방지) 하기 위해서다.

### 4-3. 타겟 분리 + 원핫 인코딩

```python
y = train['income'].map({'<=50K': 0, '>50K': 1})   # 타겟을 0/1로 변환
train = train.drop(columns=['id', 'income'])
test_id = test['id']                                # 제출용으로 따로 보관
test = test.drop(columns=['id'])

all_df = pd.concat([train, test], axis=0)   # train+test를 합쳐서 인코딩
all_oh = pd.get_dummies(all_df)             # 105개 컬럼으로 확장

X = all_oh.iloc[:len(train)]        # 다시 train 부분만 분리
X_test = all_oh.iloc[len(train):]   # test 부분만 분리
```

> ⚠️ train/test를 **합쳐서** 원핫 인코딩한 뒤 다시 나누는 이유: 각각 따로 인코딩하면 한쪽에만 있는 범주값 때문에 컬럼 개수가 달라질 수 있기 때문이다.
> ⚠️ 노트북에서 `drop(columns=['id','income'])` 셀을 두 번 실행하면 이미 삭제된 컬럼이라 `KeyError`가 발생한다 — 전처리 셀은 위에서 아래로 **한 번씩만** 순서대로 실행해야 한다.

### 4-4. train/validation 분할

```python
from sklearn.model_selection import train_test_split
X_tr, X_val, y_tr, y_val = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)
```

- `stratify=y`: 분할 후에도 원본과 동일한 타겟 클래스 비율을 유지 (한쪽에 `>50K`가 몰리지 않게)

### 4-5. 모델 학습 & 평가

```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=100, random_state=0)
rf.fit(X_tr, y_tr)

from sklearn.metrics import accuracy_score, roc_auc_score
pred = rf.predict(X_val)
proba = rf.predict_proba(X_val)[:, 1]   # 1(>50K)일 확률만 슬라이싱

print('정확도 :', accuracy_score(y_val, pred))   # 0.8528
print('ROC-AUC:', roc_auc_score(y_val, proba))    # 0.9014
```

- `predict()`: 최종 예측 클래스(0 또는 1)
- `predict_proba()`: 각 클래스에 속할 확률 — `[:, 1]`로 양성 클래스(`>50K`) 확률만 추출해 ROC-AUC 계산에 사용

## 5. 오늘 배운 것 요약

- **Series vs DataFrame**은 대괄호 개수 차이로 구분되고, 용도에 따라 골라 써야 한다
- **loc(라벨, 끝 포함) vs iloc(위치, 끝 제외)** 차이를 명확히 이해했다
- 결측치는 **수치형→중앙값, 범주형→최빈값**으로 채우는 것이 기본 패턴이다
- 인코딩은 범주가 2개면 **map()**, 여러 개면 **get_dummies()** 로 처리한다
- 머신러닝 실습에서는 **train 기준으로 계산한 값(중앙값 등)을 test에도 동일 적용**해 데이터 누수를 막고, **train_test_split(stratify=y)** 로 클래스 비율을 유지하며 분할했다
- **RandomForestClassifier**로 이진분류 모델을 학습하고, **accuracy_score / roc_auc_score**로 성능을 평가하는 전체 파이프라인을 익혔다 (정확도 0.8528, ROC-AUC 0.9014)
