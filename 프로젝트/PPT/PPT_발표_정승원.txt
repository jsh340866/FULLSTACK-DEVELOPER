안녕하십니까, 백앤드 개발과 기술 스택, 주요기능 소개를 맡은 정승원입니다.
이어서 진행하겠습니다.

[기술 스택]
먼저 기술 스택입니다. 백엔드는 Java, Spring Boot이고 인증은 Spring Security와 JWT를 썼습니다. DB는 MySQL이고 JPA, Hibernate로 접근하고, 테스트는 JUnit으로 작성했습니다.

프론트엔드는 별도 프레임워크 없이 HTML, CSS, JavaScript로만 만들었습니다.

배포·협업 쪽은 Jenkins, Docker, Git, GitHub, GitHub Webhook, Git Flow, Sourcetree를 썼습니다. 인프라는 AWS EC2, Route 53, Nginx, Let's Encrypt를 썼습니다.
	
[사용 라이브러리]
라이브러리는 네 개 썼습니다. jjwt로 토큰을 생성하고 검증했고, jsoup은 네이버 금융 뉴스 크롤링할 때 HTML 파싱 용도로 썼습니다. Swagger로 컨트롤러 전체에 API 문서를 자동 생성했고, Lombok으로 반복 코드 줄였습니다.

프론트는 특별한 라이브러리 없이 HTML, CSS, 자바스크립트로 작성했고 차트 또한 Canvas API로 직접 그렸습니다.

[사용 API]
외부 API는 여섯 개 사용했습니다. 공공데이터포털에서 주가 시세와 기업정보, 오픈다트에서 기업 코드와 기업개황, 재무제표, 배당금을 가져오고, 한국수출입은행에서 환율, KRX에서 코스피 지수 수집합니다. 네이버증권으로 실시간 시세 보여주고, 네이버뉴스는 크롤링해서 종목별 뉴스로 붙였습니다.

이 중 DART, 공공데이터포털, 한국수출입은행, KRX 네 개는 매일 스케줄러가 자동으로 돌면서 수집하고, 네이버뉴스는 매시 정각마다 스케줄러가 크롤링해서 가져옵니다.

[주요 기능]
다음으로는 주요 기능입니다.

첫번째로, 메인 화면입니다. 코스피 지수랑 환율 위젯이 있고, TOP10 추천 종목, 저PER·저PBR·고ROE·고배당 4대 랭킹을 볼 수 있습니다. 이 중 TOP10 추천 종목은 10초 주기로 실시간 갱신됩니다.

다음으로, 종목 목록입니다. PER, PBR, ROE, 배당수익률로 필터링하고 정렬, 페이징, 검색 됩니다. 

종목을 클릭하면 들어가는 상세 페이지에서는 재무제표 연도별 추이랑 투자지표, 관련 뉴스 볼 수 있습니다.

다음으로, TOP100 랭킹 페이지입니다. F-Score에 7개 팩터 가중 스코어링을 합쳐서 만든 결과를 보여줍니다.

다음으로, 투자지표 스코어링 엔진입니다. 세 단계로 나뉩니다. 첫번째로 화면에 보이는 것처럼 10개 지표를 계산합니다. 다음으로 이 지표들을 바탕으로 F-Score를 매기는데, 수익성·재무건전성·운영효율성 세 영역의 항목을 합쳐서 0점에서 9점 사이로 평가합니다. 마지막으로 F-Score가 일정 점수 이상인 종목만 후보로 걸러서, 화면에 나온 7개 지표에 각각 가중치를 매기고 백분위로 정규화한 다음 합산해서 TOP100 점수를 만듭니다.

다음으로, 로그인과 회원가입입니다. 회원가입할 때는 이메일 형식, 비밀번호는 영문과 숫자 조합 8자 이상, 닉네임까지 입력값 검증을 거치고, 이메일 중복 여부도 확인합니다. 비밀번호는 평문으로 저장하지 않고 암호화해서 저장하고, 로그인은 JWT 기반으로 Access, Refresh 토큰을 발급하고 재발급까지 처리합니다.

다음으로, 관심종목입니다. 종목 상세나 목록에서 별 모양 버튼을 눌러 관심종목으로 등록하거나 해제할 수 있고, 등록된 종목은 별 아이콘이 활성화된 상태로 표시됩니다.

다음으로, 투자일지입니다. 종목별로 투자일지를 만들고 매수·매도 기록을 추가할 수 있는데, 기록을 추가할 때마다 보유 수량이 다시 계산돼서 수량이 남아 있으면 보유 상태, 다 팔면 완료 상태로 자동 전환됩니다. 제목이나 메모도 수정할 수 있습니다. 목록은 카테고리, 검색어, 기간 조건으로 페이징 조회가 됩니다.

다음으로, 마이페이지입니다. 닉네임과 비밀번호를 변경할 수 있고 관심종목도 여기서 관리할 수 있습니다. 회원탈퇴는 소프트 삭제로 처리하고, 30일 지나면 스케줄러가 완전히 삭제합니다.

마지막으로 반응형입니다. 메인 화면부터 종목 목록, TOP100 랭킹, 투자일지, 관심종목, 마이페이지까지 전부 모바일 화면에 맞춰 대응했습니다.

지금까지 말씀드린 기능들은 현재 배포 완료된 상태로 해당 URL로 접속하여 확인하실 수 있습니다.

이상으로 기술스택과 주요기능 설명이였습니다.
